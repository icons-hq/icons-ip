# 상품상세 표시 설정 대조

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-13 로그인된 [상품상세 설정](https://sell.smartstore.naver.com/d/v2/display-config/product-detail)을 읽고 샘플 미리보기를 확인했다. 원본 적용·저장은 실행하지 않았다. 임시 문구·기간·대상 선택은 새로고침으로 폐기하고 빈 문구·띠배너 꺼짐을 다시 읽었다. 추가 조사 증거 (`output/smartstore-reference-20261012/store-detail-reference/manifest.json`)와 기존 85–95, 252–254 증거 (`output/smartstore-reference-20261012/store/manifest.json`)를 사용한다.

## 구현 경계

기존 `GoodDetail`의 필수 상세정보·KC·배송/교환반품·문의·리뷰 탭과 전체 평균/건수는 유지한다. 수동 관계는 `goods_relations`의 활성·기간·공개 구성 조건을 유지하며, 자동 추천 토글로 수동 편성을 숨기지 않는다. `GoodRelatedProducts`와 이미지 태그·코디 소비자는 수정하지 않고 새 PDP 구성을 별도 컴포넌트로 삽입한다.

일차 구현은 `/admin/display/detail`의 **띠배너**와 **리뷰·자동추천**을 독립 revision으로 저장한다. `store.manage`를 현재 프로필·운영자 원장으로 다시 검사하고 actor 잠금→operation UUID→설정 행→정렬한 대상 참조 순서로 직렬화한다. 정확히 같은 요청은 감사·저장1회, 불명확한 응답은 입력·operation을 고정해 같은 요청으로 확인한다. 다른 관리자의 수정은 충돌로 알리고 입력은 보존한다.

배너 개별 상품은 최대200개, 카테고리는 최대10개를 명시적으로 선택한다. 상품 참조는 FK로 초안 URL 변경을 따라가고 삭제 시 제거한다. 날짜는 한국 날짜의 시작 포함·종료 다음날00:00 제외로 계산한다. 카테고리는 공개 활성 상태와 조상 보관 여부를 다시 검사하고 대표·추가 분류의 하위 상품을 포함한다. 공개 응답에는 선택된 비공개 상품ID나 운영자 정보가 나오지 않는다. 개별 상품200개와 과거 날짜를 포함한 기존 기간 수정 허용은 ICONS 정책이며 원본 상한·편집 제한을 확인한 값으로 쓰지 않는다.

리뷰 요약은 현재 공개 리뷰 전체의 분모와4·5점 분자를 DB에서 집계한다. 상단 카드는4점이상 중 사진 있음→평점→최신순→ID로 최대10개를 선정한다. ICONS에 없는 동영상·도움됨 순위는 만들지 않는다. 카드 수가0이면 요약 영역을 숨기고 일반 리뷰 탭은 유지한다.

자동 추천은 다음 ICONS 기준으로 표시한다. 모든 후보는 현재 상품/IP 공개·미보관·판매제한없음 게이트를 통과하고 현재 상품을 제외한다. 품절은 기존 공개 카탈로그처럼 표시한다.

- 유사: 같은 공개 최하위 분류를 우선하고 같은 IP 후보를 뒤에 둔다. 최신 등록순·ID로 안정 정렬하며 최소5개·최대30개다. 원본의 비공개 분석 엔진과 동등한 정확도를 주장하지 않는다.
- 함께 구매: 한국 시각 직전30일의 서버 확정 결제와 취소/반품 제외를 검증한 같은 주문에 포함된 후보만 사용한다. 함께 포함된 주문 수→판매수량→ID로 정렬하며 최소5개·최대30개다. 사용자/주문ID·개별 집계값은 공개하지 않는다.
- 카테고리 인기: 활성 최하위 대표분류(깊이2이상)에서 직전30일 확정 판매수량→현재 찜 수→최신순·ID. 양수 판매/찜 근거가 있는 후보만 최대12개다.
- 스토어 인기: 같은 판매·찜 기준으로 스토어 전체에서 최대12개다. 네이버의 대표카테고리→BEST 대체 로직과는 다른 ICONS 정책이다.

구매유도 통계·배송비 절약·관심모음은 [후속 원본 대조](product-detail-experiences-parity.md)와 [구현·검증](product-detail-experiences-implementation-qa.md)을 완료했다. 대표미디어도 [등록·검증·재생](product-detail-media-implementation-qa.md)을 완료했다. 이미지 영역 선정 베스트리뷰도 [선정·노출 검증](product-detail-review-best-implementation-qa.md)을 완료했다. 동일 제품군의 다른구성은 [운영자 지정 편성과 독립 표시 설정](other-composition-implementation-qa.md)으로 구현한다. 원본 자동 추천의 산식을 재현했다고 주장하지 않는다.

13일 원본의 다른구성 추천 패널을 다시 열어 확인했다. 같은 상품의 용량·구성·맛·향을 자동 추천하며, 패션/잡화는 다른 컬러·디자인 테마를 사용할 수 있다. 카테고리와 후보 개수에 따라 테마가 달라지고 후보 0개면 숨긴다. 샘플 미리보기는 상단 리뷰 요약 아래, 상세정보 탭 위에 가로 상품 카드를 놓는다. 수동 제품군 편집이나 표준그룹상품과의 동등성을 이 화면으로 입증하지 않는다. ICONS에서 명시적인 제품군·변형축을 운영자가 지정한다면 이는 정확한 후보를 확보하기 위한 자체 대응 계약이다. 원본 패널 (`output/smartstore-reference-20261012/other-composition-source/source-panel.png`)과 확인 내용·해시 (`output/smartstore-reference-20261012/other-composition-source/manifest.json`)를 보존했다. 원본 토글과 적용하기는 조작하지 않았다.

## 구현·검증 상태

위 일차 범위인 띠배너·상단 리뷰 요약·자동 유사/함께구매/카테고리인기/스토어인기는 구현했고 격리 DB 기능·7개 경합, 실제 관리자 저장→공개 상세, 두 탭 충돌·입력 보존, PC/390px 검증과 시작값 원복을 완료했다. 세부 계약·PostgREST safeupdate 후속 수정·증거·남은 범위는 [구현·검증 기록](product-detail-presentation-implementation-qa.md)을 따른다. 원본 최종 적용과 운영 배포는 하지 않았다.
