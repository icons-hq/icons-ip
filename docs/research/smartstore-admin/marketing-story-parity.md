# 마케팅 링크·쇼핑스토리 원본 계약

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

조사일: 2026-10-13 KST. 로그인된 스마트스토어센터의 현재 화면과 직접 연 공식 도움말을 대조했다. 생성·저장·등록·삭제·링크 방문·외부 발송은 실행하지 않았다. 이 문서는 구현 기준이며 ICONS 구현 완료 보고가 아니다.

## 증거

`output/smartstore-reference-20261012/marketing-story-reference/manifest.json`에 화면별 URL·설명·SHA-256을 보존했다. 기존 `store/` 증거61–65, 96–104b와 이번 추가 화면01–14를 함께 참조한다. 도움말은 같은 페이지에서 다른 문답을 펼칠 수 있으므로 주소창과 별도로 각 문답의 `data-content-no`를 확인해 아래 정본 URL을 연결했다.

## 마케팅 링크

실제 관리 화면은 **스토어홈·상품상세·쇼핑스토리·카테고리** 네 탭이다. 홈은 URL 칸과 생성 버튼이고, 나머지는 이미 생성된 링크의 조회/복사 목록이다. 상품·스토리 목록은0개, 카테고리에는 기존 링크1개가 있었다. 링크 관리 화면에서 임의 목적지를 고르는 통합 생성 폼이나 캠페인 이름 입력은 보이지 않았다(01–03, 기존61–65).

| 대상 | 생성 진입점 | 관리 목록에서 확인한 항목 |
| --- | --- | --- |
| 홈 | 혜택/마케팅 → 마케팅 링크 → 스토어홈 | URL·생성/복사 |
| 상품 | 상품 조회/수정에서 N개 선택 → 일괄 변경 → 마케팅 링크 생성/복사 | 구분·상품번호·상품명·전시상태·URL·복사 |
| 스토리 | 쇼핑스토리 목록에서 N개 선택 → 마케팅 링크 생성/복사 | 번호·전시상태·제목·URL·복사·시작일·종료일 |
| 카테고리 | 해당 카테고리 상세 설정 하단 → 생성 | 구분·이름·URL·복사 |

생성 위치는 현재 화면 안내와 [공식 활용 방법](https://help.sell.smartstore.naver.com/faq/content.help?faqId=16330)이 일치한다. 같은 도움말은 상품 삭제 시 링크도 삭제되고 상품 복원 시 복원된다고 설명한다. 브랜드스토어 프로모션의 별도 링크 기능은 공식 문답 목록에 있으나 현재 계정의 관리 화면에는 그 탭이 없었다.

링크는 최초 생성 후 소재가 존재하는 동안 유지되고 변경할 수 없다. [스토리 링크](https://help.sell.smartstore.naver.com/faq/content.help?faqId=15931)와 [카테고리 링크](https://help.sell.smartstore.naver.com/faq/content.help?faqId=15932)가 이를 명시한다. 활성화되지 않은 카테고리는 접근할 수 없으며 잘못된 링크가 네이버플러스 스토어 홈으로 향하면 마케팅 유입으로 인정되지 않는다. 이는 현재 ICONS의 카테고리 라우팅 계약으로 자동 간주할 수 없다.

링크만 따로 삭제하는 기능은 없고 원본 상품·스토리·프로모션 등 소재를 삭제해야 한다. 사용하지 않으려면 일반 URL을 사용한다. [공식 삭제 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=16042), 증거13.

기존 링크 뒤의 분석 매개변수는 `nt`와 UTM 계열만 허용된다. 이는 네이버의 사용자정의 유입분석에 관한 계약이다. [공식 매개변수 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=15951), 증거14.

관리 화면에서 클릭수·전환수·매출 열은 확인되지 않았다. 링크를 쓰면 네이버 판매자 마케팅 수수료가 적용된다는 안내는 있지만, 이를 ICONS의 새 전환 집계가 이미 있는 것으로 해석하면 안 된다. 링크 발급/라우팅과 방문·결제 귀속은 별도 구현 단위다.

## 쇼핑스토리

### 목록과 상태

목록은 제목 검색, 상세검색의 전시상태 전체/전시대기/전시중/전시중지 및 날짜 범위, 기간 프리셋, 100개씩 보기가 있다. 현재 총0개이며 수정·번호·전시상태·제목·전시 시작/종료일·최종수정일·등록일·삭제 열과 선택삭제·마케팅 링크 생성/복사를 확인했다(04, 기존96–98). 복사 기능은 **마케팅 링크 복사**이며 스토리 본문 복제 버튼은 확인하지 못했다.

개별 스토리의 비노출 스위치는 제공하지 않는다. 전시기간 종료 시 자동 전시중지되고, 무기한 스토리도 수정에서 종료 시점을 정해 내린다. 기본 검색기간은3개월이며 삭제된 스토리는 운영 목록에서도 찾을 수 없고 공개 반영에는 시간이 걸릴 수 있다. [공식 전시중지 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=15112), 증거12. 실제 종료일 변경·삭제는 미실행이다.

공개 스토리 순서는 최신순으로 고정이고 수동 변경은 불가하다. [공식 순서 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=6097), 증거11. 여기서 최신 기준이 생성일인지 최근 수정일인지, 같은 시각의 정렬 기준은 명시되지 않았다.

### 등록과 본문

제목은 필수50자, 상세 본문은 필수다. 본문 작성은 새 스마트에디터 ONE 창으로 열리고, 원본 폼에는 가로848px 권장과 외부링크·일부 스크립트/태그 제거 안내가 있다. 관련상품과 전시기간은 각각 기본 설정안함이다. 기간을 켜면 시작일·종료일 달력 입력이 나타난다(05,08).

본문 편집기에는 사진·동영상·인용구·구분선·장소·링크·표·HTML 첨부, 글감·라이브러리·템플릿과 문단·문자 서식 도구가 있다. HTML은 입력→변환 별도 창이다(09). 내용을 넣거나 변환·저장·등록하지 않아 허용 태그 목록·최대 본문 크기·실제 정제 결과는 미확인이다. 기존 저장 초안은 열지 않았다.

## ICONS에 필요한 독립 계약

현재 `CampaignScreen`은 이벤트/드롭 캠페인과 무상 카드팩 교환처를 함께 다룬다. `lib/admin/campaigns.ts`는 작성중/공개/종료 상태, 본문 최대20블록, 상품 블록당 최대8개를 정의한다. 따라서 이름을 쇼핑스토리로 바꾸는 것만으로 원본의 섹션/상품 한도·목록·노출 계약을 충족하지 않는다.

1. **스토리 원장과 공개 표면:** 제목·본문·선택 전시기간·섹션/상품 순서, 목록 필터/페이지네이션, 수정/삭제·버전 충돌·감사, 별도 공개 목록/상세와 홈 최신3개가 필요하다. 원본의 전시상태를 날짜로 계산하되, 원본에 명시되지 않은 최신 기준·시간대/종료 경계·삭제 복원 정책은 ICONS 정책으로 밝혀야 한다.
2. **본문 편집·이미지:** 기존 안전한 이미지 업로드/claim·본문 구성 도구를 재사용할 수 있다. 스마트에디터 자체는 네이버 도구이며, HTML/리치텍스트를 도입한다면 저장·공개 양쪽의 정제 계약과 허용 링크/태그를 별도로 정한다. 대표이미지/설명 추출도 공개 렌더와 같은 결과를 써야 한다.
3. **관련상품:** 10섹션/제목13/각200/전체300을 서버에서도 검사하고 순서·중복·비공개·품절·삭제 참조를 정한다. 현재 상품선택 UI와 공개 카탈로그 게이트를 재사용하되 캠페인의8개 제한을 그대로 가져오지 않는다.
4. **마케팅 링크 원장:** 홈/상품/스토리/카테고리의 실제 대상에 고정된 링크를 한 번 발급하고 같은 대상으로 재요청하면 같은 결과를 반환한다. 각 생성 진입점과 통합 조회/복사, 대상 비활성/삭제/복원의 라우팅을 함께 다룬다. 임의 외부 URL을 저장하는 단순 단축링크로 대체하지 않는다.
5. **귀속·권한:** 클릭을 집계할지, 어느 기간/방식으로 확정 결제와 연결할지와 개인정보 보존 기준은 별도 계약이다. 원본 매니저 표에서 스토어관리는 부매니저/인플루언서/대행사에게 열리고 혜택/마케팅은 닫힌다. 생성 진입점이 다른 메뉴에 있으므로 링크 발급 권한을 메뉴 소속만으로 추정하지 말고 ICONS의 세분 권한과 명시적으로 연결한다.

이번 추가 조사 후 폼을 취소해 총0개 스토리 목록으로 돌아왔고, 생성한 도움말·편집기 탭은 닫았다. 실제 발행·수정·삭제·링크 생성/복사 결과, 링크 클릭/전환 귀속, 하위 역할의 생성 권한은 확인하지 않았다.
