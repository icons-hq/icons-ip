# 성별·연령 분석과 디지털 교환 정책 — 2026-10-19

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

상태: 사용자가 선택한 두 정책을 구현하고 격리 로컬 환경에서 검증했다. 운영·Preview 배포, 운영 DB 변경, 실제 고객 정보 수집은 하지 않았다.

## 확정한 정책과 구현

- 디지털 파일은 구매 당시 파일 재다운로드와 주문에 연결된 문의·취소/환불 심사로 처리한다. 다른 파일로 교환하지 않는다. 디지털 파일이 포함된 주문은 고객 교환 접수, 관리자 접수와 클레임 유형 변경의 DB 경계에서 교환을 거절한다. 주문 전체 처리 원칙을 유지한다.
- 설정 화면에서 별도 선택 동의와 자가 입력 성별을 받는다. 여성·남성·기타를 선택할 수 있고 초기값은 미선택이다. 동의 확인 없이 저장할 수 없다. 쇼핑·구매·마케팅 동의·회원 방문 분석과 연결하지 않는다.
- 성별은 공개 프로필이나 관리자 개인별 고객 조회에 넣지 않는다. 비공개 테이블에 현재 값만 저장하고, 변경 버전·본인·로그인 세션을 결속한다. 철회와 탈퇴 신청 시 성별과 동의 시각을 제거하며, 오래된 재시도로 복원되지 않는다. 기존 생년월일에 따른 연령대는 미제공 성별로 집계할 수 있다.
- 관리자 고객분석의 **성별·연령별 분석** 탭에 현재 가입 회원과 마감된 주·월의 결제 고객을 제공한다. 14–19세, 20대부터 50대까지 5세 구간, 60세 이상을 구분한다. 결제 고객은 승인·입금 근거를 사용하여 중복 제거하며 취소/환불된 결제도 포함한다. 성별을 동의 전 결제에 소급하지 않는다. 연령은 표시한 기준일의 생년월일로 계산한다.
- 각 성별·연령 셀의 인원이 **10명 미만이면 서버가 null**을 반환한다. 0명도 비공개이며 화면·차트·엑셀은 같은 보호 결과만 받는다. 숨긴 셀이 하나일 때는 추가 셀도 숨기고, 합계·비율·원시 인원·개인 명단을 반환하지 않는다. 이 규칙은 집계 공개 기준이며 모든 시점 간 추론을 막는 차등 개인정보보호 기법은 아니다.
- 선택 동의 안내와 개인정보처리방침 개정 본문·이전 본문을 함께 준비했다. 로컬 문서 개정일은 2026-10-19이며 실제 공개 시에는 기존 방침 제13조의 사전 공지 절차와 실제 시행일을 맞춰야 한다. 이번 작업은 고지를 운영 사이트에 게시하지 않았다.

## 원본 대조와 범위

잠금 해제 후 로그인된 스마트스토어의 상품·판매·클레임·정산·문의·리뷰·전시·혜택·분석·판매자 설정에서 55개 메뉴 경로를 다시 조회했다. 화면 이동 직후 이전 화면이 남은 캡처는 확인 근거에서 제외하고 상품 등록·목록은 완료 상태를 다시 읽었다. 포인트 지급내역은 개선 안내가 노출되어 세부 내역의 재대조 근거로 사용하지 않는다. 원본의 고객/금융 정보가 포함될 수 있는 원시 캡처는 작업 전용 로컬 임시 폴더에만 보존한다.

이 원본 조회는 등록·발송·환불 등 원본의 실제 업무를 실행한 결과가 아니다. 모든 입력 조합과 저장 결과, 픽셀 단위 동일성을 전수 검증했다고 보지 않는다. 기존 일반 기능/네이버 전용 기능 구분과 [전체 구현 기록](full-admin-implementation-20261016.md)을 유지한다.

최종 전체 회귀는 **10,071개 통과·8개 제외**, 타입검사·ESLint 오류0·빌드 통과다. 기존 린트 경고3개와 DB 경고250개는 증가하지 않았다. 407개 migration의 적용 원장과 원문 해시가 일치했다. 별도 로컬 빌드 앱의 PC1440/모바일390 다섯 상태도 페이지 오류·콘솔 경고/오류·레이아웃 지적 없이 통과했다. 통합 결과 (`output/smartstore-policy-followup-20261019/final-verification.json`), 검증 캡처 (`output/smartstore-policy-followup-20261019/verified-captures-manifest.json`), 원본 재조회 목록 (`output/smartstore-policy-followup-20261019/source-recheck-summary.json`).
