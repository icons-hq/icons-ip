# 상품 사진 자동 명암·테두리·도형 — 계산 계약과 검증

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-14. [잔여 도구 제안](product-photo-remaining-tools-proposal.md)의 우선 세 가지를 구현했다. 자체 자동 명암, 단색 안쪽 테두리, 원형·둥근 사각형 마스크다. 이 문서는 세 기능의 최초 구현·검증 기록이다. 후속 [이미지 로고](product-photo-logo-implementation-qa.md), [색조 필터·추가 기하 도형](product-photo-filters-implementation-qa.md), [자동 수평](product-photo-straighten-implementation-qa.md)은 별도 계약과 검증 기록을 따른다. 자동 인식과 전용 아트 자산은 포함하지 않는다. 원본 서비스와 같은 픽셀 알고리즘이라고 주장하지 않는다.

## 값과 합성 순서

| 값 | 허용 범위 | 의미 |
| --- | --- | --- |
| `automaticLevels` | boolean, 기본 false | 수정 전 원본 전체에서 구한 alpha 가중1%·99% 밝기 범위를 공통 RGB에 적용 |
| `frameWidth` | 정수0~64 | 최종 crop의 안쪽 테두리 두께. 실제 최대값은 짧은 변의 절반을 내림한 값과64 중 작은 값 |
| `frameColor` | `#RRGGBB`, 기본 흰색 | 단색 테두리. 두께0에서는 색만 바꿔도 무변경 |
| `mask` | `none`·`circle`·`rounded` | 최종 crop 중앙의 정원 또는 둥근 사각형. 기본 none |

처리 순서는 **자동 명암 → 밝기·대비·채도·색온도 → 선명도 → 원형·선형 블러 → 비네팅 → 모자이크 → 텍스트 → 회전·반전·사각 자르기 → 테두리·도형 마스크 → 미리보기만 축소**다. 모든 신규 선택이 기본값이면 이전 렌더 순서·출력 형식·무변경 null 반환을 유지한다. 기존 보정과 레이어는 [사진 편집](product-photo-editor-implementation-qa.md), [선명도·블러](product-photo-effects-implementation-qa.md)를 따른다.

## 자동 명암

[계산 모듈](../../../lib/admin/photo-editor-auto-levels.ts)은 각 픽셀의 밝기를 `Y=round((54R+183G+19B)/256)`로 구하고256개 히스토그램 구간에 alpha 정수값을 더한다. alpha0의 숨은 RGB는 집계하지 않는다. 누적값이 `ceil(total/100)`·`ceil(total×99/100)`에 처음 도달하는 구간을 `L,H`로 쓴다. 전체가 투명하거나 `H-L<16`이면 `L=0,H=255`로 무효과를 적용한다.

채널별 출력은 `round((C-L)×255/(H-L))` 후0~255 제한이다. 정수곱을 먼저 계산한 뒤 나눠127.5 같은 절반값을 잘못 내리지 않는다. alpha와 alpha0의 RGB는 그대로 둔다. 계수는 감마가 적용된 RGB의 밝기 지표이며 화이트밸런스나 선형 광량 계산이 아니다.

원본을 한 번 디코드한 세션에서 첫 자동 명암 요청만 원본 히스토그램을 구한다. 이후 자르기·수동 보정·도형 변경에도 같은 `L,H`를 사용하며 이전 결과를 다시 분석하지 않는다. 계산이 끝나기 전에 취소한 값은 캐시에 넣지 않는다. 끄기는 원본에 다른 선택만 적용하고 재설정은 자동 명암도 끈다.

## 최종 crop 좌표와 alpha

[테두리·마스크 모듈](../../../lib/admin/photo-editor-presentation.ts)은 원본 해상도 합성과 회전·반전·사각 자르기를 마친 캔버스의 크기만 사용한다. 회전 행렬은 경로를 그리기 전에 잠시 초기화하고 작업 후 복원한다.

- 원형은 `(W/2,H/2)` 중심, 반지름 `min(W,H)/2`다. 가로로 긴 사진에서도 타원이 되지 않는다.
- 둥근 사각형의 바깥 반지름은 짧은 변의10%다. 테두리 안쪽 윤곽은 각 변을 두께만큼 안으로 옮기고 반지름에서 같은 두께를 뺀다. 반지름은0 미만이 되지 않는다.
- 테두리는 바깥·안쪽 윤곽의 evenodd 경로를 단색 source-over로 그린다. 폭·높이가0 이하인 안쪽 윤곽은 생략한다. 1px 사진의 테두리 상한은0이고, 두께가 반지름에 도달한 원은 테두리 색으로 채워질 수 있다.
- 도형을 선택하면 원본과 테두리 합성 뒤 바깥 도형을 destination-in으로 한 번 적용한다. 마스크만 있을 때는 기존 alpha에 경계 coverage를 곱한다. 테두리는 의도적으로 alpha를 더할 수 있다. 도형 밖의 결과는 투명하며 원본 파일은 저장소에 보존한다.
- 마스크 선택은 JPEG 입력도 PNG로 출력한다. 테두리만 적용한 JPEG는 기존 JPEG 품질0.92 정책을 유지한다. PNG 인코딩 결과가5MiB를 넘으면 업로드하지 않는다.
- UI에서 자르기를 조절하는 동안에는 테두리와 마스크를 숨기고, 확정 후 새 크기로 다시 표시한다. crop이 줄어들면 두께를 새 상한으로 낮춘다. 키보드와 숫자 입력으로 같은 선택을 할 수 있다.

Canvas 경로의 안티앨리어싱은 브라우저 구현을 따른다. 다른 브라우저 간 가장자리 픽셀의 완전한 동일성은 보장하지 않는다. 미리보기와 최종 파일은 같은 원본 크기 처리 후 미리보기만1280px로 줄인다. JPEG 재압축 차이는 기존 계약과 같다.

## 4MP·자원·취소

기존 원본/최종 파일5MiB·각 변4096px·전체400만 픽셀 제한을 유지하며 테두리는 캔버스를 늘리지 않는다. 자동 명암은1KiB `Uint32Array(256)`만 추가한다. 최대 누적 alpha `4,000,000×255=1,020,000,000`은 UInt32 범위 안이다. 도형은 Canvas 경로로 계산해 별도4MP 마스크 배열이나 대형 캔버스 사본을 추가하지 않는다. 이 설명은 브라우저 전체 메모리 상한이 아니다.

히스토그램은 할당 전에 한 번, 이후4096픽셀마다 제어를 돌려주며 세션은 약8ms마다 이벤트 루프에 양보한다. alpha 적용·수동 보정도 기존 블록 단위를 따른다. 경로 그리기 전후와 인코딩 결과 반환 전 취소를 확인한다. 세션을 닫으면 bitmap·canvas·수치 캐시를 해제하며 늦게 완성된 파일을 반환하지 않는다. 네이티브 디코드·Canvas 경로·인코딩 자체의 중간 중단은 보장하지 않는다.

## 구현 회귀와 실제 Chrome 검증

구현 회귀10파일270테스트, 변경 TS/TSX의 ESLint와 관련 타입검사가 통과했다. 새 검사에는 독립적인 alpha 가중값 확장·정렬 oracle,1%/99% 경계·평탄색·완전투명·절반값 반올림·4MP 누적,1KiB 할당·중도 종료, 비정사각 원·둥근 안쪽 윤곽·1px/최대 두께, 캔버스 상태 복원, 자동 명암 cache·보정 순서, JPEG→PNG·5MiB 초과,4MP 히스토그램 취소와 늦은 결과 폐기, UI crop 중 숨김/복원·재설정을 포함한다.

근거는 실제 UI manifest (`output/product-photo-presentation-qa-20261014/ui-manifest.json`)에 실제 실행한6파일의 SHA, 캡처, PNG, DB 재조회, 정리 결과를 결속했다. 구현 단계의 검증 기록 (`output/product-photo-presentation-qa-20261014/implementation-verification.json`)은 그 시점의 독립 기록으로 보존한다. 소스 사본은 `.txt` 확장자를 붙여 빌드 입력에서 제외했다.

- **자동 명암:** 실제400×400 PNG에 대해 생산 함수를 가져오지 않는 가중 정렬 oracle을 실행했다. `L=160,H=241`이며640,000채널 전부가 일치했다. 이 입력은 전체 불투명이다.
- **테두리·도형:** 원형400×400/흰색12px, `(30,40)`에서 자른300×200 원형/흰색12px, 둥근 사각형/검은색12px와11px를 독립 거리식으로 검사했다. 도형 안의 원본 픽셀, 단색 안쪽 테두리, 도형 밖 RGBA0이 전부 맞았다. 각 윤곽의1.5px 이내는 브라우저 안티앨리어싱 검사에서 제외했다. 첫 픽셀 oracle (`output/product-photo-presentation-qa-20261014/independent-pixel-oracle.json`).
- **저장·재열기:** 검은색11px의300×200 결과를 완료·업로드·상품 저장한 뒤 다시 열었다. 미리보기·저장 파일·재열기 사이240,000채널이 모두 같았다. 인코딩 파일 바이트는 다를 수 있다. 상품 저장 전에는 두 상품 행이 그대로였고, 저장 후에는 대상 상품의 `image_path`·`updated_at`만 바뀌었다. 공유 상품과 보관함 원본 행은 그대로였다.
- **JPEG·EXIF:** EXIF6의600×400 JPEG는400×600으로 표시됐다. 원형/흰색8px을 적용한 PNG의 preview/output 960,000채널이 같고 중심 `(200,300)`·반지름200의 내부·테두리·외부 검사도 통과했다.
- **4MP:** 원본2000×2000과 자동 명암·원형/흰색64px 결과를 비교했다. 별도 가중 정렬은 `L=11,H=117`을 얻었다. 불투명 내부2,736,209픽셀의 RGB·alpha, 부분투명 내부7,179픽셀의 alpha, 흰색 테두리371,060픽셀, 외부849,472픽셀의 RGBA0이 일치했다. 부분투명 RGB와 윤곽 주변36,080픽셀은 정확 비교에서 제외했다. 업로드한4MP 결과를 같은 입력창에서 재편집한1280px 미리보기는 이전 미리보기와 바이트까지 같았다. 이4MP 경로는 상품 저장 완료와 구분한다. 추가 픽셀 oracle (`output/product-photo-presentation-qa-20261014/additional-pixel-oracle.json`).
- **응답 시간:** 단일 데스크톱 Chrome에서4MP 자동 명암의 미리보기 완료는37.7ms였다. 측정 시작 전 시각이 섞인 첫 음수 RAF 표본을 제외한 유효 간격은16.6·16.7ms 두 개다. 짧은 측정이므로 지속 프레임률이나 저사양 기기 성능 보장으로 해석하지 않는다. 원시 측정 (`output/product-photo-presentation-qa-20261014/4mp-timing.json`).
- **취소:** CPU8배 감속에서 미리보기의 갱신 중 상태를 확인하고 취소했다. 최종 파일 생성은 첫 수동 취소가 늦어 성공 사례에서 제외했다. 별도 시도에서는 DOM 관찰자가 실제 ‘편집 결과 만드는 중…’ 표시를 확인한 직후 실제 취소 버튼을 눌렀으며, 창이 닫히고 전후 상품·원본·claim 조회가 정확히 같아 늦은 업로드가 없었다. 앱 함수나 상태를 바꾸지는 않았다. 취소 관찰 (`output/product-photo-presentation-qa-20261014/final-render-cancel.json`), 취소 후 재조회 (`output/product-photo-presentation-qa-20261014/after-confirmed-cancel.json`).
- **화면:** PC와390px에서 테두리·도형 입력, 완료·취소를 직접 확인했다. 캡처02·03·04는 직접 시각 검수했으며01은 미검토 참고자료로 제외한다.04의 마스크 ‘적용 안 함’·두께0은 이미 합성된4MP PNG를 새 편집 원본으로 다시 연 정상 상태다.

검수용 상품2개·IP1개·새 claim/Storage 객체6개만 제거한 뒤 해당 잔여 건수0, 기존 보관함 원본 전체 행과 바이트의 동일성을 확인했다. 미저장 초안·검수 탭·DOM 관찰자·CPU/viewport 설정도 정리했다. 정리 결과 (`output/product-photo-presentation-qa-20261014/cleanup-result.json`).

Safari/iOS·실제 저메모리 기기·브라우저 총메모리 피크와 안티앨리어싱의 브라우저 간 동일성은 미검증이다. 새 단계에서 계정 전환 UI를 다시 재현하지 않았으며 기존 작업 수명 검증과 단위 회귀를 따른다. PNG5MiB 초과·디코드 실패 등은 관련 단위 회귀와 기존 파이프라인 검증 범위로 구분한다. 마스크와 테두리는 alpha를 의도적으로 바꾸므로 기존 보정의400만 alpha 전수 보존 결과를 이 단계에 재사용하지 않는다.
