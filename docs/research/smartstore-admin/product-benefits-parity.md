이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-14 로컬 구현·검증. 운영 반영과 스마트스토어 전체 기능 완성을 뜻하지 않는다.

## 원본에서 확인한 범위

스마트스토어 상품 등록의 구매/혜택 조건을 다시 열어 사은품 설명 100자, 사진 최대 3장과 500×500 권장 크기, 사진 사용 시 설명 필수, 이벤트 문구 40자와 상품 검색 제외 안내를 확인했다. 이벤트 템플릿 선택 모달은 빈 목록까지 확인했다. 네이버에 문구·파일을 입력하거나 등록·저장하지 않았다.

## ICONS 구현 계약

- 상품 수정의 `사은품·이벤트 안내`는 기본 상품 저장과 독립적이다. 사은품 설명·검증된 이미지 3장·이벤트 문구를 저장하고 상품 상세의 구매 영역에 표시한다. 사진 보관함을 재사용하고 사은품 사용처가 있는 사진은 보관을 막는다.
- `상품관리 → 이벤트 템플릿 관리`에서 문구를 등록·검색·수정·보관·복구한다. 사용 중/보관됨을 구분하고 페이지당 20건을 조회한다. 상품 선택 모달은 사용 중 템플릿만 제공한다.
- 템플릿 선택은 문구 복사다. 이후 템플릿 수정·보관으로 상품 문구가 바뀌지 않으며 상품 복사본도 독립된 안내를 가진다.
- 현재 상품 관리 권한, 상품/사진 잠금, 기대 버전과 요청 ID를 검사한다. 동일 요청은 같은 영수증을 돌려주며 서로 다른 오래된 저장은 충돌로 처리한다. 충돌 입력은 화면에 보존하고 재조회 후 다시 편집한다. 응답이 불명확하면 입력을 잠그고 같은 요청의 결과를 확인한다.
- 늦은 초기 조회 결과가 최신 필터·재조회·저장 결과를 덮지 않도록 읽기 순서를 확인한다.
- 공개 RPC는 상품/IP 공개·미보관·판매 제한을 검사하고 공개용 문구와 이미지 경로만 반환한다. KC 검토는 기존 상품 게시 절차의 가드를 따른다. 사은품 자동 지급·재고 할당·배송 처리나 새로운 할인 계산을 만들지 않는다.

## 남은 경계

네이버 원본의 등록·수정·삭제 후 결과는 관찰하지 않았다. ICONS 템플릿의 보관·복구·충돌·감사 방식은 기존 운영 계약을 따른다. 사은품 실물 재고·출고 자동화, 복수구매 할인, 네이버 포인트·무이자·검색 노출 정책은 이 기능에 포함하지 않는다. 운영 DB·Preview·production 배포는 실행하지 않았다.
