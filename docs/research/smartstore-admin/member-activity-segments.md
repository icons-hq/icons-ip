# 회원 방문·영상 세그먼트

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-16 사용자 확정 정책에 따라 별도 선택 동의와 최근 90일 원시 이력 보존을 구현했다. 익명 방문 통계의 `analytics-v1` 계약은 유지한다.

## 수집과 동의

- `member-activity-v1`은 회원번호·공개 화면 식별번호·상품 영상 식별번호·재생 시작/완료·관측 시각을 별도 원장에 기록한다. 원시 URL, 검색어, 이메일, 이름, IP 주소와 익명 분석 세션번호를 받지 않는다.
- 관리자 `마케팅 관리` 권한으로 타겟 세그먼트 화면에서 수집을 켜고 끈다. 기본값은 꺼짐이다. 설정 변경은 로그인 세션, revision, 작업 ID, 감사 기록으로 결속한다.
- 고객은 설정에서 안내를 읽고 별도로 동의하거나 철회한다. 기존 마케팅 수신 동의와 익명 방문 통계 선택을 변경하지 않는다.
- 수집은 현재 일반 회원의 로그인 세션·현재 동의 revision·공개 대상·영상과 상품의 실제 연결을 확인한다. 운영자·정지·탈퇴 처리 중인 계정과 비공개 화면은 수집하지 않는다.
- 철회는 같은 회원의 수집과 직렬화하고 원시 이력을 삭제한다. 탈퇴 fence도 즉시 수집을 막고 기존 이력을 삭제한다. 원시 기록은 기존 분석 보존 cron에서 한국 날짜 기준 최근 90일만 남긴다.

## 조건

방문, 미방문, 상품 조회, 상품 영상 재생 시작, 선택 상품과 같은 분류의 다른 상품 조회를 7·30·90일 조건으로 제공한다. 상품 조회·영상은 개별 상품 또는 카테고리와 하위 분류로 좁힐 수 있다. 유사 상품 조건은 선택 상품의 현재 대표 분류와 관측 시점의 조회 상품 분류를 비교하고 선택 상품 자체는 제외한다. 추천 모델이나 실제 전체 영상 시청 시간을 추정하지 않는다.

미방문은 선택한 관측 기간 전체에 걸쳐 동의와 수집이 유지된 회원만 포함한다. 동의하지 않은 회원, 동의 전 기간, 수집을 껐던 기간을 미방문으로 추정하지 않는다. 수집 재활성화 시 연속 관측 시작 시각을 갱신한다. 설정이 꺼져 있으면 해당 조건의 산출을 막으며 미집계를 0명으로 바꾸지 않는다.

세그먼트는 조건과 시점별 추정치를 저장한다. 실제 혜택·메시지 실행 시 현재 회원 상태, 현재 분석 동의, 별도의 마케팅 수신 동의를 다시 확인해야 한다.

## 검증

- 격리 로컬 DB: 별도 동의 전 차단, 계정/세션 불일치, 요청 재사용, 공개 상품·영상 연결, 상품/카테고리/유사 상품 조건, 미방문 관측 기간, 철회 삭제, 탈퇴 fence, 90일 보존 및 SQL 권한을 확인했다.
- HTTP 경합: 합성 회원의 수집 12개와 철회 1개를 동시에 실행한 5회 모두 최종 원시 기록 0건이었다.
- 실제 Chrome: 합성 관리자 수집 설정 저장, 합성 고객 동의 후 홈 방문 1건 저장, 모바일 철회 후 기록 0건과 마케팅 동의 불변을 확인했다. 후속 실제 5초 MP4를 공개 상품 화면에서 재생해 재생 시작·끝 이벤트와 동일 영상 ID를 DB에서 확인했다. 이어서 모바일에서 철회해 원시 기록 0건, 마케팅 동의 불변을 재확인했다.
- 근거: `output/smartstore-full-admin-20261016/sql-member.log`, `member-concurrency.json`, `member-browser-readback.json`, `local-member-*.png`, `member-video-browser-readback.json`, 보존한 `qa-ui/member-video-*.png`.

운영 DB와 운영 수집 설정은 변경하지 않았다. 합성 고객의 클릭은 기능 검증 자료이며 실제 사람의 개인정보 동의를 대신하지 않는다.
