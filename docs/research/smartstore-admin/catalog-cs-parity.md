# 상품·고객응대 기능 대조표

migration 파일 경로는 [배포 매핑](../../../supabase/manifests/admin-rollout-migration-map.json)을 반영했다. 아래 과거 검증·적용 기록은 당시 원본 DRAFT 기준이며 이번 운영 배포의 성공을 뜻하지 않는다.

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-12 원본 조사와 2026-10-13 상품 보충 조사, 2026-10-17 전체 후속 기능·상품 일괄 변경·복사 선택·수령 템플릿·리뷰 유형/보상의 실제 로컬 검수까지 반영한 작업 트리 기준이다. **구현 완료는 아래에 적은 ICONS 범위의 코드·검증 완료를 뜻한다. 스마트스토어 전체 기능, 모든 원본 저장 결과, 운영 배포, 모든 화면의 동일함을 뜻하지 않는다.** 실제 브라우저를 통과한 범위와 코드·SQL만 검증한 범위를 별도로 기록한다. 진행 중인 항목은 아래 후속 분류에서 완료와 구분한다.

원본 종합 근거는 상품·고객응대 조사 지도 (`output/smartstore-reference-20261012/catalog-cs/coverage.md`)와 캡처 manifest (`output/smartstore-reference-20261012/catalog-cs/manifest.json`)다. 원본의 저장·답변 발송·혜택 지급·결제·삭제·업로드는 실행하지 않았다. 고객 원문·계정 식별자는 이 문서에 복사하지 않았다.
