# 기존 통계의 전년 동일 날짜 비교

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-14. 판매분석·취소/반품/교환 분석·기존 고객현황에 비교 없음, 직전 동일 기간, 전년 동일 날짜 선택을 제공한다. 기존 RPC·금액 산식·집계 기준일은 유지하며 새 SQL이나 운영 변경은 없다. 별도 고객 구매 분석 탭과 혜택 리포트의 비교 계약은 바꾸지 않았다.

## 날짜와 호환 계약

- 선택한 시작일과 종료일을 KST 날짜로 각각 1년 전으로 옮긴다. 2월 29일은 전년 2월 28일로 보정한다. 서버 조회는 시작일 KST 자정 포함·종료일 다음 KST 자정 제외다.
- 조회기간은 기존 최대 366일이다. 비교기간은 양끝 날짜 이동 결과를 그대로 사용하므로 일수가 달라질 수 있다. 2025-02-28~2026-02-28의 366일 조회는 2024-02-28~2025-02-28의 367일과 비교한다. 비교 시작일을 임의로 잘라 맞추지 않는다.
- 기존 `compare=true` boolean 필터와 `compare=previous` 링크는 직전 동일 기간을 유지한다. URL의 `compare=true`도 직전 비교로 해석하며, `compare=year`가 전년 모드다. 비교 없음은 두 번째 RPC를 실행하지 않는다.
- [공유 날짜 계산](../../../lib/admin/stats.ts)을 페이지와 다운로드가 함께 사용한다. [비교 카드](../../../components/admin/StatsComparison.tsx)는 선택한 방식과 실제 비교 날짜를 표시한다. 빠른 7/30/90일·일/주/월·IP 필터를 보존한다. IP는 기존대로 상품 순위에만 적용한다.
- 비교 시 기존 조회 RPC를 두 기간에 각각 한 번 호출한다. 판매의 주문 생성일 기준, 클레임/가입 등 각 사건의 기존 기준과 현재 상태 판정을 바꾸지 않는다. 과거 당시의 상태 스냅샷이나 새 결제 승인일 분석으로 표현하지 않는다.
- [엑셀](../../../lib/admin/stats-workbook.server.ts)은 같은 날짜·모드·집계 단위·IP 조건과 비교 시트를 내보낸다. 조회 정보에 비교 방식·실제 KST 비교기간·윤년 보정 설명을 담는다. 기존 시트·순위 상한·숫자와 식별자 형식을 유지한다.
- 공유 모듈을 쓰는 [혜택 리포트 필터](../../../lib/admin/benefit-report.ts)는 직전 비교만 계속 지원한다. 전년 통계를 추가했다고 미승인 혜택 리포트까지 확대하지 않는다.
