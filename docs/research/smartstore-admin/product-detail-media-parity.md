# 상품 동영상·숏클립과 대표미디어 대조

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-13 로그인된 [스마트스토어 상품등록](https://sell.smartstore.naver.com/#/products/create)과 [상품상세 전시](https://sell.smartstore.naver.com/d/v2/display-config/product-detail)를 열람했다. 원본에는 파일을 업로드하거나 설정을 적용하지 않았다. 원본 화면 4개 (`output/smartstore-reference-20261012/store-media-reference/manifest.json`)에 캡처·DOM·SHA-256을 기록했다.

| 항목 | 원본에서 확인한 계약 | ICONS 구현 |
| --- | --- | --- |
| 상품 동영상 | 상품등록에서 영상과 20자 타이틀을 등록한다. 업로드 팝업은 최대 1분/1024MB와 여러 컨테이너를 안내한다. | 상품별 별도 영상 관리 화면에서 동영상 1개와 숏클립 1개를 등록한다. 타이틀은 각 1~20자다. |
| 대표미디어 | 이미지·동영상·숏클립 중 먼저 보여줄 형식을 선택한다. 해당 영상이 없으면 이미지가 먼저 나온다. | 동일한 세 가지 우선순위와 이미지 fallback을 제공한다. 기본은 이미지이며 영상은 재생 버튼으로 시작한다. |
| 숏클립 전시 | 직접 등록한 숏클립 또는 쇼핑라이브에서 자동 추출한 클립을 전시한다. | 직접 등록한 숏클립을 상세 갤러리와 선택적 별도 영역에 표시한다. 별도 영역은 기본 OFF이며 자산이 없으면 숨긴다. |
| 외부 서비스 | 네이버TV 채널 연동, 쇼핑라이브 자동 추출, GIF 자동 생성 안내가 있다. | 외부 네이버 계정 연동·라이브 추출·GIF 생성은 제공하지 않는다. 직접 영상 등록은 이 제외 범위에 포함하지 않는다. |

ICONS의 영상 수용 규칙은 **MP4, H.264 영상 1트랙, 선택 AAC-LC 음성 1트랙, 최대 50MB·60초·표시 메타데이터 가로/세로 1920px**다. 원본의 1024MB·다중 컨테이너 지원을 구현했다고 표시하지 않는다. 기존 이미지 업로드의 JPEG/PNG/WebP·5MB 계약과 분리한다. 숏클립에는 같은 검증을 적용하고 세로 영상을 권장한다.

브라우저는 파일을 전용 비공개 staging Storage로 직접 전송한다. 서버는 [MP4Box.js](https://github.com/gpac/mp4box.js) 2.4.1을 이용한 제한된 컨테이너/트랙/샘플 구조 검사와 메타데이터 제거 후 전용 공개 버킷으로 승격한다. 전체 코덱 디코드·재인코딩·악성코드 스캔을 수행하는 계약은 아니다. 실제 브라우저가 재생을 거절하거나 대기 시간이 초과되면 대표 이미지와 안내 문구를 보여준다.

상품별 영상 편집은 `catalog.manage`, 스토어 대표미디어 전시 설정은 `store.manage` 권한으로 분리했다. 상품의 구매·재고·이미지·KC 정보는 이 설정으로 바뀌지 않는다. 저장·정리·공개 반영의 실제 검증은 [구현·검증 기록](product-detail-media-implementation-qa.md)을 따른다.
