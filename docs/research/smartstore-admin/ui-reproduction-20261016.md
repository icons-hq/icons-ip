# 2026-10-16 스마트스토어 원본 기반 어드민 UI 정합화

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

기존 대화의 미완료 범위와 현재 코드를 확인한 뒤, 로그인된 Chrome의 스마트스토어센터를 읽기 전용으로 조사했다. 공통 셸과 홈·상품 조회/수정·상품 등록·주문·반품·상품문의·리뷰·고객문의의 표현 계층을 수정했다. **이번 결과는 전체 메뉴·상태·업무 기능의 1:1 이식 완료가 아니다.** 네이버 전용 서비스, 기존에 남긴 판매 5개·비판매 13개 정책 단위, 운영 배포는 완료 범위에 넣지 않는다.

관리자 전용 Pretendard Variable 1.3.9를 로컬 제공한다. 공식 배포본·라이선스·SHA는 `docs/licenses/pretendard-source.json`에 있다. 홈의 범용 그림문자 4개는 원본에서 수집한 SVG이며 `public/admin/seller-icons/source.json`에 출처와 해시를 기록했다. 네이버 로고·판매자 프로필·상품 사진·고객 정보는 앱 자산이나 fixture에 복제하지 않았다.

새로 추가된 작은 선택 글자와 상품 설정 선택 라벨에는 `--wc-admin-success-aa`를 적용했다. 선택 라벨 대비 5.20:1, 문의·리뷰의 900px 이하 입력 최소 44px를 확인했다. 공개 쇼핑몰 스타일은 바꾸지 않았다.

## REA 사용과 비교 근거

[morluto/rea](https://github.com/morluto/rea)의 `rea-agents@6.5.0`을 별도 임시 디렉터리에 설치하고 `compare-web-screenshots`를 실행했다. 프로젝트 의존성에는 추가하지 않았다. **캡처는 Chrome/CUA, 비교는 REA**가 수행했다. REA로 원본 계정의 동작을 실행하거나 데이터를 수집한 것으로 표기하지 않는다.

원본·구현은 PC 1440×1000, 모바일 390×844, DPR 1의 PNG다. 합성 fixture의 계정·수치·목록 수와 원본 계정은 다르며, 네이버 전용 메뉴도 다르다. 따라서 픽셀 차이는 기능 완성도나 동일화 백분율이 아니다. 채널 차이 임계값은 8이다.

PC 8쌍과 모바일 5쌍의 결과·입력 SHA는 최종 REA 비교 목록 (`output/smartstore-rea-ui-20261016/rea-comparisons-verified.json`)에 있다. `pair-*.png`는 왼쪽 원본/오른쪽 구현을 한 이미지에 배치한 검수 자료이고 `focus-*.png`는 서체·간격 확인용 확대 영역이다. 원본은 작은 화면에서 데스크톱 구조가 잘리는 상태였지만 ICONS는 모바일 메뉴·한 열 폼·표 내부 스크롤을 유지했다.

`source-returns-390.png`는 실제 1440×1000이므로 모바일 근거에서 제외했다. 해당 파일의 별도 JSON에 거절 사유를 기록했다. 결과가 없는 원본 목록, 저장 뒤 상태, 모든 옵션 조합까지 확인했다는 뜻은 아니다.

## 검증 한계와 남은 동일화

- 실행 중 로컬 Supabase/Docker가 없어 빌드는 `http://127.0.0.1:9`와 비밀이 아닌 placeholder를 사용하는 **비연결 컴파일·prerender 검사**로 수행했다. 운영/Preview 환경 변수 gate, DB/Auth/서버 액션 검증은 포함하지 않는다.
- 화면 검증은 실제 컴포넌트에 합성 데이터를 주입한 fixture다. 실제 관리자 로그인·DB 저장·환불·발송·엑셀 출력·실제 창고 WMS 수용을 재검증하지 않았다. fixture에서 계정 의존 쓰기와 일부 조회가 차단되는 안내는 그대로 보인다.
- 고객문의 하단 응대와 상품문의 대표 이미지·인라인 답변을 추가로 반영했다. 리뷰의 복수 선택 필터, 상품 등록의 모든 독립 입력 분기는 기존 데이터 계약과 차이가 있다. 현재 데이터/동작 계약을 유지한 화면 정합화와 추가 기능 이식을 구분한다.
- 상품문의 이미지는 기존 goods의 image_path/bg를 같은 RLS 조회에서 읽고 기존 공개 미디어 URL 규약을 따른다. 경로 정규화·이미지 없음·기존 이미지 배경 fallback과 목록 필터는 단위 검사로 확인했다. 실행 중 DB가 없어 실제 DB 응답으로 새 필드를 다시 조회하지는 못했다. [조회 API](https://supabase.com/docs/reference/javascript/select)·[공개 미디어 URL](https://supabase.com/docs/reference/javascript/storage-from-getpublicurl)과 현재 저장소 계약을 확인했으며 스키마·권한 변경은 없다.
- 원본의 전 메뉴·권한·로딩/오류·저장 후 상태를 전수 비교하지 않았다. 네이버 금융/배송/광고 서비스는 가장하지 않는다. 남은 일반 업무는 [기존 범위 분류](sales-remaining-scope.md)와 [README](README.md)를 따른다.
- 원본 스마트스토어 저장·발송·환불, 운영/Preview 배포, 운영 DB 변경은 수행하지 않았다. 남양주·김포 엑셀 운영과 부분취소/부분반품 제외 결정은 유지했다.

로컬 검수 화면: `http://127.0.0.1:4319/?view=overview`. 실행 명령은 `npm run admin:visual-fixture`다. 화면의 수치는 합성 데이터이며 실제 운영 현황이 아니다. 인라인 응대 후속의 Chrome 검증 (`output/smartstore-rea-ui-20261016/cs-inline-browser-qa.json`)과 최종 실행 요약 (`output/smartstore-rea-ui-20261016/final-verification.json`)을 함께 확인한다.
