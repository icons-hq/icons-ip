# 스토어 공통·상품목록 표시 설정 대조

2026-10-13 원본 로그인 화면을 추가 열람했다. `store-display-settings-reference/manifest.json`에 URL·화면·SHA-256을 보존했다. 적용하기·상품 담기·실제 저장은 누르지 않았으며 미리보기 선택은 원래 값으로 돌리거나 새로고침으로 폐기했다.

## 공통 테마와 홈 검색

[공통관리](https://sell.smartstore.naver.com/d/v2/display-config/common-config)는 14개 컬러 테마를 제공한다. 확인값은 `#292b2c`, `#666668`, `#6b90dc`, `#654f43`, `#72d887`, `#20c5b0`, `#ff9dc5`, `#fc5296`, `#e96061`, `#ee4a44`, `#af7de7`, `#fcdf33`, `#f79a49`, `#eae1d8`이다(증거01). 현재 선택은 마지막 베이지이며 선택 변경이나 적용은 하지 않았다.

[홈 편집기](https://sell.smartstore.naver.com/d/v2/display-config/home)의 공통 GNB는 기본형/컬러형과 로고형/텍스트형, 모바일·PC 로고를 제공한다(02). 기존 ICONS에는 기기별 로고가 연결되어 있지만 공통 테마와 GNB 컬러형은 없다.

‘스토어 및 셀러 정보’의 **스토어내 상품검색은 홈 본문 검색 배너**다. 체크하지 않은 상태에도 GNB 검색 아이콘은 표시된다. 체크 미리보기에서는 소개·알림받기 영역 다음에 검색 입력 모양의 배너가 추가됐다(03–04). GNB 검색 숨김 기능으로 해석하면 원본과 다른 동작이 된다. 검색 체크는 다시 해제하고 다른 페이지로 이동했다.

같은 패널에는 소개, 스토어등급, Today 방문수, PC Total 방문수, 모바일 데이터랩이 있다. 등급·방문수는 실제 데이터 산정·노출 조건이 별도 필요하므로 단순 토글만으로 구현 완료로 처리하지 않는다.

## 상품목록

[상품목록 설정](https://sell.smartstore.naver.com/d/v2/display-config/product-list)의 기본 선택은 정사각형·대표이미지만·PC 상세설명/BEST·NEW 태그 표시, 컬러칩/장바구니 숨김이다(05). 전체 적용은 하지 않았다.

| 설정 | 확인한 계약 |
| --- | --- |
| 썸네일 | 정사각형 또는 세로직사각형. 세로 미리보기의 컨테이너는 109×136.25px, 즉 4:5이며 정사각 이미지 자체는109×109px로 여백을 유지했다. |
| 이미지 전시 | 대표 한 장 또는 대표+추가 최대10장. 추가 이미지 선택을 미리보기에서 확인했다. 이미지의 실제 넘김 동작 전체는 미확인이다. |
| 컬러칩 | 일반상품은 표시 선택 가능, 그룹상품 컬러칩은 정보 전달을 위해 항상 표시된다는 도움말. 현재 상단 상품에서는 체크 후에도 실제 컬러칩 데이터가 보이지 않았다. |
| 상세설명 | PC만 표시하며 상품상세의 상세정보 텍스트 일부를 사용한다. |
| 장바구니 | 표시 체크 후 미리보기에 상품별 담기 버튼이 생겼다(07). BEST 카테고리·쇼핑스토리 관련상품·리뷰이벤트 대상상품은 제외한다. 실제 담기는 실행하지 않았다. |
| 태그 | BEST/NEW 표시 선택. 가격/할인/품절 전체 표시를 끄는 설정은 아니다. |

도움말의 적용 범위는 카테고리·BEST·NEW·N배송·FOR YOU·리뷰이벤트·쇼핑스토리와 스토어 검색결과·최근본상품·찜한상품·배송비 절약상품이다. 렌더된 도움말 DOM 텍스트는 `product-list-help.txt`에 보존했다. 외부 전용 서비스는 ICONS에 있는 공개 표면의 동일 목적과 구분한다.

06–07에서 세로/추가이미지·컬러칩·담기 미리보기를 확인한 뒤 새로고침했다. 정사각형·대표이미지만·컬러칩/장바구니 숨김으로 돌아온 것을 다시 읽었다. 실제 상품·스토어 설정은 저장하지 않았다.

## 구현과 검증 상태

2026-10-13 `/admin/display/settings`의 공통·상품목록 독립 원장과 공개 소비자를 구현하고 실제 저장·재조회했다. [구현 검증 보고](store-presentation-implementation-qa.md)에 SQL·경합·PC/390px·원복 증거를 정리했다.

- 공통 테마는 원본 14색과 기존 ICONS 기본색을 제공한다. GNB 기본형/컬러형과 홈 본문 검색 배너를 각각 공개 헤더/Home에 연결했다. 공개 검색 UI는 도메인 용어인 굿즈를 사용한다.
- 상품목록은 정사각/4:5, 대표 또는 최대10장, 명시 색상칩, PC 설명, 담기, BEST/NEW 태그를 저장한다. 일반목록·NEW·BEST·검색·찜·관련상품에 적용하며 홈 큐레이션과 어드민 미리보기는 별도 디자인을 유지한다.
- 스토리 섹션이 저장한 정사각/세로 비율은 전역 비율보다 우선한다. 원본의 전역/섹션 충돌 처리 전체는 확인되지 않아 이 우선순위는 ICONS 정책으로 명시했다.
- 색상칩은 상품별 최대20개, 이름1~30자·고정6자리 hex를 직접 저장한다. 옵션명으로 색을 추측하지 않으며 재고·옵션을 바꾸지 않는다. 해당 개수/이름 상한은 ICONS 정책이다.
- 공개 메타데이터는 실제 goods와 IP의 공개/보관/판매제한 게이트를 다시 검사해 최대9장 추가경로·최대240자 텍스트·등록색만 반환한다. HTML 본문은 태그/script/style을 제거하고 엔티티를 한 번만 해석한다. 일반 텍스트는 원문 문자를 유지한다.
- 담기는 기존 장바구니·옵션 재고 검사를 재사용한다. 여러 옵션·직접입력은 상세 선택, 최소수량2개 이상은 상세 수량 선택으로 보낸다. BEST/스토리에는 담기를 표시하지 않는다.
- common/listing은 서로 독립 revision이며 현재 store.manage, 색상칩은 catalog.manage를 RPC에서 재검사한다. operation UUID 재시도·감사·충돌·권한회수와 경합을 확인했다.

상품상세의 띠배너·상단 리뷰 요약·자동 유사/함께구매/카테고리인기/스토어인기는 [별도 상세 표시 단위](product-detail-presentation-implementation-qa.md)로 구현·로컬 검증했다. 대표이미지 우선순위와 나머지 상세 모듈, 홈 일반 자유상품 디자인, 전시 전용 분류는 남아 있다. 운영 배포와 네이버 원본 저장은 하지 않았다.
