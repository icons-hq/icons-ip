## 사용자 확정 정책

- 반품/교환비, 구매확정 기간, 중복·배송비 쿠폰, 등급 적립금, BEST 리뷰 보상은 관리자 설정으로 제공한다. 값을 확정하기 전 자동 청구·지급·확정은 꺼둔다.
- 같은 구매자·수취인·주소·출고지의 발송 전 주문을 합포장할 수 있다. 기존 주문별 결제금액·배송비는 유지하며 중복 배송비를 자동 환급하지 않는다.
- 회원 방문·영상 시청은 별도 선택 동의를 받은 회원만 수집한다. 원시 이력 보존은 90일이다. 동의 전에는 기존 익명 분석 계약만 적용한다.
- 주문제작은 운영자가 제작 시작·완료를 기록하고 상품별 납기를 설정한다. 제작 시작 후 취소도 자동 거절하지 않고 접수 후 심사한다.
- 배송없음 상품에는 방문수령·직접전달 외에 디지털 콘텐츠 제공을 포함한다. 보호된 파일 다운로드부터 구현하며 결제 확인 후 로그인한 구매자에게 제공하고 환불 시 접근권한을 회수한다. 다운로드 후 취소 요청은 관리자 심사로 처리한다.
- 새 설치비·직접배송·화물·퀵 비용은 주문서에서 확정해 선결제한다. 기존 택배 착불 정책은 유지한다.
- 배송 중 반품/교환 접수를 허용하되 실물 회수 완료 전 환불·재배송을 막는다. 회수 시작 전 전체 주소 변경을 허용하고, 운임 차액이 생기면 금액 처리 정책을 설정하기 전에는 변경 확정을 막는다.
- 기존 부분취소·부분반품 제외, 남양주·김포의 창고 엑셀 운영, 운송장 발급·회수·추적 API 자동화 제외를 유지한다.

위 정책의 확정은 구현·검증 완료를 의미하지 않는다. 금액 원장·권한·멱등 처리와 고객/관리자 화면을 연결한 뒤 해당 단위를 완료로 기록한다.
