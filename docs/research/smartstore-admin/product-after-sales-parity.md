## 원본에서 확인한 범위

[스마트스토어 A/S 템플릿 관리](https://sell.smartstore.naver.com/#/products/template/as)의 등록 모달과 도움말을 읽었다. 전화번호는 필수 20자, A/S 안내는 필수 1,300자, 판매자 특이사항은 선택 1,300자다. 전화번호는 상품정보제공고시의 A/S 책임자·전화번호와 독립된 항목이고, 판매자 특이사항은 상품 상세에 표시하며 모바일에서는 구매 추가정보에서 확인한다. 네이버 원본에 등록·수정·삭제를 실행하지 않았다.

- 원본 관찰값·SHA (`output/product-templates-qa-20261014/source-manifest.json`)
- 전화번호 도움말 화면 (`output/product-templates-qa-20261014/source-as-phone-help.png`)
- 등록 폼과 판매자 특이사항 도움말 (`output/product-templates-qa-20261014/source-as-help.txt`)

## ICONS 구현 계약

- `상품관리 → A/S 템플릿 관리`에서 전화번호·안내·판매자 특이사항을 등록·수정·검색·보관·복구한다. 사용 중/보관됨을 나누고 페이지당 20건을 조회한다. 마지막 페이지의 마지막 항목을 보관하면 남은 페이지로 돌아간다.
- 상품 수정의 `A/S 안내·판매자 특이사항`은 기본 상품 저장과 독립적이다. 템플릿 선택은 세 항목 복사이며 상품의 별도 `안내 저장`을 눌러 반영한다. 이후 템플릿 수정·보관으로 이미 저장한 상품 안내가 바뀌지 않는다.
- 전화번호·안내는 함께 입력한다. 판매자 특이사항만 입력하거나 전화번호만 입력하는 부분 저장은 거절한다. 상품에 한해 `안내 해제`가 세 항목을 모두 비우고 공개 안내를 숨긴다. 해제에도 버전과 감사 이력을 남긴다. 템플릿의 필수 항목 규칙은 유지한다.
- 전화번호 20자, 안내·특이사항 각 1,300자를 Unicode 문자 수로 검사한다. 여러 줄 안내의 CRLF/CR은 LF로 정규화하며 일반 텍스트로 출력한다. 스크립트나 HTML을 실행하지 않는다.
- 기존 `notice_as_manager`·`notice_as_contact`는 변경하지 않는다. 공개 상품 상세 하단의 A/S 안내와 판매자 특이사항은 기존 고시정보와 별도로 표시한다. 상품/IP가 공개·미보관 상태이고 판매 제한이 없는 경우에만 공개 RPC가 세 항목을 반환한다. 빈 상품 안내는 반환하지 않는다.
- 현재 `catalog.manage` 권한을 확인한 후 기대 버전과 요청 ID를 검사한다. 동일 요청은 같은 저장 결과를 반환하고, 다른 오래된 저장은 충돌로 차단한다. 권한이 회수된 계정은 과거 요청을 다시 확인하는 경우에도 거절한다.
- 응답 유실 시 입력을 잠그고 같은 요청 결과를 확인한다. 충돌 시 입력을 보존하고 명시적 재조회 후 편집을 재개한다. 늦은 초기 조회가 최신 필터·재조회·저장 결과를 덮지 않는다.
- 상품 복사는 저장된 안내를 독립된 초안 상품에 복사한다. 기존 복사 함수의 소유권을 유지하고 새 테이블 접근은 별도 내부 함수로 제한한다.

## 검증 경계

`catalog.manage`가 없는 역할로 로그인된 별도 브라우저 호스트는 확인되지 않아 브라우저의 직접 URL 거절은 실행하지 않았다. 계정이나 권한을 새로 만들거나 바꾸지 않고 SQL·서버 액션 거절, 내비게이션·접근 매핑과 페이지 가드로 검증했다.

네이버 원본의 등록·수정·삭제 결과는 관찰하지 않았다. ICONS의 보관·복구·동시 수정·감사·안내 해제는 기존 운영 계약을 따른다. 이 기능은 상품별 안내와 템플릿이며 법정고시 자동 작성, 고객 A/S 접수·처리, 반품 정책 변경이나 환불 실행을 포함하지 않는다. 운영 DB·Preview·production 배포는 실행하지 않았다.
