# 상품상세 구매·탐색 원본 대조

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-13 로그인된 스마트스토어 `상품 상세 구성`의 구매유도·배송비 절약·관심상품 영역과 도움말을 읽었다. 원본 설정은 적용하지 않았고 임시 선택은 새로고침으로 폐기했다. 원본 화면 5개 (`output/smartstore-reference-20261012/store-detail-experience-reference/manifest.json`)와 대표이미지 도움말 (`output/smartstore-reference-20261012/store-detail-reference/representative-help.txt`)이 근거다.

| 영역 | 원본에서 확인한 동작 | ICONS 구현 |
| --- | --- | --- |
| 구매자수 | 기준 인원 10~1,000명. 오늘/최근 1주가 부족하면 6개월·1년 확인. 2년 누적 옵션은 입력 기준과 무관하게 1명 이상이면 표시. 기간 선택 UI는 없음. | 서로 다른 확정 구매자를 계산한다. 한국 시각 오늘 → 오늘 포함 7일 → 6개월 → 1년 순서로 최소 충족 기간을 표시하고, 별도 2년 옵션은 1명 이상일 때 표시한다. |

| 베스트·신상품 | 최근 3일 판매건수와 최근 7일 등록상품 자동 선정. 원본 동률은 누적 판매·인기도 등을 사용한다. | 오늘을 제외한 한국 시각 직전 3일의 확정 판매수량 상위 10개, 동률 상품코드순으로 실제 순위를 표시한다. 신상품은 등록 시각부터 7일간이다. 원본 비공개 인기도와 동일한 순위라고 하지 않는다. |

| 관심상품 | 재구매·장바구니·찜·최근본상품. 해당 목록이 없으면 숨김. 상세와 모아보기 진입점을 함께 설정. | 본인 서버 원장의 재구매·장바구니·찜, 브라우저에서 계정별로 보관한 최근 본 굿즈를 연결한다. 빈 종류는 숨기고 현재 상세의 굿즈는 제외한다. 독립 `/interests`와 전체 메뉴를 같은 표시 설정으로 제어한다. |

구매 실적은 서버 승인 근거와 결제/주문의 사용자·금액 일치를 확인하며 완료 취소·반품 주문을 제외한다. 개인 식별자와 주문 정보는 공개 RPC에서 반환하지 않는다. 원본의 구매자수 대비 리뷰수 대체 문구는 사용하지 않는다. 구매와 리뷰 수는 서로 다른 수치로 유지한다. 원본의 약 5초 메시지 연출 대신 이미지 하단에서 읽을 수 있는 실적 문구를 표시한다.

배송비 비교는 현재 굿즈의 선택과 후보만 기준이다. 다른 장바구니 항목, 추가구성, 지역 추가배송비와 쿠폰을 합치지 않으며 이 범위와 주문서 최종 확인을 공개 문구로 설명한다. 같은 출고지의 정책 배송 후보를 하루 동안 안정된 순서로 최대 50개 검토한다. 임의의 추천액이나 주문·재고 변경은 만들지 않는다.

재구매 목록은 최근 2년의 확정 주문 2건 이상이다. 최근 본 굿즈는 계정 UUID 또는 비회원 구분키 아래 상품코드 최대 30개만 브라우저에 저장한다. 분석·마케팅 원장으로 전송하지 않고 표시 설정이 꺼져 있으면 새 기록을 남기지 않는다. 로그인 전환 시 기존 계정 목록과 늦게 도착한 응답을 폐기한다.
