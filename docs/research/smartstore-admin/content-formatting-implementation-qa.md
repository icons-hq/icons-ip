# 상품·스토리 본문 서식

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-14. 상품 HTML의 일반 서식과 공용 정제·공개 렌더를 구현했다. 스토리 정제기에도 같은 허용 목록을 적용했으며 **스토리 편집 UI와 개인 템플릿은 후속 작업 중**이다.

원본 인용 선택 (`output/smartstore-reference-20261012/product-editor-06-quote-styles.jpg`), 구분선 선택 (`output/smartstore-reference-20261012/product-editor-07-divider-styles.jpg`), 스토리 도구 모음 (`output/smartstore-reference-20261012/marketing-story-reference/09-story-editor-html.png`)을 직접 보았다. 인용5종·구분선8종과 정렬·글자 크기·강조 도구의 존재를 확인했지만 원본 저장 결과나 모든 수치·CSS는 확인하지 않았다. 아래 값·그림은 ICONS의 제한된 문서 서식이다.

## 저장·렌더 계약

[공유 계약](../../../lib/content-format.ts)은 정렬 `left/center/right`, 크기12·14·16·20·24·32·40px, 인용 `line/quotes/bubble/note/frame`, 구분선 `line/short/bold/chevron/diamond/dots/slash/vertical`만 허용한다. 정렬·크기는 문단·제목·span 등 지정된 문서 태그에서만, 인용은 blockquote에서만, 구분선은 hr에서만 허용한다. 값은 제한된 `data-icons-*` 속성으로 저장한다.

상품·스토리의 저장·미리보기·공개 HTML 정제기가 같은 목록을 사용한다. 임의 CSS·class·이벤트·지원하지 않는 속성과 값은 계속 제거한다. 기존 이미지 검증과 상품의 안전 링크/스토리의 공개 내부 링크 규칙은 바뀌지 않는다. 공개 서식은 `content-format.css`가 두 문서 표면에서만 소유한다. 기존 일반 문서의 속성 없는 출력은 유지한다.

상품 `글자 서식`은 선택한 HTML에서 텍스트를 가져와 정렬·크기·굵게/기울임/밑줄/취소선을 지정한 한 문단으로 바꾼다. 해당 선택의 이미지·기존 태그가 바뀐다는 안내와 미리보기를 제공한다. 원본 소스를 유지하는 별도 코드 입력도 그대로 사용한다. 이는 문서 전체를 시각 편집기로 전환하는 기능은 아니다.

도구는 HTML 태그·인용부호가 있는 속성·주석·문자 참조 중간에 삽입하지 않는다. 양쪽 선택 지점은 여는 태그의 이름뿐 아니라 원문 위치까지 같은 요소 안이어야 한다. 형제 문단 일부를 가로지르는 선택, 문단/인라인 태그 안의 새 블록, 기존 링크 안의 새 링크는 거부한다. 문단 전체 또는 태그 밖에서 삽입하며 오류 시 원문은 그대로다. 이 검사는30,000자 이하의 편집 위치 보호용이며 실제 HTML 정제기를 대신하지 않는다. 기존 계정·세션·폼·저장/reset 수명 검사는 유지한다.

## 검증

상품 실제 QA manifest (`output/content-format-qa-20261014/manifest.json`)에 구현 소스·입력·DB 저장값·공개 DOM·캡처를 기록한다. 관련5파일135테스트와 scoped lint를 통과했다. 선택 경계 보강 후 scoped 타입검사도 통과했다. 저장·스토리 동작·가이드까지 넓힌11파일은171개가 먼저 통과했고, 진행 중인 카테고리 신규 가이드 누락1건을 보완한 뒤 해당14개 검사를 다시 통과했다. 전체 작업 트리 최종 빌드는 별도 단계다.

- 기존 문단 전체를 선택해 가운데24px·굵게·밑줄·두 줄 텍스트로 바꾸고, 모달 계산 스타일과 HTML을 확인했다.
- 인용5종과 구분선8종을 실제 UI로 넣었다. 인용 기본 왼쪽 선도 미리보기와 저장값 모두 같은 속성을 사용하고20px/24px 여백으로 표시한다.
- 링크의 `example.com` 부분만 선택해 서식 삽입을 시도하면 오류를 표시하고 원래 주소와 본문이 정확히 보존됐다.
- 실제 상품 저장·재조회 후 공개 상세에서 center/24px, 인용5개, 구분선8개를 확인했다. 변경된 DB 필드는 `description`·`updated_at`뿐이며 가격·게시시각·KC 검토값은 같았다.
- 390px 관리자 모달과 공개 본문을 직접 보았다. 공개 문서 client/scroll380/380px, 본문348/348px로 가로 넘침이 없었다. 중간 스크롤 캡처는 최종 근거에서 구분했다.
- 합성 상품1/IP1·옵션·KC·운영 알림만 정리하고 해당 검수 탭과 viewport를 닫았다. 이미지 업로드·실제 메시지·운영 배포는 하지 않았다.

개인 템플릿, 스토리 편집 UI, 외부 서비스 글감·장소 검색, 네이버 전용 자산은 이 상품 검수 완료에 포함하지 않는다.
