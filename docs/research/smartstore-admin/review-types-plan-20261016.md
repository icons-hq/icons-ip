# 한달사용·재구매 리뷰 구현 근거

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-16 공식 도움말 확인:

- [상품/한달사용 리뷰](https://help.sell.smartstore.naver.com/faq/content.help?faqId=3422): 구매확정 기준 일반 30일, 한달사용 31~90일이고 주문 1년 제한을 적용한다. 네이버 지급 포인트는 이식 대상에서 제외한다.
- [재구매 표시](https://help.sell.smartstore.naver.com/faq/content.help?faqId=12609): 리뷰 작성 시 180일 안의 배송완료 이력이 있는 동일 상품번호 기준이다. 그룹상품 전체를 동일상품으로 취급하지 않는다.
- [총 평점](https://help.sell.smartstore.naver.com/faq/content.help?faqId=4261): 공개된 일반/한달사용 리뷰를 함께 집계하며 블라인드는 제외한다.

현재 ICONS 일반 리뷰는 배송완료 후 90일, 주문·상품·구매자별 1건이다. 신규 기간 정책은 사용자 승인대로 관리자 설정/기본 꺼짐으로 제공하며 기존 일반 리뷰의 권리를 임의로 줄이지 않는다. 한달사용 기간의 기산점/시작/마감과 적용 범위를 명시하고, 신규 보상 여부는 기존 보상 정책과 구분해 명시적으로 설정한다.

## 구현 계약

- 일반/한달사용을 별도 유형으로 저장하고 주문·상품·구매자·유형별 1건으로 제한한다. 일반 리뷰의 기존 90일 계약은 유지한다. 한달사용 리뷰는 일반 리뷰를 먼저 작성하지 않아도 작성할 수 있다.
- 한달사용 정책은 기본 꺼짐이다. 관리자가 배송완료/거래확정 기산점, 시작·마감, 주문 경과 제한을 설정한다. 작성 시점의 자격과 마감 시각을 저장하여 기존 리뷰의 수정 기한이 후속 설정 변경으로 달라지지 않는다.
- 재구매 여부는 작성 당시 180일 안에 배송 완료된 같은 상품의 다른 정상 결제 주문으로 계산한다. 과거 자료가 없는 기존 리뷰는 미확인으로 남기며 그룹의 다른 상품 이력으로 추정하지 않는다.
- 공개 목록·평점은 두 유형을 함께 집계하고 유형별 조회를 지원한다. 관리자 필터·상세·암호화 엑셀과 고객 작성/수정/내 리뷰에도 유형과 재구매 여부를 표시한다.
- 한달사용의 이벤트·BEST 보상 자격은 별도 기본 꺼짐이다. 켜려면 마케팅 권한과 명시적 설정 근거가 필요하며 실제 금액은 기존 보상 정책이 결정한다.

## 검증

- 격리 로컬 DB의 유형·작성/수정 기간·평점·환불/블라인드·보상 차단 및 명시적 지급·권한 SQL 검사 통과.
- 동시 생성 16회에서 유형별 1건, 정책 변경과 작성 경합 9회에서 정책 CAS 1회 반영 및 현재 설정에 맞는 작성 결과를 확인했다.
- 관련 앱 테스트 168개, 타입 검사 통과. 이후 공개 리뷰 안내 문구를 새 유형 계약에 맞춰 수정했으며 관련 주문/거래/리뷰 검사 59개도 통과했다.
- 실제 Chrome에서 정책 저장, 한달사용+재구매 필터, 암호화 엑셀 18열/1행 다운로드를 확인했다. 합성 구매자 계정으로 한달사용 4점 리뷰를 등록해 재구매 배지와 공개 총 3건/평균 4.67점을 DB·화면에서 대조했다. PC 및 390px 화면을 직접 검사했다.
- 근거는 `output/smartstore-full-admin-20261016/review-types-*`, `local-review-month-*`에 있다. 운영 DB·고객 리뷰·보상 정책을 변경하지 않았다.
