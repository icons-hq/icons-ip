# 빈 상품등록 양식 원본과 ICONS 엑셀 비교

이 문서의 `output/`·임시 경로는 내부에 보존한 로컬 검수 근거의 파일 참조이며, 해당 자료와 비공개 원본 캡처는 저장소에 첨부하지 않는다.

2026-10-14 조사 당시 ICONS v5와 비교했다. 이후 직접입력형 시트를 v6에 구현한 결과는 [별도 계약·검증](goods-custom-input-workbook.md)을 따른다. [스마트스토어 상품 일괄등록](https://sell.smartstore.naver.com/#/products/bulkadd)의 조회 결과가 없는 화면에서 신·구형 **빈 등록 양식**만 내려받았다. 기존 상품·주문·고객 자료의 내보내기와 네이버 업로드·등록은 실행하지 않았다. 원본은 로컬 조사 근거로 보존하며 앱 양식이나 테스트 데이터로 배포하지 않는다.

## 실제 파일 확인

| 구분 | 신형 | 구형 |
| --- | --- | --- |
| 다운로드 이름 | `ExcelSaveTemplate_20260324.xlsx` | `ProductTemplate_260324.xls` |
| 바이트 | 24,873 | 68,608 |
| 시트 | `일괄등록` 1개 | `ver.2.1` 1개 |
| 열 | A:CO, 93개 | A:BY, 77개 |
| 행 구성 | 1행 영역, 2행 제목, 3행 필수 여부, 4행 예시, 5~6행 작성 안내 | 1행 제목, 2행 필수 여부, 3행 작성 안내, 4행 예시. 서식은 103행까지 있으나 5행 이후 값 없음 |
| 필수 표시 | 필수 7, 조건부 39, 비필수 47 | 필수 18, 조건부 28, 비필수 31 |

신형의 필수 7개는 카테고리·상품명·판매가·재고·대표 이미지·상세설명·원산지 코드다. 이것은 **양식의 표시**를 집계한 값이다. 카테고리·배송·A/S 등 조건에 따른 서버 등록 검증을 실제 실행한 결과는 아니다. 신형에는 목록 등 유효성 검사 17개가 있고 수식은 없다. 신형 안내는 제출 시 3~6행을 제거하도록 되어 있다.

- 원본 SHA-256: 신형 `1868ee9824d79bca49ea4c1586109d76bb6a4512f468a81d0e93a756b2d9ab2d`, 구형 `e0294b1957bac15821594e0f82a6d994dd8f565af6f4698e74fb526d8d7154b4`.
- 다운로드 출처·파일 해시 (`output/smartstore-blank-template-reference-20261014/sources.json`), 시트·열·필수 표기 구조 (`output/smartstore-blank-template-reference-20261014/structure.json`), 양식 선택 화면 (`output/smartstore-blank-template-reference-20261014/01-template-choice.png`).
- 읽기 전용으로 신형은 `openpyxl`, 구형은 임시 경로의 `xlrd 2.0.2`로 열었다. 원본 바이트를 수정하거나 재저장하지 않았으며 검사 후 해시가 그대로임을 확인했다.

## 입력 계약 차이

| 항목·원본 위치 | 원본에서 확인한 내용 | 현재 ICONS v5와 다음 범위 |
| --- | --- | --- |
| 옵션 — 신형 M2:Q5, 구형 BC1:BG3 | 최대 3축. 셀 안에서 축은 줄바꿈, 값은 쉼표로 구분. 조합형 가격·재고는 첫 축 값을 기준으로 같은 조합에 반복 | 3축을 이미 지원한다. 옵션마다 한 행에 독립 가격·재고를 적는 ICONS 계약을 유지한다. 원본의 첫 축 반복 규칙으로 축소하지 않는다. |
| 직접입력 — 신형 R2:R5, 구형 BC3:BD3 | 신형은 최대 5개 이름을 독립 열에 기입. 구형은 옵션 형태의 입력형 분기를 사용 | 조사 당시 상품 편집만 지원했다. 이후 v6 별도 시트로 이름·사용·삭제·전체 해제와 기존 ID/버전 보존을 구현하고 실제 저장까지 검증했다. |
| 이미지 — 신형 W2:Y5, 구형 L1:N3 | 대표·추가 최대 9개·HTML 상세. 신형은 URL/파일명과 추가 이미지 줄바꿈, 구형은 파일명과 쉼표 구분 | 대표·추가 9개·상세, URL/ZIP, HTML을 이미 지원한다. GIF/BMP 등 원본 허용 형식을 기존 JPEG/PNG/WebP 정책으로 무조건 넓히지 않는다. |
| 카테고리·원산지 — 신형 B2:B5, AD2:AG5 | 네이버 카테고리 코드와 원산지 코드, 수입사·복수 원산지·직접입력 분기 | ICONS 자체 대표/추가 카테고리 코드와 제조국 문자열을 사용한다. 국가·지역명 도우미는 한국어 명칭 입력용이다. 네이버 고유 코드 어댑터와 국내 상세지역은 별도다. |
| 고시 — 신형 AY2:BC5 | 템플릿 코드가 개별 값보다 우선. 공란에는 원본의 기본 문구를 채우는 항목이 있음 | ICONS의 직접 입력 우선 고시 프리셋, 필수 고시·KC 검토 규칙을 유지한다. 원본 공란 기본값을 KC 근거 또는 실제 고시 확인으로 간주하지 않는다. |
| A/S — 신형 BD2:BG5 | A/S 템플릿 또는 전화·안내·판매자 특이사항 | 상품별 독립 안내와 템플릿은 구현되어 있으나 v5 상품 시트의 고시 A/S 항목과는 별개다. 독립 버전·저장 경계를 검토한 후 엑셀로 연결한다. |
| 사이즈 — 신형 CL2:CO5 | 상품군, 사이즈명, 측정 항목별 값, 등록된 착용모델 참조. 모델 필드는 일반 상품 모델명이 아님 | 고시 `크기`와 별개인 [범용 안내표·복사용 템플릿](goods-size-chart-proposal.md)을 수동 편집과 공개 표시로 구현했다. [상품 엑셀 v7의 사이즈 안내 시트](goods-guidance-workbook.md)로 왕복 편집·누락 보존·표시 중지·충돌/재시도를 구현하고 실제 Chrome·DB·파일 재조회를 검증했다. 착용 모델 관리·AI 추출과 네이버 상품군 사전은 포함하지 않는다. |
| 일반 상품속성 | 두 파일 모두 카테고리 동적 상품속성 정의·값을 담는 열은 없음 | ICONS 상품속성 엑셀 편집은 별도 사용성 확장 후보이며, 이번 원본 파일에 있는 기능이라고 주장하지 않는다. |
| 할인·포인트·부가세·단위가격·도서·채널 조건 | 원본 전용 거래/노출 정책과 업종별 조건을 포함. 신형 BJ:BK는 작성 안내상 사용 불가 | 기존 ICONS의 기간 할인·결제·적립 정책과 분리한다. 열 존재만으로 신규 금전 정책을 자동 이식하지 않는다. |

ICONS v5는 상품 85열, `상품`·`KC 검토`·`작성 안내` 시트다. 상품 4행이 제목이며 5행부터 옵션마다 한 행을 읽는다. 파일당 500옵션행/2MB, v3·v4 읽기, 3축 상품의 구형 파일 차단, 검증 미리보기와 상품별 원자적 적용을 유지한다. 근거는 [양식 계약](../../../lib/admin/goods-workbook.ts), [파일 처리](../../../lib/admin/goods-workbook-file.ts), [조회·내보내기](../../../lib/admin/goods-import.server.ts)다.

원본 파일 형식을 그대로 수용하는 어댑터는 이번 범위가 아니다. 다음 작업은 [직접입력형 옵션의 엑셀 편집 계약](goods-custom-input-workbook.md)을 따른다.
