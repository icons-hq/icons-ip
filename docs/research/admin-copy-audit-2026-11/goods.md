## GOODS (상품 편집)

범위: 상품 등록·수정 화면의 패널, 상품 상세 연출, 관련 서버 액션·lib 문구. `components/admin/GoodsOptionEditor.tsx`는 메인 담당이라 건드리지 않았다. 모든 수정은 문구·표시만 바꿨고 data-* 속성·상태 값·함수·저장 값·올릴 때 읽는 엑셀 머리글은 그대로다.

공통으로 맞춘 말:
- 결과를 모를 때: '저장됐는지(처리됐는지) 확인하지 못했습니다' + 화면에 있는 버튼 이름('같은 요청 결과 확인', '처리 결과 조회', '진행 내역 확인', '같은 요청으로 결과 확인', '저장 결과 확인') + '같은 요청은 두 번 저장되지 않습니다'(코드에서 같은 operationId로 다시 보내는 것 확인).
- 세션: '로그인한 계정이 바뀌었거나 다시 로그인했습니다. … 새로고침해주세요.'
- '초안'(게시 상태가 아닌 뜻): 기간 할인·복수구매 할인·확장 배송비의 draft 상태 → '대기'(가격·결제에 반영 안 함), active → '적용'/'사용'.
- KST → 한국 시각, 미설정 → 정하지 않음/선택 안 함/없음, 할당 재고 → 재고수량.
