## ORDERS (주문·배송·정산)

운영팀이 매일 쓰는 발송 흐름(출고지시 내보내기 → 창고 회신 → 운송장 등록 → 배송완료)의 오류는 '무엇이 문제인지 + 다음 행동(새로고침·어느 버튼·누구에게)'을 붙였다. 결과를 모르는 경우(저장됐을 수 있음)는 화면에 실제로 있는 확인 버튼 이름을 [ ]로 적었다. 창고 회신 양식(김포 21열·남양주 송장양식·ICONS 표준 양식)의 머리글과 올릴 때 읽는 열 이름은 바꾸지 않았다.
