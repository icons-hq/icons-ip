# linefriendssquare.com 재현 스펙 — 08. 기능 총람과 채택 티어

> [ADR-0011](../../adr/0011-lfs-storefront-redesign.md)의 T-A/T-B/T-C 분류를 기능 단위로 전개한다. "LFS 동작"은 01~07 문서의 실측 요약이고, "DB"는 신규 마이그레이션 필요 여부다.

## T-A — 표면과 함께 구현 (리디자인 단계 내)

| # | 기능 | LFS 동작 요약 | ICONS 현황 | DB |
|---|---|---|---|---|
| A1 | 필터 사이드바 | 200px 사이드바: 브랜드/상품타입/가격 듀얼 슬라이더, 적용 칩 없이 카운트 피드백, 모바일 바텀시트(지연 적용) | 없음 | 불필요 (IP=브랜드, `goods.type`=타입, 가격 실측) |
| A2 | 정렬 | 셀렉트 9종(컬렉션) / 3종(검색), 컬렉션별 기본값 상이 | 없음 | 불필요 |
| A3 | NEW/SALE 배지 | 정보영역 인라인 뱃지(11/600, tint bg), 메타필드 기반 | `goods.badge` 문자열 존재 | **필요**: 상품 할인(`compare_at_price`)·배지 정규화 |
| A4 | SOLD OUT 오버레이 | 목록 카드 하단 1/3 밴드, PDP는 CTA 교체 | `stock` 상태 존재, 표기 상이 | 불필요 |
| A5 | 장바구니+바로구매 2CTA | 27:73 비율, 바로구매는 카트 우회 | 장바구니 단일 | 불필요 (주문 생성 경로 재사용) |
| A6 | 모바일 고정 구매바 + 플로팅 미니 구매바 | 72px 검정 풀폭 상시 / 데스크톱 스크롤 시 우하단 미니 바 | 없음 | 불필요 |
| A7 | 공지바 | 이미지 스트립 1장(스케줄 노출), 닫기 없음 | 없음 | **필요**: `home_curations` kind 확장 |
| A8 | 온라인 팝업 디렉토리 | 피처드 타일 + A–Z 클라이언트 필터 + 4열 로우 | `/ip` 목록 존재(문법 상이) | 불필요 |
| A9 | 브랜드관(개별 온라인 팝업) | 풀블리드 배너 540px + 좋아요 원형 + 해시태그, facet 축약 | `/ip/[id]` 존재, `fans_count` 재사용 | 불필요 |
| A10 | 위시리스트 | 카드 하트(리스트 행)·PDP 하트, 마이 위시 목록 | 없음 | **필요**: `wishlists` (user_id×good_id, RLS) |
| A11 | 재입고 알림 | 품절 옵션 선택 시 CTA 교체, 클릭 시 로그인 벽 | 없음 | **필요**: `restock_alerts` + 재고 갱신 연동 발송(기존 알림함·메일 경로) |
| A12 | 검색 오버레이 | 페이지 이동 없는 오버레이(1180×60 인풋+추천 칩), 결과는 별도 페이지 | `/search` 페이지만 존재 | 불필요 (추천어는 큐레이션) |
| A13 | 공유 | PDP 원형 버튼 | 없음 | 불필요 |

## T-B — 도메인 신설 (리디자인 에픽 내 별도 단계)

| # | 기능 | LFS 동작 요약 | ICONS 현황 | DB |
|---|---|---|---|---|
| B1 | 쿠폰 | 카트 단계 프리셋 select+직접입력, 캠페인 경품 코드와 단일 체계, 마이 쿠폰함(티켓형 2열 카드) | 없음 | **필요**: 쿠폰 정의·발급·사용 원장, 주문 생성 RPC 할인 통합(금액 개입 유일 지점) |
| B2 | 회원 등급·리워드 | WELCOME/SILVER/GOLD/VIP, 등급별 쿠폰 배지 색, 프로필 스트립 노출 | 없음 | **필요**: 등급 산정(구매 실적)·등급 혜택 발급 |
| B3 | 상품 Q&A | PDP 위젯 내 공개 질문 탭 | 1:1 문의만 존재 | **필요**: `product_questions`(공개, 운영 답변) |
| B4 | 출석·코인 | 캠페인 랜딩에 코인 잔액 상시 노출, 코인은 가챠·게임 재화 | 없음 | **필요**: 코인 원장+출석 기록+**코인→뽑기권 교환 RPC**(기존 발급 경로 재사용, 결제 무관) |
| B5 | 이벤트(캠페인 허브) | 배너 스와이퍼+ALL/EVENT/DROP 탭+2열 카드, 아티클은 쇼케이스 랜딩 | `/events`는 오프라인 팝업 예매 | **필요**: `campaigns`(유형·기간·랜딩 구성) + 오프라인 팝업 경로 이사 |

## T-C — 범위 외 (외부 계약이 본질, 후속 결정)

| 기능 | 사유 |
|---|---|
| 1:1 실시간 채팅(채널톡류) | SaaS 계약. 현행 1:1 문의 도메인 유지 |
| 다국어 `/en`·글로벌 배송(Global-e) | SaaS+물류 계약 |
| 접근성 위젯(AccessiBe) | SaaS. 접근성은 자체 마크업 품질로 대응 |
| 휴대폰 본인인증 가입 | 본인인증 SaaS(NICE 등) 계약 필요 |
| SNS 로그인 확장(네이버·카카오·구글) | provider 콘솔·심사 필요. 현행 인증 방식 유지, 별도 결정 |

## 이미 보유 — 문법만 이식

리뷰(자체 도메인 — 별점 요약·포토 그리드 문법 이식), 1:1 문의, 주문/주문 상세, 알림함, 카트, 검색 페이지, 큐레이션 어드민, 티켓(오프라인 팝업 예매 — 진입 강등만), 참여형 게임(스탠드얼론 문법 동일).
