## 1. 페이지 골격 (데스크톱)

```
[프로모 스트립 + 헤더 68px — sticky]
[상단 2칼럼: 갤러리 649 | 정보 531]          ← section.ipx-product (h ≈ 867)
[sticky 탭바 54px: 상세설명|리뷰|Q&A|추가정보] ← section.ipx-pdp-tab 시작
[탭 패널(단일 컬럼 840 + 우측 빈 rail 340)]   ← 상세설명 패널만 h ≈ 14,600
```

- 컨테이너: `.product.grid` 1212px, 좌우 여백 ≈ 107px(1440 기준). display:flex.
- 좌 `.product__media-wrapper` **649px** : 우 `.product__info-wrapper` **531px** (내부 padding-left 85px → 실 콘텐츠 **446px**). 비율 ≈ 55:45.
- **정보 칼럼 sticky 아님**: `product-info`에 `product__column-sticky` 클래스와 `top:30px`은 있으나 computed `position: static`. 스크롤 시 갤러리와 함께 그대로 흘러 올라감(스크롤 233→900 실측으로 확인). 클래스만 남은 죽은 기능.
- 헤더는 sticky(스크롤 1500에서도 top 0, h 68). 탭바가 그 아래 `top:68px`로 붙음.

## 2. 갤러리

구조: `pdp-slide`(메인) + `pdp-thumbs`(썸네일 스트립), 둘 다 Swiper.

| 항목 | 값 |
|---|---|
| 메인 캔버스 | **649×649 (1:1 고정)**, 슬라이드 이미지 `object-fit: cover` |
| 원본 이미지 | 3:4 세로(예: 656×874, 상세 원본 1029×14999) → **1:1로 크롭됨** |
| 슬라이드 수 | 상품별 상이(표본: 8/7/6장), 전부 이미지(비디오 슬라이드 없음), loop:true, autoplay 없음 |
| 좌우 화살표 | **없음** (드래그/스와이프 + 도트 + 썸네일만) |
| 도트 | 메인 이미지 **내부 하단**(하단에서 약 35px 위), 8px 원, 검정. active opacity 1 / idle 0.3, 피치 16px |
| 썸네일 | 메인 아래 10px, **84×84** 정사각 이미지, gap 10, slidesPerView 7(넘치면 가로 스와이프) |
| 썸네일 활성 표기 | **없음** — border/opacity/::after 전부 무변화(활성 마커 부재). 썸네일 클릭 시 메인만 전환 |
| 줌/라이트박스 | **없음** — `product-modal` DOM은 있으나 opener 미배치, 클릭 확대 미제공 |
| 모바일 | 썸네일 스트립 `small-hide`로 숨김. 메인 360×500(≈3:4 세로형으로 전환) + 도트만 |

## 3. 정보 칼럼 anatomy (위→아래 전순서)

`product-info` 446px 안에서, 순서 고정:

1. **배지 행** `.product__badge` (h 20)
2. **상품명** `.product__title > h1`
3. **가격 블록** `.price.price--large`
4. **툴즈 행** `.product__tools` — 별점 요약(좌) + 위시/공유(우)
5. **폼 블록** — 옵션 셀렉트 → 수량 행 → 총 상품 금액 → CTA
6. **브랜드 칩** `.product__vendor`

**배송·혜택 안내 블록은 정보 칼럼에 없음**(쿠폰 혜택은 하단 상세 첫 배너로, 배송 정보는 별도 공지 페이지로만). "전체 세부 정보 보기" 링크는 DOM에 있으나 숨김(0×0).

### 3.1 배지

- `span.ipx-badge` 인라인 나열(NEW·SALE 동시 표기 가능), 12px/700, padding 0 3px, radius 1px, h 20.
- `NEW` = `.red`: 텍스트 `#F83BAA`(핫핑크), 배경 `rgba(248,59,170,0.1)`.
- `SALE` = `.white`: 텍스트 `#F83BAA`, 배경 `#FFF`, 보더 1px `rgba(248,59,170,0.1)`.
- EXCLUSIVE 배지는 이번 표본 4종에서는 미관측(목록 카드 필터 기준으로 타입은 존재).

### 3.2 상품명

- h1 **18px/700**, lh ≈ 20px, `#111`, letter-spacing -0.2px. 배지와 8px 간격.

### 3.3 가격 블록 (상태 2종)

- **정가만**: 1행 — 라벨 "정가" 14px/600 `#111` + 금액 `price-item--regular` **24px/700 `#111`** (블록 h ≈ 26).
- **할인 시** (`price--on-sale`): 2행 스택 (블록 h ≈ 46):
  - 1행 `.price__original`: 라벨 "정가" 14px/600 + `<s>` 취소선 금액 **14px/500 `#BBBBBB`**
  - 2행 `.price__final`: 라벨 "할인가" 14px/600 + `price-item--sale` 24px/700에서 **할인율 `%`만 `#F83BAA`**, 금액은 `#111`. 표기 순서: `할인가 30% ₩10,500`
- 가격은 **선택된 variant 기준으로 실시간 교체**된다. variant별로 할인 유무가 다를 수 있음(표본 ②: 품절 variant만 30% 할인가 보유 — 기본 선택 variant는 정가 표시였음). URL `?variant=` 갱신은 하지 않음.

### 3.4 툴즈 행 (별점 + 위시 + 공유)

- 행: flex space-between, 하단 보더 1px `#F0F2F4`, padding-bottom 25px, h 62.
- 좌 **Stamped 별점 배지** `.stamped-product-reviews-badge` (92×30): 별 5개 + 리뷰 수. 리뷰 0개면 회색 아웃라인 별 5개만(개수 없음), 있으면 검정 별(`#000` 강제 인라인)+개수.
- 우 `.button_tools` (84×36, gap 12):
  - **위시 하트** 36×36 원형, 보더 1px `#DCDEE0`, 투명 배경. Wishlist King 앱(`button.wk-button`, `data-variant-id` 단위).
  - **공유** 36×36 원형 동일 스타일, svg 22×21. 클릭 → 자체 `ipx-modal` 팝업: SNS 아이콘 5개 + "URL 복사" + "닫기". 모달 제목이 i18n 키 문자열(`ipx.product.modal.share_product`) 그대로 노출되는 버그성 상태.

### 3.5 옵션 셀렉트

- **네이티브 `<select>`** 1개(`options[Option]`): 래퍼 `.select` 446×42 보더 박스 + select 444×40 + 우측 캐럿 svg 12×7(우측 15px 인셋). label은 시각 숨김.
- 옵션 텍스트 포맷: `옵션명` / 품절 시 **`옵션명 - 품절`** 서픽스. **disabled 아님 — 품절 옵션도 선택 가능**하고, 선택하면 CTA가 재입고 모드로 바뀜(3.8).
- 기본 선택 = **첫 번째 "구매 가능" variant**(앞쪽이 품절이면 건너뜀). placeholder("옵션을 선택하세요")형 빈 옵션 없음.
- 단일 variant 상품도 셀렉트 행 유지(전량품절이면 `단일옵션명 - 품절`이 그대로 선택돼 있음).
- 펼친 상태는 OS 네이티브 드롭다운(커스텀 리스트 UI 아님) — 품절 표기는 옵션 텍스트 서픽스가 전부.

### 3.6 수량 스테퍼

- `quantity-input.quantity` **92×32**, 보더 1px `#DCDEE0`, radius 2px. 행 좌측에 라벨 "수량"(14px), 스테퍼는 우측 정렬.
- 내부: [− 30×30] [number input 28×30, 15px/700, min=1] [+ 30×30]. 버튼 배경 투명, 글리프 18px.
- qty=1일 때 −버튼에 `disabled` **클래스만** 부여(시각 처리; 실제 disabled 아님, min으로 클램프). 재고 상한 rules(`quantity__rules`)는 DOM만 있고 숨김.
- 품절 variant 선택 중에도 스테퍼는 계속 노출.

### 3.7 총 상품 금액(합계)

- 행 `.product__buy_price`: 좌 "총 상품 금액" **14px/700**, 우 `strong.current-subtotal-price` **18px/700 `#111`**, `₩ 25,800` 형식.
- **실시간 갱신 실측**: 수량 +1 → `₩ 25,800` → `₩ 51,600` 즉시 반영. variant 전환 시 해당 variant 가격(할인가) 기준으로 교체.

### 3.8 CTA (판매중 ↔ 품절 전환 규칙)

판매중 variant 선택 시 (합계 행에서 16px 아래):

| 버튼 | 크기 | 스타일 |
|---|---|---|
| 장바구니 | **122×50** | 흰 배경·검정 텍스트 15px/700, radius 2px, **보더·섀도 없음**(흰 바탕에서 면으로만 구분) |
| 구매하기 | **319×50** | 검정 `#000` 배경·흰 텍스트 15px/700, radius 2px |

- 가로 배치, gap 5px → 비율 ≈ **27 : 73**. 둘 다 `type=submit`(product form 직접 제출; 옵션 시트 등 중간 단계 없음).
- **품절 variant 선택 시**: 두 버튼 숨김(구매하기는 "SOLD OUT" disabled 상태로 대체된 채 숨겨짐) → **`재입고 알림 받기` 446×50 검정 풀폭 단독 버튼**으로 교체. 좌측에 벨 아이콘 svg 19×20(margin-right 6px). 이 버튼은 DOM에 상시 존재(`.sendBis`)하며 표시만 토글.
- **재입고 알림 = 로그인 벽**: 비로그인 상태에서 클릭 → `/account/login` 리다이렉트(사이트 로그인은 카카오 OAuth 연동). 이메일만 받는 게스트 모달이 아님(Back in Stock 앱이 계정 기반으로 동작).

### 3.9 브랜드 칩

- 상단 보더 1px `#EBEDEE` 아래 flex 행(h 82): 브랜드 배너 이미지 **150×80**(원본 300×160) + 브랜드명 + "브랜드 보러가기 ›" 13px `#3F3F3F` 링크 → `/collections/{brand}`. 품절 캡처 기준 박스형 카드로 렌더.

### 3.10 기타

- `klarna-placement` 요소가 CTA 아래 존재하나 빈 상태(높이 0).
- 결제수단·배송 예정일·적립금 안내 등 구매 보조 정보는 정보 칼럼에 일절 없음.

## 5. 하단 상세 영역

### 5.1 sticky 탭바

- `.product--tab` — **position: sticky, top: 68px**(sticky 헤더 바로 아래; 모바일은 top 43px), 흰 배경, 하단 보더 1px `#F0F2F4`. 내부 `.tab-list.page-width` h 54.
- 탭 4개, 각 **220×54**, 20px/700: `상세설명` `리뷰` `Q&A` `추가정보`.
- active: 텍스트 `#111` + **검정 밑줄 바** / idle: `#A0A0A0`, 밑줄 없음.
- 리뷰 탭에는 개수 뱃지 병기: `리뷰 (17)` 형태.

### 5.2 탭 동작 = 패널 전환(아코디언 아님)

- 콘텐츠는 `.detail-product-wrap` 안 `.tab-body` 4개: `#tab-content`(상세설명, 기본 표시) / 무명 리뷰 패널 / `#tab-qna` / `#tab-info`. 탭 클릭 → 해당 패널만 display 토글 + 탭바 위치로 스크롤. href는 `#tab-*` 앵커지만 실동작은 JS 패널 스위치.
- `#tab-qna` 자체는 **빈 div**이고, Q&A 탭은 리뷰 패널 안 Stamped 위젯의 내부 탭(`#tab-questions`)을 활성화하는 방식(6.4).

### 5.4 브랜드 관련 상품 캐러셀

- Swiper slidesPerView **4**, gap 16, 슬라이드 **50장**, 내비 화살표 없음(드래그만).
- 카드 172.8px: 미디어 **3:4 세로**(172.8×236.6 — 컬렉션 그리드의 정사각 카드와 다름) + 콘텐츠 79px.
- 카드 구성: 썸네일(호버 시 2번째 이미지) + 우상단 하트 36×36(`wk-floating`) + 벤더 12px/600 `#111`("공급업체:" 프리픽스 노출) + 상품명 h3 13px/400 `#3F3F3F` lh15 + 가격 14px("정가 ₩n" / 할인 병기) + 별점 배지(있을 때). 품절 카드는 4장의 SOLD OUT 밴드.

## 6. 리뷰 위젯 (Stamped)

리뷰 탭 패널 = `#stamped-main-widget` 단일 위젯(폭 709). 표본 ④(리뷰 17개, 평점 5.0) 기준.

### 6.1 요약부 (h ≈ 140)

- 좌: 평균 **"5.0" 37px/700 검정** + 검정 별 5개(폭 128×19) . **분포 바(5★~1★ %)는 DOM에만 있고 항상 숨김 — 화면에 분포 UI 없음.**
- 중: **포토 리뷰 그리드 2×4**(총 8장 표시, 썸네일 70×55) — 캐러셀 아님.
- 우: **`리뷰쓰기(Rate)`** 버튼 — 흰 배경+검정 보더 박스(117×45). 실체는 `span[role=button]` + `StampedFn.toggleForm('review', productId)`.
- 리뷰 0개 상품의 빈 상태: "0.0" + "Be the first to review this item" + Write a Review (영문).

### 6.2 정렬/필터

- 정렬 셀렉트 1개: `Sort / With Photos / Most Recent / Highest Rating / Lowest Rating / Most Helpful` — **영문 그대로**. 별점 필터·More Filters는 마크업만 있고 숨김.

### 6.3 리뷰 아이템 anatomy (아이템 h ≈ 198~)

위→아래:
1. **작성자**(좌) 14px/700 — **마스킹 불일치**: `박**` 같은 부분 마스킹과 실명(한글 풀네임·영문명)이 혼재.
2. **날짜**(우) 12px `#555`, `YYYY/MM/DD`.
3. **별점**(20px 검정 별) + **리뷰 제목** 15px/700 `#121212` (같은 행).
4. **본문** 14px/400.
5. **첨부 사진**(있을 때) 썸네일 98×130.
6. **구매 상품 라인**(회색): `상품명 - 옵션명` 포맷으로 어떤 variant 구매자인지 표기.
- "Was this helpful? 👍0 👎0" 투표·공유 마크업은 존재하나 **표시 안 됨**. 검증구매(Verified) 배지도 숨김 상태.

### 6.4 페이지네이션 · 작성 폼 · Q&A

- 페이지네이션: 리뷰 5개/페이지, `‹ 1 2 3 4 ›` 숫자 페이저(17개 → 4页).
- **리뷰 작성**: `리뷰쓰기(Rate)` 클릭 → **인라인 폼 확장**(`.new-review-form`, h ≈ 590; 모달·로그인 벽 없음, 게스트 작성): Name*, Email*, Location, Rating*(별 선택), 제목(Title)*, 본문(Description)*, 사진/비디오 업로드, Submit. 라벨은 영문, placeholder 일부만 한글.
- **Q&A 탭**: 같은 Stamped 위젯의 내부 `Questions` 탭을 활성화. 표본들에서 질문 0건 빈 상태(h ≈ 289)만 관측 — 목록 아이템·답변 표시 형태는 질문 보유 상품을 찾지 못해 **미관측**. 작성 진입점은 `Ask a Question`(`StampedFn.toggleForm('question', id)`, 리뷰와 동일한 인라인 폼 패턴).
- **추가정보 탭**(`#tab-info`, h ≈ 276): "상품 정보 고시" 테이블(품명/모델명, 제품 크기 등 법정 고시 항목 행).
- i18n 상태: 위젯 UI 문구(정렬 옵션, 폼 라벨, 빈 상태, helpful)가 **대부분 영문 노출** — 한글화는 `리뷰쓰기(Rate)` 버튼 정도.

## 7. 모바일 (375×812)

### 7.1 1열 스택 순서 (위→아래 전부)

1. 프로모 스트립 배너 → 로고 헤더(GLOBAL OFFICIAL 배지, 검색·카트 아이콘) → GNB 가로 스크롤 행 — 합쳐서 sticky(탭바 top 43px 실측)
2. **갤러리 360×500**(세로형; 도트만, 썸네일 숨김, 스와이프)
3. 배지(있을 때) → **상품명** → **가격 블록** → **툴즈 행**(별점/하트/공유 — 데스크톱과 동일 구성)
4. **폼 블록 인라인 유지**: 옵션 셀렉트 → 수량 행 → 총 상품 금액 → CTA(장바구니+구매하기 인라인 그대로 노출; 품절 시 재입고 버튼 교체도 동일)
5. 브랜드 칩
6. sticky 탭바(4탭) → 상세설명 패널: 쿠폰 배너(모바일 전용 이미지, h 170) → 상세 이미지 → …데스크톱과 동일 순서(관련 상품 캐러셀은 2열 폭 카드)

### 7.2 하단 고정 구매바

- `.ipx-tab > .pay_tools`: **position:fixed bottom:0, 풀폭, height 72px(CSS 명시), 검정 배경, z-index 100.** 스크롤 위치와 무관하게 **상시 노출**(등장 애니메이션/조건 없음).
- 구성: **단일 `<button>`(type="button")** 이 바 전체(360×72)를 차지하고, 내부가 2존으로 보임 — 좌측 **카트 아이콘 존 82px**(흰 카트 아이콘 24×24, 세로 구분선) + 우측 **"구매하기" 텍스트 존 278px**(18px/700, **핫핑크 `#FD4BBB`**).
- 합계 금액·하트는 바에 **없음**(합계는 본문 인라인에만). 데스크톱 CTA(흰 장바구니+검정 구매하기)와 완전히 다른 문법.
- **탭 시 옵션 시트 없음**: 바텀시트/드로어류 DOM이 페이지에 존재하지 않음. 옵션 선택은 본문 인라인 셀렉트가 유일한 경로. 바 버튼은 product form에 미연결된 type=button + JS 리스너 — 실제 클릭 동작(장바구니 담기/즉시구매)은 구매 발생 리스크로 **미실행·미검증**.
- 품절 variant 선택 상태에서도 바는 "구매하기" 그대로(재입고로 안 바뀜) — 상태 비반응. 재입고 전환은 본문 인라인 CTA만 수행.
- 참고: 750~989px(태블릿) 구간에는 합계+장바구니+구매하기가 든 `.product__buy`(small-hide) 변형이 바 안에 준비되어 있음.

## 10. 리디자인 관찰 노트 (구조적 사실 기반)

1. **정보칼럼 sticky 미작동**(클래스만 존재) — 긴 갤러리 대비 우측 칼럼이 먼저 사라짐.
2. **갤러리 활성 썸네일 마커 부재**, 줌/라이트박스 부재 — 8장 갤러리 대비 탐색 어포던스 약함.
3. **리뷰 위젯 영문 혼재**(정렬·폼·빈 상태·helpful), 분포 바 숨김, helpful 투표 숨김 — 리뷰 신뢰 UI가 반쯤 꺼져 있는 상태.
4. **작성자 마스킹 불일치**(실명 노출 혼재).
5. **재입고 알림 = 카카오 로그인 벽** — 이메일 게스트 신청 불가.
6. 정보칼럼에 **배송·적립 안내 부재**, 혜택은 하단 배너로만.
7. 모바일 고정 바가 **금액·상태 비반응 단일 버튼** — 데스크톱 CTA 문법과 단절.
8. 공유 모달 제목 i18n 키 노출, "공급업체:" 라벨 노출 등 로컬라이즈 잔결함.
