## 1. 공통 요소 스펙

### 1-1. 섹션 헤딩 블록

- H2, **28px / 700**, 색 #111 (섹션별 #121212·#222 혼재 — 사실상 동일 잉크색), line-height 106~128%, 좌측 정렬. 클래스 `ipx-font-weight-800`(실렌더 700).
- 좌측선: 데스크톱 콘텐츠 좌단(x122.5), 모바일 x16. **모든 밴드 헤딩이 왼쪽 정렬** — 가운데 정렬 없음.
- "전체보기" 링크가 헤딩 우측에 붙는 패턴은 홈에 **없다**. 대신 ④~⑥은 하단 중앙 아웃라인 버튼, ②·③·⑦은 하단 중앙 fraction 페이지네이션이 그 역할.
- 서브카피(④~⑥만): 헤딩 하단 +10px, **16px / 400**, #121212, 한 줄 (프로모션 조건 안내 성격).
- 헤딩(또는 서브카피) 하단 → 콘텐츠 시작 간격: **24px** 공통 (②·④·⑤·⑥·⑧ 실측 24, ③·⑦은 좌탭 구조라 예외).
- 모바일: 28px 유지 (⑧만 27px — vw 기반 클램프 추정).

### 1-2. 상품 카드 (그리드형) — 밴드 ③·⑦ 공용, 최중요 재사용 컴포넌트

Shopify Dawn `card-wrapper product-card-wrapper` + `ipx-card-product`.

```
.card-wrapper (D 212×370.9 / M 167.5×330.6)
├ .card__inner.ratio  --ratio-percent: 136.99%   ← 이미지 비율 고정 73:100 (세로형)
│ └ .card__media > .media > img (D 212×290.4 / M 167.5×229.4, object-fit cover, radius 0)
└ .card__content > .card__information
  ├ .card__vendor   브랜드  D 12px/600 #111, ls -0.2, 하단마진 4 / M 13px
  ├ h3.card__heading.h5 > a  상품명  D 13px/400 #111 lh115% / M 14px — 말줄임 없이 랩(모바일 2줄 사례 확인)
  ├ .price          가격    D 14px/600 rgba(18,18,18,.75~1) / M 15px
  └ .card-product-review  Stamped 별점 (리뷰 0이면 height 0 숨김; 별·괄호 리뷰수 #bbb 13~15px)
```

- 수직 간격: 이미지→브랜드 12 / 브랜드→상품명 4 / 상품명→가격 8.
- **할인 시 가격 2줄 스택**: 1줄째 취소선 정가 (`s.price-item` 14px #BBBBBB) → 2줄째 `할인율% + 할인가` (`.sale-percentage` **14px/600 핑크 #F83BAA** + 할인가 14px/600 #121212). 할인율이 가격 왼쪽에 붙는 형식.
- 하트(위시리스트) 버튼: 그리드형 카드에는 **없음** (리스트 행에만, 1-3 참조).
- 정보영역 배경 투명, 카드 보더/그림자/라운드 없음. hover 시 상품명 밑줄 클래스(`underline-links-hover`) 부착. 이미지 hover 스왑용 두 번째 이미지는 홈 카드에 없음.
- 클릭 → 상품 상세 (`/products/*`).

### 1-3. 상품 리스트 행 (컴팩트형) — 밴드 ④~⑥ 공용

```
행 (D 380×80 / M 343×80, 행 간격 D 37 / M 33)
├ 썸네일 80×80 (cover, radius 0)  ← 좌측
├ 텍스트 칼럼 (썸네일 우측 +15px, 폭 D 173~176 / M 173)
│ ├ 브랜드 13px/400 #888888
│ ├ 상품명 13px/400 #111 (1줄)
│ ├ 가격   14px/600 rgba(18,18,18,.75)
│ └ 별점 (리뷰 있을 때만, h≈17)
└ 하트 버튼 30.4×30.4 — 행 우측 끝 (우측 여백 D 8 / M 7.8), 수직 중앙
```

- 하트는 Wishlist King 앱 (`.wishlist-button.wk-floating`). 그리드 카드에는 미부착 — **하트는 이 리스트 행 전용**.

### 1-4. fraction 페이지네이션 (밴드 ②·③·⑦ 공용)

- `‹ n / m ›` 구성: 좌우 화살표 8×13 SVG + 분수 텍스트 13px #121212. 화살표-분수 간격 ~22px.
- 위치: 슬라이더 영역 하단 중앙 (②는 페이지 중앙, ③·⑦은 우측 슬라이더 칼럼의 중앙), 콘텐츠 하단에서 +40px.
- 첫/마지막 페이지에서 해당 화살표에 `swiper-button-disabled`.
- 모바일: ③·⑦은 유지, ②는 **숨김** (스와이프만).

### 1-5. 아웃라인 버튼 (밴드 ④~⑥ "컬렉션 전체보기")

- D 300×50 / M 전폭 343×50, 페이지(밴드) 중앙 정렬.
- 14px/700 #111, bg #FFF, **outline 1.5px #111** (border 아님), radius 2px, padding 0 30, flex 중앙.
- 리스트 하단 +56px(D) / +40px(M) 지점.

## 2. 밴드별 상세

### ① 히어로 캐러셀 (`ipx-main-slide`)

- **슬라이드 실측**: D **1425×770** (뷰포트 1440 기준 전폭×고정 770px — 뷰포트 높이를 760으로 줄여도 770 유지, vh 연동 아님. min-width:1440 구간 고정 높이). 비율 ≈ 1.85:1. M **375×450** = **5:6 세로형**.
- 이미지: PC/MO **별도 아트웍 2벌** (`Home_Main_pc_*` / `Home_Main_mo_*`), `<picture>` 소스 분기 min-width 750/1440, object-fit cover.
- **전환**: Swiper `effect: fade`(슬라이드 아님), 전환 1000ms, **autoplay 5000ms**, loop, 슬라이드 9장, 상호작용 후에도 autoplay 유지(`disableOnInteraction: false`).
- 슬라이드 링크: 컬렉션 7 + 이벤트 아티클 1 등 슬라이드당 1링크 (전면 클릭).
- **텍스트 오버레이**: 이미지 위 절대배치, 하단 기준 D bottom 56 / M bottom 32. 2줄 구성 — 캐치카피 `24px/700` + 부제(상품 영문명 성격) `15px/400`, 줄 간격 6px. 색은 슬라이드별 CSS 변수 `--color`(현재 9장 전부 흰색). 정렬: **D 가운데 / M 왼쪽**.
- **인디케이터**: 점이 아니라 **전폭 세그먼트 진행바**. 슬라이드 하단(bottom 0)에 높이 **6px** 바를 9등분(flex-grow 1, 세그먼트당 1425/9=158.3px, 간격 0). 비활성 검정 30% / **활성 세그먼트만 불투명 검정**, opacity transition 0.3s. 클릭으로 해당 슬라이드 이동 가능. 모바일 동일(6px, 375/9등분).
- **화살표**: 좌우 24×36 얇은 꺾쇠 SVG(#DCDEE0), 가장자리에서 24px, 수직 중앙. 클래스 `small-hide` — **모바일 숨김**.
- 텍스트·진행바 가독성용 하단 그라데이션 오버레이가 이미지 위에 깔림(스크린샷 확인, 하단부 어두워짐).

### ② 에디터의 제안 (`ipx-featured-contents`) — 콘텐츠 카드 3열

- 헤딩 아래 24px에 캐러셀. **콘텐츠 카드**(상품 카드와 다른 별도 anatomy).
- **데스크톱**: Swiper slidesPerView 3, gap(spaceBetween) 20 → 카드 **380×470.4**, 3열 표시, 14장 로드(fraction은 `1 / 12` = 14−3+1 위치 수). loop·autoplay 없음.
- 카드 anatomy (세로 스택, 배경 투명·라운드 없음):
  - 이미지 **380×380 (1:1)**, cover — 하단 14px 간격
  - **배지**: `NEW`/`EVENT` — 12px/700, 색 **#FD4BBB**(핑크), bg **#F6F8FA**(연회색 칩), padding 3×6, radius 0. 두 종류가 **동일 스타일**(텍스트만 다름). 이미지 위 오버레이가 아니라 **이미지 아래 텍스트 영역 첫 줄**에 배치 — 하단 10px 간격
  - 타이틀 18px/700 #111, 1줄 — 하단 8px 간격
  - 설명(상품 영문명·행사 조건 성격) 13px/400 #111, 1줄
- 카드 전체가 컬렉션/이벤트 링크.
- 하단 중앙 fraction `‹ 1 / 12 ›` (카드 하단 +40).
- **모바일**: slidesPerView `auto` — **고정 300px 카드** + gap 10, 좌 16 시작, 다음 카드 **49px 피킹**. 이미지 300×300. 타이포 뱃지 12 / 타이틀 18 / 설명 14. **fraction·화살표 숨김** (자유 스와이프).

### ③ 카테고리 BEST (`ipx-main-tab` 1st) — 좌탭 + 페이지형 상품 그리드

- **데스크톱 2칼럼**: 좌 220px 칼럼(헤딩+탭) + 64px 갭 + 우 896px 슬라이더. 우측 그리드가 **헤딩과 같은 y에서 시작** (헤딩이 좌칼럼 소속).
  - 좌칼럼: 헤딩(220 폭, 2줄 가능) → 39px → **세로 탭 목록**. 탭 5개(NEW·키링·랜덤 가챠·파우치·리빙), 항목 높이 19, 행간 37.8. 활성 **16px/700 #111** / 비활성 16px/400 **#888**. 밑줄·보더·배경 없음 — 굵기+색만으로 구분.
  - 우측: Swiper slidesPerView 1 — **슬라이드 1장 = 그리드 1페이지**(1행×4열 상품 카드), spaceBetween 16, 페이지 3장 = 탭당 최대 12품. 카드는 1-2 공통 스펙(212px, 열 pitch 228 = 카드 212+갭 16).
  - 페이지네이션: 우측 칼럼 하단 중앙 fraction `‹ 1 / 3 ›`.
- **탭 전환 동작**: 탭은 `href="#tab-…"` 앵커. 탭마다 **별도 Swiper 패널 5개가 미리 렌더**되어 있고 클릭 시 활성 패널만 표시 전환(페이지 이동·리로드 없음, 각 패널 슬라이드 위치 독립 유지). `active` 클래스 이동.
- **모바일**: 탭이 **가로 flex 줄**로 변환 (gap 12, nowrap, 넘치면 가로 스크롤 — 현재 5개는 343 안에 다 들어감). 활성 700 #111 / 비활성 400 rgba(0,0,0,.4). 헤딩→9px→탭→24px→그리드.
  - 슬라이더: 페이지당 **2열×2행**(4품) 그리드, 카드 167.5, 열 갭 8, 행 갭 32, 페이지 간 7px. fraction `1 / 3` 유지 (하단 중앙).

### ④~⑥ 프로모션 배너+리스트 3연속 (`ipx-featured-collection` ×3)

세 밴드는 **완전 동일 템플릿** — 콘텐츠(대상 컬렉션·배너 아트웍·서브카피)만 다르다. 구조적 차이 없음.

- 헤딩(28px) → 10px → 서브카피(16px, 쿠폰/자동할인 조건 성격) → 24px → 본문 2칼럼.
- **좌 배너**: **780×431.1** (비율 ≈ **1.81:1**, 원본 550×304·420×232), cover, radius 0. **텍스트 오버레이·버튼 없음** — 카피는 전부 이미지에 베이크. 전체가 컬렉션 링크(우측 리스트와 동일 타깃).
- **우 리스트**: 배너 우측 +20px, 폭 380. **1열×4행** 컴팩트 행(1-3 스펙: 80px 썸네일+텍스트+하트). 4행 고정.
- 하단 중앙 **아웃라인 버튼**(1-5, 컬렉션 전체보기) — 배너·리스트 하단 +56.
- 각 밴드 타깃: ④ K-POP 쿠폰 기획전 / ⑤ 주간 브랜드 기획전 / ⑥ 카테고리(파우치) 기획전 — 성격만 다르고 UI 동일.
- **모바일 재배치**: 세로 스택 — 헤딩 → 서브 → **배너(343×189.5, 1.81:1 유지)가 위** → 16px → **리스트 4행 세로 유지**(가로 스크롤 아님) → 40px → 전폭 버튼. 하트 행 우측 유지.

### ⑦ 인기템 (`ipx-main-tab` 2nd) — ③과 같은 컴포넌트

- ③과 동일 섹션 타입·동일 레이아웃(좌 220 탭 + 896 그리드, 카드 212 스펙 동일). **차이점만**:
  - 탭이 카테고리가 아니라 **브랜드 축** 6개(MULTI + 브랜드 5).
  - 현재 데이터가 페이지 1장·상품 3개뿐 → fraction `1 / 1`, 4열 그리드에 3장만 채움(빈 슬롯 유지).
  - 섹션 pad-bottom 80 (③은 100).
- 모바일: ③과 동일한 2열 그리드 변환 (카드 3개 → 2+1 배치).

### ⑧ 혜택 4타일 (benefit tab)

- **전폭 배경 #F0F2F4** 밴드. 상단 padding 80 → 헤딩(28px) → 24px → 타일 행 → 하단 96.
- 타일: `<ul>` flex gap 20, **`<a>` 타일 4개 280×158**, bg #FFF, radius 2, padding 32×24. 그림자·보더 없음. 각 타일이 공지 아티클 링크(배송 안내·멤버십 등).
- 타일 anatomy (좌상단 정렬 세로 스택):
  - 아이콘: 라인 스타일 SVG **32×32** (#111 계열)
  - +10px → 타이틀 **18px/600, 타일별 포인트 컬러** (①파랑 #0D6AFF ②핑크 #F83BAA ③보라 ④주황 — 타일마다 다른 색)
  - 설명 18px/600 **#111** (타이틀 바로 아래, lh 26)
- **모바일**: **2×2 그리드** (flex wrap, gap 10), 타일 166.5×112, padding 16×24. 데스크톱/모바일 텍스트 노드가 별도(`desktop-only`/`mobile-only`) — 모바일 타이포: 타이틀 **13px/700**(포인트 컬러 동일), 설명 13px/600 #111. 아이콘 32 유지. 헤딩 27px, 상단 padding 56.

## 3. 모션·연출

- **스크롤 진입 연출 없음**: AOS·`scroll-trigger`·slide-in 계열 클래스 0개. 이미지 native `loading="lazy"`뿐 (플레이스홀더 페이드 연출 없음 — 로드 전 흰 영역).
- 모션은 3곳뿐: 히어로 fade 전환(1s)/진행바 opacity(0.3s), Swiper 슬라이드 드래그, 카드 hover 밑줄. 전반적으로 **정적인 화이트 카탈로그 톤**.
- 우하단 채널톡 스타일 플로팅 버튼(핑크 원형, 서드파티)이 전 밴드 위에 상주.

## 4. 재현 요점 요약

1. 홈은 **컴포넌트 4종의 조합**이다: 콘텐츠 카드(②), 상품 카드 그리드(③=⑦), 배너+컴팩트 리스트(④=⑤=⑥), 혜택 타일(⑧). 밴드 ③~⑦은 사실상 2개 템플릿의 반복.
2. 그리드 수치 체계: 콘텐츠 1180 / 카드 212×4+갭16 / 콘텐츠 카드 380×3+갭20 / 배너 780+20+리스트 380 / 타일 280×4+갭20 — 전부 1180으로 수렴.
3. 섹션 배경 흰색, 라운드 최대 2px, 보더 대신 outline·굵기·잉크 농도로 위계 표현. 포인트 컬러는 핑크 2종(#FD4BBB 배지 / #F83BAA 할인·타이틀)과 타일 4색뿐.
4. 모바일 변환 규칙: 세로 탭→가로 탭, 4열→2×2 페이지, 배너 위→리스트 아래 세로 유지, 3열 캐러셀→300px 고정폭 피킹 캐러셀, 4타일→2×2. fraction은 ②만 숨김.
5. 밴드 리듬: D 120~140 / M 64~100. 헤딩→콘텐츠 24 공통.
