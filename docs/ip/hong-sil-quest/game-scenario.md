# 홍실 퀘스트 — 서사형 게임 시나리오 (개정판)

[story-bible.md](./story-bible.md)의 정전을 기준으로 다시 쓴 대본이다. `components/prototype/hong-sil-vn/story.ts`(브랜치 `ps/feat/hong-sil-vn-prototype-preview`)에 구현돼 있으며, 이 문서가 그 원본이다.

- **플레이어** = 이연 1인칭
- **무대** = 원작 시즌2 최종화의 〈홍기훈 퀘스트〉. 기억을 잃은 기훈과 7년 만에 재회한 시점
- **분량** = 8라운드 × 선택지 3개. 조건부 페널티 구간 2개
- **경로** = 3⁸ = 6,561. 엔딩 21종 · 전부 도달 가능(테스트로 검증)

## 개정 요약

| | 현행 | 개정 |
|---|---|---|
| 라운드 | 4 | **8** |
| 경로 | 81 | **6,561** |
| 엔딩 | 20 | **21** (해석 메커닉 전용 1종 추가) |
| 퀘스트 | 텍스트 한 줄 | **원작 카드 포맷**(라벨·기한·페널티) + 홍실바위 화자 |
| 실패 | 없음 | **실패 → 페널티 → 보너스 퀘스트** (원작 룰) |
| 선택지 종류 | `say` / `do` | + **`read`**(선배의 속을 읽는다) |
| 무대 | 대학 강의실 | **검찰청 → 조선 전생 → 대학 회상 → 홍실바위** |
| 톤 | 100% 비극 | **코미디 절반 + 비극 절반** |

### 고친 캐논 위반

1. **기훈이 차분했다** → 기억 없는 기훈은 `"박살 난 개 또라이 태양"`(54화). 전 라운드에서 시끄럽다
2. **이연의 독백이 서정적이었다** → 존댓말 겉 / 반말 욕설 속의 분열로 복구
3. **무대가 대학 강의실이었다** → 캐논상 기억 삭제 후 7년이 지났다. 이연은 검사, 기훈은 월드클래스 축구선수다. 대학은 회상으로만 등장한다. **엔딩 문장 21종도 전부 다시 썼다** — 전부 `선배`·`학기`·`학관`을 쓰고 있었다
4. **`release`가 배드엔딩이었다** → 작가는 놓아준 선택을 옳다고 못박았다. `깨끗한 단면`·`돌려주고 물러서다`를 N→R로 올렸다
5. **전생이 요약 한 씬이었다** → 3라운드로 확장(원작 시즌2의 정서적 정점)

## 자료구조

```ts
/** 원작의 퀘스트 알림 포맷. 화면은 이걸 카드로 조판한다. */
export interface QuestCard {
  round: string;      // '제1라운드' | '보너스 퀘스트' | '최종 라운드'
  label: string;      // '〈손을 잡으세요〉'
  deadline: string;
  penalty: string;
}

export type Beat =
  | { kind: 'narration'; text: string }
  | { kind: 'line'; who: CastKey; text: string }   // CastKey에 'rock' 추가
  | { kind: 'inner'; text: string }
  | { kind: 'quest'; card: QuestCard };            // 문자열 → 구조체

export interface Choice {
  /* … */
  kind: 'say' | 'do' | 'read';
  correct?: boolean;   // kind === 'read'에서만 의미
}

/** 직전 라운드를 실패했을 때만 본문 앞에 붙는 구간(원작 보너스 퀘스트 룰). */
export interface PenaltyPrologue { when: FlagKey; beats: Beat[] }

export interface Scene {
  /* … */
  choices: [Choice, Choice, Choice];
  penalty?: PenaltyPrologue;
}

export const sceneBeats = (scene: Scene, flags: Set<FlagKey>): Beat[] =>
  scene.penalty && flags.has(scene.penalty.when) ? [...scene.penalty.beats, ...scene.beats] : scene.beats;
```

**신규 플래그**: `fail_r1` `fail_r4`(페널티 유발) · `named_him`(전생에서 이름의 뜻을 말해 줌) · `read_fear` `read_hurt` `read_alone`(해석 정답).

**설계 선택** — 페널티 구간을 별도 씬이 아니라 다음 라운드 앞에 붙는 비트로 뒀다. 씬 그래프로 가지 않았으므로 열거·순수성·`3ⁿ` 경로 계산이 그대로 살아 있고, 모든 씬이 선택지 3개를 유지해 변형 A/B/C가 손대지 않아도 된다(KISS/YAGNI).

조판 규칙: `say`는 따옴표, `do`는 평문, **`read`는 말줄임과 물음표**(추측이므로).

line 기훈  "혹시 이거 운명 아닐까요? 형은 그런 거 잘 믿거든."

### 특수 엔딩 3종

| 판정 순서 | # | id | 제목 | 등급 | 조건 |
|---:|---|---|---|---|---|
| 1 | **21** | `read_him` | **알아차린 사람** | HOLO | `read_fear` ∧ `read_hurt` ∧ `read_alone` ∧ `named_him` ∧ `remember` |
| 2 | 19 | `unwish` | 소원을 무르다 | HOLO | `found_wish` ∧ `remember` ∧ `진 ≥ 5` |
| 3 | 20 | `swap` | 몫을 바꾸다 | SSR | `broke_pattern` ∧ `restart` ∧ `아 ≤ -4` |

> **21번에 종막 플래그(`remember`)를 넣은 이유** — 넣지 않으면 해석을 다 맞힌 순간 이 엔딩이 최종 선택을 통째로 덮어써서, 게임의 중심 결정인 3분기가 무의미해진다. 회귀 방지 테스트(`특수 엔딩이 최종 선택을 덮어쓰지 않는다`)로 못 박아 뒀다.

### 등급 조정 (`release` 프레이밍)

작가는 놓아준 선택을 옳다고 못박았으므로, 놓아줌·물러섬 결말이 최하 등급인 상태를 고쳤다.

| # | 제목 | 변경 |
|---|---|---|
| 02 | 돌려주고 물러서다 | N → **R** |
| 08 | 깨끗한 단면 | N → **R** |

나머지 등급은 유지했다. N은 `천천히, 처음부터`(14)·`먼저 다가간 쪽`(17) 둘로 남는다 — 둘 다 실패가 아니라 조용한 결말이다.

### 문장 전면 교체

21종 전부 다시 썼다. 화자는 이연이고, 독백이므로 반말에 자조 섞인 태클이 붙는 원작 화법을 따른다. `선배`·`학기`·`학관`·`같은 과 후배` 같은 대학 설정 잔재를 전부 제거했다.

예 — `깨끗한 단면`
- 이전: "미련도 자국도 없었다. 다음 학기에 **선배는 졸업했고, 우리는 학관에서** 가볍게 인사했다. 이렇게 끝나는 이야기도 있다."
- 개정: "미련도 자국도 없었다. **그 사람은 시즌 내내 골을 넣었고 나는 그걸 전부 봤다.** 이렇게 끝나는 이야기도 있다. 끝났다고 안 보는 건 아니고."

### 굿즈

특수 엔딩 전용 SKU가 3종이 됐다(21번용 `「알아차려 줄래?」 봉함 카드 3통` 추가). 종막 대표 3종 + 특수 3종 = **6 SKU**.
