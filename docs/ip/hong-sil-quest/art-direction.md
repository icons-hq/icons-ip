## 1. 진단 — 현행 56컷의 문제

공식 키아트 `public/generated/ip/hong-sil-quest.webp`(© SOOP2RANG, operated by ICONS)와 실제 생성 컷을 대조한 결과다.

| # | 문제 | 확인 방법 | 심각도 |
|---|---|---|---|
| 1 | **컷마다 얼굴이 다르다** | `scenes/act1-bg` · `choices/act1-c1` · `cards/card-01`에서 이연의 눈매·턱선이 각각 다르다 | 치명 |
| 2 | **기훈이 전 컷 무표정이다** | 키아트의 기훈은 혀를 내밀고 능글맞게 웃는다. 생성 컷 56장 전부 무표정하거나 우울하다 | 치명 |
| 3 | **이연의 빨간 캡모자가 0컷** | 키아트에서 이연의 시그니처 아이덴티티인데 게임 원화에 한 번도 없다 | 높음 |
| 4 | **화풍이 다르다** | 키아트 = 강한 레드 그래픽 + 플랫 채색 + 뚜렷한 선. 생성 컷 = 무채색 소프트 셰이딩 + 사진적 배경 흐림 | 높음 |
| 5 | **홍실이 안 보인다** | 브랜드가 "홍실"인데 가는 선 하나로만 표현된다. 키아트의 압도적 레드가 없다 | 높음 |
| 6 | **손 해부학 붕괴** | `cards/card-01`의 맞잡은 손이 구조적으로 이상하다. `choices/act1-c1`도 마찬가지 | 중간 |
| 7 | **원작 개그 시각언어가 0** | 과장 리액션·chibi 분열·의성어 연출이 하나도 없다. 원작은 절반이 코미디다 | 높음 |
| 8 | **무대가 캐논과 다르다** | 대학 강의실로 그려져 있으나 캐논은 기억 삭제 후 7년(검사·프로선수)이다 | 치명 |

**1·2번이 근본 원인이다.** 캐릭터 레퍼런스가 키아트 1장뿐이고 표정 지시가 없어서, 생성기가 "프리미엄 로맨스 판타지 남주" 기본값으로 매번 새로 그렸다.

## 2. 선행 작업 — 캐릭터 시트 (다른 컷보다 먼저)

**컷 발주 전에 이것부터 확정한다.** 시트 없이 본 컷을 뽑으면 1번 문제가 반복된다.

### 2.1 필수 산출물

| 시트 | 내용 | 규격 |
|---|---|---|
| `sheet/yeon-face` | 이연 — 정면 · 측면 · 3⁄4 · 눈매 클로즈업 · 턱선 클로즈업 | 2048×2048 |
| `sheet/yeon-outfit` | 이연 — 검사 정장 / 대학 시절 블레이저 / 조선 도령 한복 / **빨간 캡 착용** 전신 | 2048×2048 |
| `sheet/kihoon-face` | 기훈 — 정면 · 측면 · 3⁄4 · 눈매 클로즈업 · 턱선 클로즈업 | 2048×2048 |
| `sheet/kihoon-outfit` | 기훈 — 축구 유니폼 / 캐주얼 / 조선 무관복 / 노비 아이 | 2048×2048 |
| `sheet/expressions` | **표정 매트릭스** (§3) | 2048×2048 |
| `sheet/props` | 시그니처 소품 (§4) | 2048×2048 |

시트는 게임 화면에 들어가지 않는다. **모든 본 컷 프롬프트의 필수 레퍼런스**로만 쓴다.

### 2.2 캐릭터 확정 사항

**이연** — 검은 머리, 회색빛 눈, 무표정이 기본. 마르고 단정하지만 **키는 기훈보다 크다(187cm)**. 현행 컷들이 이연을 작게 그린 것은 오류다.
- 검사 시점(R1·R2·R6·R7·FINAL): 어두운 정장, 흰 셔츠, 절제된 넥타이
- 대학 회상(R6 일부): 어두운 블레이저 + 흰 셔츠 + 줄무늬 넥타이 + **빨간 캡**
- 조선(R3·R4·R5): 도령 한복. 아역과 성인 두 버전

**기훈** — 금발, 눈꼬리가 올라간 눈, **웃는 얼굴이 기본**. 이연보다 어깨가 넓고 운동한 체형이지만 키는 조금 작다.
- 현대(R1·R2·R6·R7·FINAL): 캐주얼 또는 트레이닝복. 정장은 안 어울리게 그린다(캐릭터)
- 대학 회상: 흰 셔츠 + 느슨한 남색 넥타이
- 조선: 무관복(성인) / 남루한 노비 옷(아역)

## 3. 표정 매트릭스 — 필수

**모든 컷 발주에 어느 표정인지 명시한다.** 지정 없는 발주는 반려한다.

### 기훈 (4종 필수)

| 코드 | 표정 | 근거 | 쓰이는 컷 |
|---|---|---|---|
| `K-GRIN` | **능글** — 혀를 살짝 내밀고 눈을 접어 웃는다 | 공식 키아트의 표정. **기본값** | R1·R2·R7 다수 |
| `K-BURST` | **폭소** — 입을 크게 벌리고 눈을 감는다. 과장 | 원작 개그 리액션 | R1 · 실패 경로 페널티 구간 |
| `K-STILL` | **정색** — 웃음이 완전히 사라진다. 드물어서 강하다 | 45화 "웃는 게 뭐더라" | R2c · R6c 정답 컷 |
| `K-FEAR` | **공포** — 눈이 크게 흔들리고 손이 먼저 움직인다 | 잃어버린 기억의 정체 | R5 · R4 |

> **배분 규칙**: `K-GRIN`이 절반 이상이어야 한다. `K-STILL`은 전체 3컷을 넘기지 않는다 — 흔해지면 무게가 사라진다.

### 이연 (4종 필수)

| 코드 | 표정 | 근거 |
|---|---|---|
| `Y-FLAT` | **무표정** — 기본값. 속과 겉이 다른 상태 |
| `Y-GLARE` | **정색 노려보기** — 속마음이 욕일 때. 눈만 움직인다 |
| `Y-CRACK` | **균열** — 반말이 새는 순간. 눈가만 무너진다 |
| `Y-CHIBI` | **과장 리액션** — 데포르메. 원작 개그 컷 |

## 4. 시그니처 소품 — 최소 1개씩

각 컷에 원작 팬이 알아볼 요소를 하나 이상 넣는다.

| 소품 | 의미 | 등장 |
|---|---|---|
| **빨간 캡** | 이연의 아이덴티티(키아트) | 대학 회상 컷 전부 |
| **홍실** | 브랜드. 발광하는 crimson | 전 컷 (`restart` 계열 제외) |
| **산딸기** | 전생 첫 만남의 매개. 반복 모티프 | R3 · R4 · R5 |
| **파란 장미** | 원래 파랄 수 없는 꽃 = 기훈의 마음. **꽃말은 원작 미공개이므로 문자로 설명하지 않는다** | R7 · 엔딩 일부 |
| **홍실바위** | 세계관 중심. 명랑한 화자이므로 무섭게 그리지 않는다 | R4 · R5 · FINAL |
| **게임보이 UI** | 키아트의 "QUEST START!" 연출 | 퀘스트 카드 프레임 (코드 렌더) |
| **긍정 기훈 chibi** | 기훈 내면의 위원회 | 오버레이 애셋 |

### 4.1 chibi 오버레이 (신규 애셋군)

원작 최고의 개그 장치이며 현행에 없다. 배경과 분리된 투명 PNG로 제작해 코드에서 겹친다.

| 슬롯 | 내용 |
|---|---|
| `chibi/positive` | 긍정 기훈 — 엄지 척, 반짝임 |
| `chibi/worry` | 걱정 기훈 — 눈물 그렁, 발 동동 |
| `chibi/yeon-glare` | 이연 chibi — 무표정 정색 |
| `chibi/rock` | 홍실바위 — 눈만 달린 돌. 고객센터 톤의 시각화 |

## 5. 화풍과 팔레트 — 키아트 기준으로 회귀

현행이 `near-black / deep oxblood / dusty ivory` 기조에 붉은 실만 crimson으로 제한했는데, **키아트는 화면 전체가 레드다.** 그쪽으로 되돌린다.

```
주조색   crimson  #C8102E ~ deep red  #9C001D   ← 화면의 지배색
보조색   near-black #0B0709 / bone #EFE6DC
발광     hong glow #FF2E63                      ← 홍실 전용
액센트   cyan #2DE2FF (진眞 축) / amber #FFB23D (아我 축)
```

- **플랫에 가까운 셀 셰이딩.** 사진적 배경 흐림(bokeh)을 줄이고 선을 살린다
- **그래픽 처리 허용** — 키아트처럼 인물 실루엣을 단색 레드로 깔거나 스크린톤을 쓰는 것을 권장한다
- **`restart` 계열(13~18번)만 예외** — 홍실도 초자연 효과도 넣지 않는다. 이 경우에만 무채색 톤 허용
- 이미지 안에 **글자·숫자·로고·말풍선·UI·워터마크 금지**(기존 규칙 유지). 퀘스트 카드는 코드가 렌더한다

### 6.2 엔딩 컷·카드 (21종)

번호와 제목은 [game-scenario.md](./game-scenario.md) 엔딩표를 따른다. 연출 원칙만 적는다.

- **회복(01~06)** — 홍실이 선명하다. 두 사람이 같은 프레임 안에 있다
- **해방(07~12)** — 홍실이 끊어졌거나 흔적만 남는다. **거리는 두되 등을 돌리지 않는다** (놓아줌은 실패가 아니다)
- **재회(13~18)** — **홍실도 초자연 효과도 없다.** 평범한 빛. 무채색 톤 허용
- **19 소원을 무르다** — lime/cyan/magenta 분광 (HOLO)
- **20 몫을 바꾸다** — magenta/silver 반사광 (SSR)
- **21 알아차린 사람** — HOLO. 두 사람이 마주 보되 **기훈이 `K-STILL`**. 시리즈에서 유일하게 기훈이 웃지 않는 엔딩 카드다. 종막이 `remember`로 고정돼 있으므로 홍실은 선명하다
