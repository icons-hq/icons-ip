# G2 비교 프로토타입 평가 키트

> 상태: 내부 평가용 · env gate · `noindex` · 로컬 무권위
>
> 권리 브리프: **LOCKED** — 사용자 확인에 따라 《지금 우리 학교는》 시즌 1·2 IP, 상호작용 제작, 제공 이미지 사용, 상품화·판매 권리를 이번 캠페인 전제로 잠근다. 이 기록은 제3자 음원·모델의 별도 라이선스를 대신하지 않는다.

## 목적과 승격 규칙

세 후보를 같은 진입·결과 계약으로 비교한다. 참여자 모집과 최종 선택은 내부팀이 담당한다. 에이전트는 실행 가능한 빌드, 점수표, 관찰 기록 양식만 제공한다.

1. `Last Bell` — 1인칭 3D 듣기·은신·환경 조작 탈출
2. `감염 기록` — 짧은 선택으로 감염 경로와 생존 기록을 만드는 2D 체험
3. `3분 생존` — 이동·회피·위험 신호 판독에 집중한 아케이드

`Last Bell`이 가중 총점 1위이면서 아래 필수 기준을 모두 통과할 때만 대표 G3로 승격한다. 동점이면 IP 진정성, 모바일 조작성, 첫 10초 이해 순으로 우선한다.

- 첫 10초 안에 목표를 설명 없이 이해한 참여자 비율 80% 이상
- 390×844 모바일에서 치명적 조작 실패 0건
- 완주 또는 명시적 실패 결과가 반드시 한 번 생성됨
- 결과에서 공유와 팝업 복귀를 모두 찾을 수 있음
- 상품 미리보기는 완주 여부와 무관하게 접근 가능

## 공통 실행 계약

각 후보는 동일한 캠페인 입구에서 시작하고 다음 결과만 로컬에 기록한다.

```ts
type AouadComparisonResult = {
  schemaVersion: 1;
  authority: "local-prototype";
  rewardEligible: false;
  candidateId: "last-bell" | "infection-record" | "survival-arcade";
  runId: string;
  startedAt: string;
  completedAt: string;
  activeDurationMs: number;
  retryCount: number;
  resultType: string;
};
```

- 닉네임, 학생증 이름, 업로드 사진, 자유서술은 결과나 분석 이벤트에 넣지 않는다.
- 결과는 보상, 순위, 재고, 가격, 구매 자격을 만들지 않는다.
- 공통 결과 화면에는 `다시 하기`, `결과 공유`, `팝업으로 돌아가기`, `매점 미리보기`를 제공한다.
- 브라우저 새로고침과 모션 감소 설정에서도 결과 계약은 동일해야 한다.

## 평가표

각 항목은 `1 매우 낮음`부터 `5 매우 높음`까지 정수로 기록한다. 제작·운영비만 `5 저비용·저위험`, `1 고비용·고위험`으로 평가한다.

| 항목 | 가중치 | 확인 질문 |
| --- | ---: | --- |
| IP 진정성 | 20 | 효산고와 지우학의 경험이라고 느끼며, 일반 좀비 게임과 구분되는가? |
| 첫 10초 이해 | 15 | 설명 없이 목표와 첫 행동을 이해하는가? |
| 첫 3분 재미 | 15 | 긴장·판단·피드백이 반복 플레이를 만들 만큼 선명한가? |
| 모바일 조작성 | 15 | 390×844에서 오조작, 가림, 가로 넘침 없이 완료 가능한가? |
| 공유 욕구 | 10 | 결과가 개인적이고 보여줄 가치가 있는가? |
| 재도전 욕구 | 10 | 실패 이유를 이해하고 다른 선택으로 다시 해보고 싶은가? |
| 팝업 연결 | 10 | 학생증·존·컬렉션·매점으로의 복귀가 자연스러운가? |
| 제작·운영비 | 5 | 콘텐츠 갱신, 성능, QA, 운영 부담이 감당 가능한가? |

가중 총점은 `sum(score × weight) ÷ 5`로 100점 만점으로 계산한다. 평균만 남기지 않고 참여자별 원점수와 관찰 근거를 보존한다.

## 세션 기록 양식

```md
참여자 코드: P___
기기·브라우저:
후보 순서: ___ → ___ → ___

후보:
- 첫 행동까지 걸린 시간:
- 첫 3분 이탈 여부와 시각:
- 완료/실패 결과:
- 재도전 횟수:
- 공유 CTA 발견 여부:
- 팝업 복귀 CTA 발견 여부:
- 매점 직행 성공 여부:
- 관찰된 막힘(행동만 기록):
- 참여자 한 문장 회상:
- 8개 항목 점수:
```

후보 순서는 참여자마다 순환 배치해 순서 효과를 줄인다. 진행자는 플레이 중 해결 방법을 알려주지 않고, 10초·3분·결과 시점만 기록한다.
