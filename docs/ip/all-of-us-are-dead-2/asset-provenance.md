## 7. 오디오 제작

### 원칙과 권리

- 원작 드라마의 음원·대사·효과음을 추출하지 않았다.
- 최종 8개 파일은 외부 샘플을 전혀 사용하지 않고 FFmpeg의 sine/noise source와 필터로 직접 합성했다.
- 제작 도구: `ffmpeg 8.1.2`. noise source는 아래 고정 seed를 사용한다.
- 권리 상태: ICONS 프로젝트 자체 생성물. 제3자 음원 라이선스·저작자 표시 의무 없음.
- 루프·앰비언스는 Ogg/Opus 48kHz stereo, 짧고 정확한 onset이 필요한 효과는 PCM WAV 48kHz stereo다.

### 재현 레시피

공통 출력 후처리는 `volume=<factor>,alimiter=limit=0.90`이며 Opus는 `libopus -b:a 96k -vbr on -application audio`, WAV는 `pcm_s16le`다.

- 7개 재질 WebP를 각각 직접 확인하고, 6개 개별 맵은 임시 2×2 repeat contact sheet로 경계도 다시 검수했다. quadrant 오염, 텍스트, 워터마크, 방향성 그림자, 비정상 highlight가 없고 WebP 압축 뒤 미세 균열·긁힘·망입선이 보존됐다. 큰 얼룩과 긁힘의 반복은 보여서 `visual-spec.md`의 실제 스케일과 베이별 UV offset을 수용 조건으로 둔다.

### 오디오

- 모든 파일을 `ffprobe`로 검사하고 `ffmpeg -v error -i <file> -f null -`로 전 구간 decode했다. decode 오류 없음.
- 전 파일: 48kHz stereo. WAV는 PCM s16le, OGG는 Opus.
- 8개 파일을 `showwavespic`으로 한 장에 렌더링해 이벤트 개수와 무음·tail 구조를 확인했다. 차단기 1회, 심박 doublet 4회, 발소리 5회, 문 충격 4회, 종 3회가 의도한 시점에 분리되어 있다. QA 이미지는 확인 뒤 저장소 밖 임시 경로에서 삭제했다.
- `volumedetect` 결과는 다음과 같다.

| 파일 | duration | mean | peak |
| --- | ---: | ---: | ---: |
| breaker switch | 1.200s | -27.8 dB | -3.6 dB |
| breath/heartbeat | 8.007s | -34.7 dB | -11.1 dB |
| classroom ambience | 18.092s | -28.9 dB | -16.8 dB |
| corridor footsteps | 3.350s | -26.7 dB | -5.1 dB |
| distant groan | 5.317s | -24.0 dB | -12.1 dB |
| classroom drone | 24.937s | -26.3 dB | -16.1 dB |
| door pounding | 2.900s | -22.0 dB | -3.3 dB |
| school bell | 3.800s | -21.2 dB | -2.1 dB |

효과음 peak는 -2.1 dB 이하, 배경음 peak는 -16.1 dB 이하로 분리되어 런타임 믹스에서 헤드룸을 남긴다. `breath-heartbeat-loop.ogg`는 반복 가능한 8초 긴장 레이어지만 완전 무봉합 음악 루프가 아니라 상태 진입·이탈 fade와 함께 사용한다.

## 9. 알려진 한계

- 공식 효산고 3D 원본과 공식 원작 오디오 파일은 현재 저장소에 없다. 절차형 3D replacement seam과 자체 합성 오디오로 수직 슬라이스를 진행한다.
- 생성 환경의 교실 구조는 시각 정본이지 원작 세트의 치수 복제본이 아니다. 공식 GLB 도착 시 안정 앵커·충돌·이벤트 계약을 유지하고 메시를 교체한다.
- 생성 재질은 base-color fallback만 제공한다. normal·roughness·height map과 수학적 무봉합 보장은 없으며, 공식 GLB/PBR 재질 도착 시 texture slot 단위로 교체한다.
- `last-bell-corridor.webp`의 감염자는 얼굴·부상 표현이 없는 실루엣 정본이다. 실제 3D 적 모델의 애니메이션 품질을 대신 검증하지 않는다.
