# LINE FRIENDS SQUARE 문법의 스토어프론트 전면 개편을 채택한다

2026-08-26 결정. 공개 스토어프론트(비어드민 전 표면)를 linefriendssquare.com(Shopify 기반 IPX 공식몰)의 레이아웃·IA·컴포넌트 구조·인터랙션 문법·시각 톤을 기준으로 전면 재구축한다. 레퍼런스의 저작·식별 자산 — 이미지·캐릭터·로고·카피·액센트 핑크(#FD4BBB) — 은 어떤 형태로도 재사용하지 않고 전부 ICONS 자산과 토큰으로 치환한다(화이트 캔버스·블랙 잉크·brand-green `#78bb53` 단일 액센트·Pretendard·radius 0~2px 스퀘어). 기존 1세대 Holographic Midnight 잔재와 2세대 Living IP Editorial 시스템은 제거하고 `DESIGN.md`를 새 시스템 기준으로 재작성한다. 유일한 보존은 구 홈의 콘텐츠 섹션을 `/about`(회사 소개)으로 이전하는 것이며, 자체 헤더/푸터 없이 새 전역 셸 아래에 둔다.

IA와 명칭: GNB는 `NEW | BEST | 카테고리 | 온라인 팝업 | 카드팩 | 이벤트 | 커뮤니티`, 유틸바는 검색·카트·마이. "IP 허브"는 **온라인 팝업**으로 개칭하고, `/events`는 캠페인 허브 **이벤트**로 재정의하며, **오프라인 팝업** 예매 도메인은 신규 경로로 이동해 임시로 푸터 진입만 남긴다(기능·티켓·검표는 유지). 모바일은 햄버거 없는 가로 스크롤 GNB 탭과 상품 상세 하단 고정 구매바를 채택하고, 전면 메뉴와 바텀탭은 폐기한다.

기능 채택: 표면과 함께 가는 T-A(필터·정렬, NEW/SALE/SOLD OUT 배지, 장바구니+바로구매 2CTA, 공지바, 온라인 팝업 디렉토리, 공유, 위시리스트, 재입고 알림)와 도메인 신설이 필요한 T-B(쿠폰, 회원 등급·리워드, 상품 Q&A, 출석·코인)를 이번 개편 에픽에서 함께 구현한다. T-C(1:1 채팅 SaaS, 다국어, 접근성 SaaS)는 외부 계약이 본질이라 범위 외로 남긴다.

돈의 경계: 신규 기능 중 주문 금액에 개입하는 것은 **쿠폰뿐**이며, 할인은 서버 주문 생성 RPC에서 확정한다. `PaymentGateway.confirm` seam·멱등 finalizer·할당 재고·카드 발급 RNG·RLS·검표 계약은 동결한다. **코인**은 결제와 무관한 참여 재화로 뽑기권 교환 같은 무상 리워드 소진처만 가진다([ADR-0003](./0003-free-reward-pivot.md)·[ADR-0004](./0004-draw-ticket-card-packs.md) 정합).

출고: 통합 브랜치(`ps/feat/lfs-storefront-redesign`)에 단계 PR을 쌓아 preview로 검수하고, 완성 시 일괄 전환한다. 메이플스토리 첫 판매 전 전환 완료가 목표다.

## Considered Options

- **Living IP Editorial 유지 + 부분 개선** — 폐기. 에디토리얼 연출 중심 시스템과 커머스 전환 중심 레퍼런스 문법이 근본적으로 다르고, 전면 교체가 명시 확정됐다.
- **PR #275 프로토타입(A/B/C 시안) 재사용** — 폐기. base가 main보다 37커밋+ 뒤고, 홈·굿즈 상세 2표면 한정이며, 토큰화되지 않은 `public/` CSS다. 이번 재조사(구조 조사 + 스크린샷 34장) 기반 신규 구축을 채택했다.
- **픽셀·자산 단위 복제** — 폐기. 타사 저작·식별 자산 복제는 법적 리스크이며, ICONS 자신이 IP 라이선스 사업자라 트레이드 드레스 분쟁이 실제 사업 리스크다. 구조·톤 카피 + 자산 전면 치환이 실무적 최대치다.
- **신규 기능(T-B)을 후속 에픽으로 분리** — 폐기. 첫 판매 전 시간 여유가 확인되어 이번 범위에 포함하기로 확정했다.

## Consequences

- `DESIGN.md`·`AGENTS.md` 프론트엔드 규칙은 새 시스템 기준으로 재작성되고, `globals.css`의 Holographic Midnight 토큰과 dead CSS는 제거된다.
- "온라인 팝업"은 IP관 **화면 명칭**이며, [ADR-0008](./0008-remove-unvalidated-popup-native-roadmap.md)이 제거한 online-popup 전용 운영층(`popups` 운영 단위·미션·도장·래플·파트너 운영)의 부활이 아니다. 그 재진입 조건은 그대로 유효하다. 이번 회원 등급·출석·코인은 스토어프론트 로열티 기능이고 파트너 운영층과 무관하다.
- 오프라인 팝업 예매(티켓·검표 포함)는 기능을 유지한 채 진입만 강등된다. 복원은 GNB 항목 추가로 가능하다.
- 헤더/푸터 이중화(홈 자체 셸)와 내비 진실원 2개(`lib/routes.ts` vs `Home.tsx` 하드코딩)는 이번 개편에서 한 벌로 통일된다.
- 클래스명을 단언하는 컴포넌트 테스트 약 87개와 `app/editorial-design.test.ts`는 표면 교체와 함께 재작성된다.
- 재현 참조 자료(스크린샷·구조 조사)는 `outputs/lfs-reference/`(gitignored)에, 재현 스펙은 `docs/research/linefriends-square/`에 둔다. 스펙 문서는 레퍼런스의 문구·이미지를 옮기지 않고 구조·수치·동작만 기술한다.
