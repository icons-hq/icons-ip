# 그룹상품은 옵션을 별도 상품으로 전환하고 과거 판매 단위는 보존한다

2026-10-14 사용자는 기존 상품과 옵션을 그대로 묶는 대안 대신, 스마트스토어처럼 선택한 옵션을 각각 별도 상품으로 전환하는 방식을 선택했다. 각 판매옵션은 독립된 상품번호와 상세페이지를 가지며, 그룹의 이름과 판매옵션 값으로 함께 탐색한다. 네이버의 검색 노출 그룹·추천 순위·표준 옵션 사전은 제공자 전용 계약이며 이 결정으로 복제하지 않는다.

전환은 상품 복사나 옵션 불러오기와 다르다. 각 원상품에서 첫 번째로 선택한 옵션은 원상품의 번호를 이어받고, 다른 선택 옵션에는 새 상품번호를 부여한다. 선택하지 않은 옵션은 판매에서 제외한다. 그러나 과거 주문·환불·교환·재고 이력이 참조하는 옵션 행은 물리적으로 삭제하거나 다른 상품으로 옮기지 않는다. [ADR-0015](0015-goods-variants.md)의 옵션 정체성과 주문 스냅샷을 보존하면서, 전환 전후 판매 단위와 재고·ERP 연결의 이동을 별도 기록한다.

단순 연결 방식은 과거 참조를 그대로 유지하기 쉽지만 사용자가 요청한 별도 상품·상세페이지·가격 관리가 되지 않아 채택하지 않았다. 반대로 기존 옵션의 소속 상품을 직접 바꾸거나 옵션을 삭제하면 복합 참조와 과거 주문의 의미가 바뀐다. 새 판매 단위를 만들고 과거 단위를 보존하는 비용을 감수한다. 그룹 해제는 분리된 상품을 다시 합치는 역이관이 아니다.

사용자는 별도 상품으로 나뉜 뒤에도 **기존 상품의 합산 조건 유지**를 선택했다. 같은 원상품에서 전환된 판매옵션의 수량은 복수구매 할인·주문 수량 제한·회원 누적 구매 제한·수량별 배송비 계산에서 함께 센다. 과거 구매량도 포함한다. 이 합산 관계는 화면의 그룹 구성과 별개로 유지하며 그룹 해제나 재배치로 할인 조건·구매 제한을 초기화하지 않는다. 원상품의 공통 거래 정책을 한 곳에서 관리하고 각 상품의 실제 가격·재고·주문 상품 식별자는 보존한다. 기존 상품 간 임의의 합산 관계 병합은 이 결정에 포함하지 않는다.

전환 확정 전에는 대상·선택 순서·기존/신규 번호·가격·할당 재고·판매 제외 옵션·복사되는 설정과 재검토할 설정을 비교한다. 같은 작업의 재확인은 원래 결과를 반환하고, 다른 작업자의 수정이나 결제·배송의 미확정 상태가 있으면 자동으로 덮어쓰지 않는다. 새 상품의 공개와 KC 검토는 기존 계약을 따른다. 운영 데이터의 실제 전환이나 배포를 이 결정만으로 실행하지 않는다.

이 문서는 사용자가 선택한 구조를 기록한다. 상세 계약과 구현·검증 상태는 [그룹상품 전환 계약](../research/smartstore-admin/group-product-conversion-contract.md)을 따른다.
