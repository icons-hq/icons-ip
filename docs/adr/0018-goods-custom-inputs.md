# 직접 입력 옵션은 장바구니 행을 구분하고 주문 시 고정한다

- Status: accepted (2026-10-12)
- 관련: [ADR-0015](./0015-goods-variants.md), [ADR-0016](./0016-fulfillment-origins-and-shipments.md)

각인 문구처럼 고객이 입력하는 값은 별도 재고를 가진 옵션이 아니다. 같은 옵션에 서로 다른 문구를 담아도 합쳐지지 않도록 장바구니의 논리 식별자를 사용자·옵션·직접 입력값·정의 버전으로 확장하고, 안정적인 행 ID로 주문에 소비한다. 기존 입력 없는 장바구니 호출은 빈 입력 행만 다루며, 주문 당시 항목명과 입력값은 주문 품목에 불변 스냅샷으로 보존한다.

## 결과

- 상품의 직접입력형 정의는 최대 5개 항목, 항목명 25자, 사용 여부를 갖는다. 사용 중인 항목은 모두 필수이며 고객 값은 항목당 100자까지 받는다. 항목 ID는 이름을 수정해도 유지하고, 정의 변경은 버전을 올린다. 기존 카트는 바뀐 정의를 조용히 적용하지 않고 상품에서 다시 확인하게 한다.
- 같은 옵션·같은 값·같은 버전은 수량을 합치고, 다른 값은 별도 행이다. 행 식별 해시가 같아도 원본 값과 버전이 다르면 덮어쓰지 않는다. 가격·재고·구매 한도는 같은 옵션 또는 굿즈의 모든 행을 합산하며, 기존 가격·배송·쿠폰·적립금 계산을 유지한다.
- 카트와 고객 주문 품목은 안정적인 행 ID와 정확한 개수로 끝까지 조회한다. API의 행 응답 상한으로 일부만 반환되거나 조회 중 행수가 바뀌면 부분 목록을 성공으로 다루지 않는다. 주문 생성은 고객이 확인한 전체 카트와 DB 원본을 같은 잠금 아래 대조하며, 다른 탭에서 바뀐 카트는 다시 확인한다. 이미 생성된 체크아웃 키의 재시도는 새 카트를 소비하지 않고 기존 주문을 반환한다.
- 구매자는 저장된 문구를 장바구니와 주문서에서 확인한다. 주문 생성은 상품·옵션 잠금 아래에서 현재 정의를 재검증하고, 서버가 정의한 항목명과 값을 고정한다. 이후 상품 설정 변경·복사·취소가 주문 문구를 다시 쓰지 않는다.
- 출고 연결과 재고 환원은 주문 품목 ID를 따른다. 같은 옵션이 여러 행이어도 전체 취소 시 각 행의 수량을 한 번씩 환원한다. 취소·반품은 주문 전체·전액으로 처리하고 부분 취소·부분 환불을 도입하지 않는다.
- 주문 순회 전에 대상 굿즈를 정렬해 잠근 뒤 카트 행을 순회한다. 같은 굿즈의 재고 캐시를 갱신하면서 그 굿즈를 반복 잠그는 커서는 일부 행을 건너뛸 수 있으므로 사용하지 않는다.
- 기존 상품 엑셀에는 직접입력형 설정을 추가하지 않는다. 엑셀 저장은 기존 정의를 유지하고, 미리보기 후 정의가 바뀌면 지문 충돌로 거절한다. 상품 복사는 정의를 가져오되 카트나 주문 입력값을 복사하지 않는다.

## 검토한 대안

입력값을 옵션 속성으로 만들면 문구마다 SKU와 재고가 생긴다. 입력값을 기존 옵션별 카트 한 행에 덧붙이면 다른 문구가 합쳐지거나 이전 문구를 덮어쓴다. 두 방식 모두 주문 제작 요청과 실물 재고의 경계를 흐리므로 채택하지 않는다.
