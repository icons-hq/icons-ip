# 스토어 셸·홈·목록·POP-UP·EVENT의 시각 정본을 X SQUARE Figma로 바꾼다

- Status: accepted (2026-11-17) — 신사업팀(김미주 대리)의 2026-11-12 Figma와 "보내주신 피그마 적용" 결정(아래 인용). main 머지와 운영 배포는 별도 승인.
- 대체(일부): [ADR-0011](./0011-lfs-storefront-redesign.md)의 **셸·홈·NEW·BEST·카테고리 목록·이벤트 허브의 시각·IA·수치**. ADR-0011의 금지선(레퍼런스 자산·카피·핑크 재사용 금지)·돈의 경계·나머지 표면(상품 상세·카트·마이·검색·IP관·오프라인 팝업·법적 문서)은 그대로다.
- 관련: [ADR-0044](./0044-retire-goods-type.md)(상품 유형 폐기 — 상품 종류는 카테고리, '타입' 필터는 예약판매만), [ADR-0027](./0027-random-option-sale-goods.md)(랜덤 판매 — '캡슐토이' 칩의 원천), 루트 `DESIGN.md` "X SQUARE 표면(v5)", [카테고리 운영 절차](../runbooks/storefront-categories.md), [X SQUARE 스토어 운영 입력](../runbooks/xsquare-storefront-content.md)

## 맥락

2026-11-12 신사업팀이 공개 스토어프론트의 Figma(프레임 6개: Main·New·Best·Category·POP-UP·Event, 1920 캔버스)를 보냈다. 카톡 원문은 "레이아웃은 픽스고 개체마다 수치만 다듬고 있어서"였고, 같은 날 이사님이 전달한 로고 파일(글자 "X SQUARE")에는 "넵 일단 저거로 메인 로고 바꿀게요~"라고 답했다. 개발 쪽 결정 원문(2026-11-12): "보내주신 피그마 적용, 지금 수정사항 까지 다 반영해서 (회의) 잡는게 좋겠죠?" → 신사업팀 "앗 넹넹!!". 같은 묶음의 요청은 다음과 같다.

- 상단 띠배너는 랜덤 노출, 메인 배너는 일정 시간 뒤 자동 슬라이드.
- POP-UP 화면은 "현재 진행중인 온오프라인 팝업"이 있을 때만 열린다. 이벤트에는 "현재 마케팅 중인 제품이나 IP"가 노출돼야 한다.
- 카테고리는 상품 등록 때 입력하는 분류(문구용품·인형 / 봉제·아크릴·피규어·디지털·홈데코·소형가전·기타)를 쓴다. 나중에 상품 수정 화면에서도 카테고리를 바꿀 수 있어야 한다.
- MD-0034(검색 아이콘을 눌러도 장바구니·마이페이지가 눌려야 함), MD-0035(카테고리에서 쇼핑스토리 항목 삭제).

ADR-0011은 LINE FRIENDS SQUARE 문법을 기준으로 공개 표면을 정했다 — 2단 헤더, 전폭 히어로 홈, 왼쪽 필터가 있는 4열 목록, 단일 brand-green 액센트, radius 0~2의 각진 플랫. Figma는 이 가정과 여러 곳에서 다르다: 1320 컨테이너와 5열 그리드, 1단 헤더와 빨간 롤링 띠, radius 8~18의 둥근 카드와 히어로, 빨강 할인율, 3색 칩, 필터 없는 목록, 새 메뉴(POP-UP·EVENT). 두 문법을 한 화면에서 절충하면 둘 다 어긋나므로 어느 쪽이 정본인지 정해야 했다. 11/12 카톡이 이번에 반영할 범위로 못박은 표면이 이 여섯 프레임이다.

## 결정

1. **여섯 프레임의 시각 정본은 Figma다.** 대상은 셸(롤링 띠배너·유틸 메뉴·1단 헤더·GNB·푸터), 홈, NEW, BEST, 카테고리, POP-UP, EVENT와 그 안의 상품 카드다. 수치는 Figma 덤프(Main `1:3`, New `174:574`, Best `176:3927`, Category `176:5456`, POP-UP `176:6122`, Event `176:4627`)를 따르되, 코드의 정본은 토큰 `--wc-x-*`(`app/styles/wc-foundation.css` `.wc-root`)와 `DESIGN.md`의 새 절이다. 그 밖의 표면은 ADR-0011과 R-스펙을 계속 따른다 — 이번 개편의 상품 카드는 상품 카드를 쓰는 모든 화면(검색·IP관·위시·최근 본 등)에 적용되며, 이 화면들의 나머지 틀은 바뀌지 않는다.
2. **새 토큰·넓은 컨테이너·공용 부품을 둔다.**
   - 토큰은 `--wc-x-` 접두로 `.wc-root`에 추가한다(잉크 `#121212`, 보조 글자, 구분선 4종, 할인율·하트·롤링 띠 색, 칩 3색, 반경 6종).
   - 넓은 컨테이너 `.wc-container.wc-container--wide`는 최대 1320, 데스크톱(≥990) 좌우 24 — 안쪽 폭 1272. 기존 `.wc-container`(1212)는 다른 표면이 그대로 쓴다.
   - 공용 부품은 `components/wc`에 둔다: `ProductCard`(개편)·`ProductGrid`·`SectionHeader`·`StripBanner`·`PromoCard`. 칩 판정은 순수 함수 `lib/product-card-chips.ts` 하나다. 공용 부품 CSS는 `app/styles/wc-storefront-x.css`(`.wc-x-`·`.wc-strip-banner`·기존 `.wc-product-card` 계열 선택자만), 화면 CSS는 `wc-listing.css`·`wc-popups.css`다. 이 파일들은 `wc-inquiry-widget.css` 뒤에 불러 앞선 카드·카탈로그 규칙을 덮는다.
3. **로고와 메뉴.** 메인 로고는 `public/brand/xsquare-logo.png`(X SQUARE)다. 운영자가 어드민에서 올린 로고가 있으면 그게 우선한다. 상호·법정 표기·페이지 제목(`… — ICONS`)·파비콘은 바꾸지 않는다 — 요청은 "메인 로고"뿐이었다. GNB 기본은 NEW · BEST · 카테고리 · POP-UP · EVENT이고, 고정 id `popups`(경로 `/popups`)를 더해 메뉴가 9개가 된다. 온라인 팝업·카드팩·커뮤니티·쇼핑스토리는 기본 숨김이다(MD-0035 — 운영 메뉴 설정에서 다시 켤 수 있다). 옛 8개 저장값은 관용 파싱이 `popups`를 카테고리 바로 뒤에 끼워 읽고, migration이 DB 저장값을 같은 규칙으로 옮긴다.
4. **목록 세 화면(NEW·BEST·카테고리)은 한 틀이다.** 스트립 배너(1272×340) → 제목 + 탭 줄 + 정렬 셀렉트 → 5열 그리드 → VIEW MORE. 정렬은 7종(추천순·인기도순·최신 등록순·판매량순·낮은 가격순·높은 가격순·리뷰 많은순)으로 통일하고 이름순 2종·오래된순은 화면에서 뺀다(URL 호환만 남긴다). **BEST는 기간 판매 랭킹**(실시간·일간·주간·월간, 홈 판매 BEST와 같은 집계 정의)이다. **카테고리는 전시 분류 트리**(이미 메가메뉴·모바일 시트의 원천)이고 칩 1줄(앞 4개)·2줄, 하위 탭을 둔다.
5. **POP-UP과 EVENT는 한 카드 문법의 두 목록이다.** `/popups`는 오프라인 팝업(예매 도메인 `events`)과 POP-UP 캠페인(캠페인 노출 설정에서 POP-UP에 싣기를 고른 것)을 합쳐 진행 중 → 오픈 예정 순으로 보이고, 둘 다 없으면 빈 상태를 보인다. `/events`는 POP-UP이 아닌 진행 중·오픈 예정 캠페인만 3열 카드로 보인다. 어느 쪽에 보일지, 카드가 어디로 갈지는 새 테이블 `campaign_presentations`와 어드민 '노출 설정' 패널이 정한다. 캠페인 본문 저장은 건드리지 않는다.
6. **홈은 기존 큐레이션 종류를 재사용하고 운영 입력이 완성한다.** 새 고정 블록 `new_arrivals`(최신 등록 10개 자동)와 `strip_banner`(옛 공지 배너 `announcement`를 '홈 스트립 배너'로 되살림)를 더하고, 추천 콘텐츠는 'IP 바로가기', 연달아 놓은 기획전 배너는 'ICONS PICK' 카드 줄, 상품 모음에는 '그리드형(5열)'을 더한다. 어느 IP·어느 배너를 보이는지는 운영 데이터라 코드가 정하지 않는다. 옛 블록(카테고리 BEST·인기템·혜택·쇼핑스토리·랭킹·모자이크)은 렌더를 바꾸지 않고, 운영자가 레이아웃 편집기에서 끄면 Figma와 같아진다.
7. **셸 동작.** 텍스트 공지 바는 Figma의 빨간 흐르는 띠이고 같은 화면 후보가 여럿이면 스토어를 새로 열 때마다 하나를 무작위로 보인다. 히어로는 손으로 장을 옮겨도 자동 넘김을 끄지 않는다(일시정지 버튼·hover·포커스·탭 숨김·줄인 움직임에서만 멈춘다). 검색 패널은 비모달이라 딤 위에 밝게 남는 줄(공지 띠·유틸 메뉴·헤더 행)이 열린 채로 눌리고, 그 링크·버튼을 누르면 이동과 함께 패널이 닫힌다(MD-0034).

## 대가

- **"단일 brand-green 액센트·radius 0" 규칙에 표면별 예외가 생긴다.** 이 표면들의 액센트는 초록이 아니라 잉크(`#121212`)이고(GNB 현재 표시는 초록 밑줄 → 잉크 밑줄, 알림·장바구니 배지는 초록 → 잉크), 빨강(롤링 띠·할인율·위시 하트)과 칩 3색(보라·하늘·주황)이 새로 들어온다. 반경은 3~18이다. 같은 사이트 안에서 이 여섯 표면과 상품 상세·카트·마이가 서로 다른 문법을 쓰게 된다 — 통일은 후속 결정이다.
- **Figma 글자색 일부를 WCAG AA로 어둡게 보정했다.** 이 저장소는 DESIGN.md 이래 AA(작은 글자 4.5:1, 비텍스트 3:1)를 지켜 왔고, 배지 글자색을 AA로 내린 선례도 있다. 보정 후에도 육안 차이는 작게 두었다. 값과 대비는 `DESIGN.md` 새 절의 표에 있고, 원본으로 되돌리기로 하면 토큰 한 곳(`--wc-x-*`)만 바꾸면 된다.

  | 쓰임 | Figma 값(대비) | 구현 값(대비) |
  |---|---|---|
  | 보조 글자 | `#888888`(3.5:1) | `#767676`(4.5:1) |
  | 할인율 글자 | `#FF4D4D`(3.3:1) | `#E02424`(4.7:1) |
  | 롤링 띠 바탕(흰 글) | `#EC2227`(4.4:1) | `#E31B23`(4.7:1) |
  | 예약판매 칩 글자 | `#955FCA`(3.8:1) | `#8650BD`(4.6:1) |
  | 무료배송 칩 글자 | `#3485A3`(3.6:1) | `#276E89`(5.0:1) |
  | 캡슐토이 칩 글자 | `#F08418`(2.3:1) | `#A6560B`(4.8:1) |

  위시 하트(`#FF4D4D`)·히어로 화살표(`#888888`)는 비텍스트 3:1을 넘어 그대로 둔다. 하트는 Figma가 원 없는 `#E6E6E6` 채움이라 `#F3F3F3` 썸네일 위에서 1.1:1로 안 보여 흰 원 + 헤어라인 위에 올린다.
- **NEW·BEST·카테고리의 왼쪽 필터(IP·타입·가격)·모바일 필터 시트·수량 줄이 사라진다.** Figma 세 프레임에 없다. `?ip`·`?type`·`?min`·`?max`·`?category` 쿼리는 이 세 화면에서 무시한다. 검색 결과와 IP관 목록은 Figma 범위 밖이라 필터가 있는 기존 본문(`CollectionBrowser`)을 그대로 쓴다.
- **BEST의 정의가 바뀐다.** 지금까지 BEST 화면은 홈 전시관리에서 운영자가 고른 BEST·인기템 큐레이션 순서였고, 이제 기간 판매 랭킹이다(Figma 탭이 실시간/일간/주간/월간이다). 운영자가 고른 순서는 홈 밴드로만 남는다. 판매 랭킹은 결제 승인 증거가 있는 주문만 세므로 운영 DB의 시뮬레이션 가주문(태그 `hsq-ops-2026-10`)이 승인 상태면 BEST·판매량순·인기도순이 왜곡된다 — 정리 확인은 사람 게이트다. 성인(19금) 굿즈는 랭킹·정렬에서 빠진다.
- **NEW에는 정렬 셀렉트가 없다.** 탭 줄 자체가 정렬이라 같은 차원을 두 번 고르지 않게 했다(Figma NEW의 셀렉트는 BEST·카테고리 머리 틀을 복사한 흔적으로 읽음 — MD 회의에서 확인할 항목).
- **'캡슐토이' 칩은 랜덤 판매 굿즈 전부에 붙는다.** Figma 샘플이 랜덤 상품마다 붙였기 때문이다. 홍실 랜덤 포토카드처럼 캡슐토이가 아닌 랜덤 상품에도 붙으므로 문구를 '랜덤'으로 바꿀지는 확인 대기다.
- **홈이 Figma와 같아지려면 운영 입력이 필요하다.** 히어로 2장 이상·IP 바로가기 4개·홈 스트립 배너·그리드형 모음·ICONS PICK 3개·영역 순서·롤링 공지 문구를 사람이 넣어야 한다(운영 절차에 있다). 코드만 배포하면 운영 홈은 지금 데이터로 새 틀에 그려진다.
- **DB 변경이 따른다.** migration 8개(내비 9개 id, 홈 블록 키·그리드형 검증, 목록 정렬·BEST 랭킹 RPC 2종, 카테고리 전시 정렬 3종 패치와 그 세 정렬의 VIEW MORE 토큰을 순위가 아닌 구성으로 계산하는 패치, `campaign_presentations`와 저장 RPC·공개 열 grant·바로가기 검증, 전시 투영의 카드 칩 필드). 공개 정렬 RPC는 사람마다 같은 값이라 anon에 열되 정렬된 id 배열만 돌려주고 판매·위시 원수치를 공개하지 않는다.
- **칩·상품 카드가 모든 화면에 퍼진다.** 상품 카드의 새 모양(하트 우하단·할인율 빨강·취소선 정가 없음·칩 줄)이 검색·IP관·위시·최근 본 상품에도 적용된다. 이 화면들의 시각 검수는 개편 범위에 포함해야 한다.

## 후속

- **전역 액센트 결정** — 이 여섯 표면의 잉크 액센트와 나머지 표면의 brand-green을 통일할지(어느 쪽으로, 언제). 결정 전까지 DESIGN.md는 표면별 예외로 기록한다.
- **공지 게시판** — Figma 유틸 메뉴·푸터의 '공지사항'. 게시판 화면이 없어 지금은 그리지 않는다(알림함은 개인 알림이라 같은 것이 아니다).
- **서비스 가이드라인** — Figma 푸터 항목. 문서를 받으면 `/legal/[document]`에 슬러그를 더한다. 그때까지 그리지 않는다.
- **X(구 트위터) SNS** — 푸터 아이콘. 브랜딩 설정의 플랫폼 목록에 없어 추가하려면 `private.store_branding_valid`까지 바꾼다. 인스타그램·블로그·페이스북은 브랜딩 설정에서 켠 것만 보인다.
- **상호·페이지 제목 표기** — `… — ICONS` 접미사·파비콘·`ICONS` 법정 표기를 X SQUARE로 바꿀지(상호 변경이면 법정 문서·사업자 정보와 함께 판단). 푸터 사업자 이메일(Figma `xsquare@…`)과 대표 SNS 주소는 어드민 입력이다.
- **Figma 범위 밖 화면** — 검색 결과·IP관 목록(필터 있는 본문)·상품 상세·카트·마이의 Figma 적용 여부.
- 죽은 코드 정리 — 옛 컬렉션 배너 규칙·카테고리 전시 내비 읽기 경로 등 후보는 통합 메모에 있다.
