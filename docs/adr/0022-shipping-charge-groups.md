# 배송비 묶음그룹을 구매 합산군과 물리 배송 건에서 분리한다

- Status: accepted (2026-10-14)
- 관련: [공통 주문 구조](0020-goods-transaction-sources.md), [그룹 전환](0021-group-products-from-variants.md), [배송비 묶음그룹 계약](../research/smartstore-admin/shipping-charge-groups-proposal.md)

서로 다른 굿즈에 최소·최대 배송비와 무료 우선 규칙을 적용하려면 재편성 가능한 요금 그룹이 필요하다. 전시 그룹상품을 재사용하면 전시 변경이 결제금액을 바꾸고, 영구 구매 합산군을 재사용하면 배송 설정이 할인·구매 제한의 정체성까지 바꾼다. 따라서 같은 주문·출고지 안의 배송비 묶음그룹을 별도로 두고, 구매 합산군의 정책 소유 상품에 배정한다. 명시 배정된 실제 선택의 전체 수량·기간 할인 후 소계로 배송 후보를 평가하며, 그룹 기본료는 기존 소계 우선·수량 대체의 정수 배분으로 나눈다. 선결제와 착불은 그 배분 이후 분리한다. 미배정 상품의 기존 계산과 과거 확정 주문은 유지한다.

지역 추가료는 출고지 정책 상속 또는 명시 그룹 정책으로 나눈다. 명시 그룹의 상품은 출고지 지역료 대상에서 제외하고 그룹당 한 번 부과하며, 상속 상품은 기존 출고지의 부과 단위를 유지한다. 이는 요금 그룹마다 물리 배송 건을 만드는 대안보다 현재 운송장·재고 인계·전체 환급 계약을 보존한다. 신규 계산의 여러 지역 정책은 별도 스냅샷 형식으로 기록하고, 단일 출고지 정책 필드로 위장하거나 과거 형식으로 조용히 읽지 않는다. 기본 그룹 변경은 기존 상품을 이동시키지 않으며, 사용 중지·보관은 연결 상품을 먼저 명시 해제하거나 이동한 뒤 수행한다. 운영 배포·실제 지역표·금액·수납 계약의 적용은 이 구조 결정과 별도다.
