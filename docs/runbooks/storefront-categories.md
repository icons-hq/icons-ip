# 카테고리 전시·분류 반영 (X SQUARE 개편)

2026-11-17 · [ADR-0043](../adr/0043-xsquare-figma-storefront.md) · 신사업팀 김미주 대리의 카테고리 분류(2026-11-12 카톡·Figma Category 프레임)

고객이 보는 카테고리 화면(`/shop` 칩·하위 탭, `/shop?displayCategory=<id>`)은 **전시 분류**(`/admin/display/categories`)의 트리를 그대로 읽는다. 상품 등록 화면의 **상품 분류**(`/admin/catalog/categories`, 대표·추가 카테고리와 상품 유형 연결)는 전시 분류와 독립이다. 코드는 이 분류를 시드로 넣지 않는다 — 운영 데이터라서 아래 순서로 사람이 입력한다. 어느 단계가 빠지면 화면이 비거나 상품이 공개되지 않는다.

## 반영할 분류

| 칩 줄 | 1단계(트리 순서) | 2단계 |
|---|---|---|
| 1줄 | 문구용품 | 다이어리 / 캘린더 / 플래너 · 스티커 · 노트 / 메모지 · 카드 / 봉투 / 포스터 · 필기류 · 데스크 용품 |
| 1줄 | 인형 / 봉제 | — |
| 1줄 | 아크릴 | — |
| 1줄 | 피규어 | — |
| 2줄 | 디지털 · 홈데코 · 소형가전 · 기타 | — |

- 칩 영역은 맨 앞에 코드가 '전체' 칩(→ `/shop`)을 붙이고, 전시 트리의 1단계를 **트리 순서대로** 앞 4개는 1줄(18 SemiBold), 5번째부터는 구분선 아래 2줄(15 SemiBold)에 놓는다. 1단계가 4개 이하이면 한 줄만 보인다. 어느 줄에 놓일지는 순서로만 정한다 — 위 표의 순서대로 만든다.
- 2단계는 고른 1단계의 하위 탭이 된다. 코드가 맨 앞에 '전체' 탭(그 1단계 자체)을 붙이므로 '전체'라는 분류를 따로 만들지 않는다.
- 이름은 전시 분류 생성 한도(20자)를 모두 지킨다. 새 분류는 최대 3단계, 최상위 19개·각 상위 아래 15개까지다.

## 1. 고객 카테고리 공개 스위치 확인

`/admin/catalog/categories` → **활성화 상태** 카드(최고 관리자 `platform.manage`에게만 보인다)가 '고객 화면 적용 중'인지 확인한다. '고객 화면 미적용'이면 펼쳐서 고객 분류 근거(출처·참조·검증 시각)를 입력하고 **활성화 상태 저장**을 누른다. 실제 이름·코드·카테고리 구조와 운영 확인 근거가 없으면 켜지지 않는다.

꺼져 있으면 전시 트리는 고객에게 보이지 않는다 — 카테고리 화면은 칩·하위 탭 없이 `/shop` 전체 목록만 보이고 PC 메가메뉴·모바일 카테고리 시트는 기존 메뉴로 돌아간다. 켜기·끄기는 저장 즉시 공개 메뉴에 반영된다(캐시 태그 만료).

## 2. 전시 분류 만들기

`/admin/display/categories`(`store.manage`)에서 위 표의 1단계 8개를 칩 순서대로 만들고, 문구용품 아래 2단계 6개를 만든다. 순서는 위·아래 이동으로 정하며 이 순서가 곧 칩 순서다. 만들 때 이름을 그대로 입력하고(`/`·공백 포함), 저장 뒤 트리 순서가 표와 같은지 확인한다. 전시 이름·계층을 바꿔도 상품의 카테고리·ERP 정보·상품속성은 바뀌지 않는다.

## 3. 구성 켜기와 배너

각 전시 노드마다 구성(상품 연결·배너)을 켠다.

- 상품 연결: **상품 분류 최대 10개**(하위·추가 분류 포함) 또는 **수동 상품 최대 1,000개** 중 하나를 고른다. 두 방식의 선택은 보존되고 지금 고른 방식만 공개된다.
- 배너(선택): PC 이미지 하나와 선택적 모바일 이미지. 고객 화면은 1272×340(모바일 375×175) 스트립 배너로 그리므로 PC는 **2544×680**, 모바일은 **750×350**을 권장한다. 문구(제목·내용)는 이미지에 넣지 말고 배너 문구 칸에 입력한다. 배너가 없으면 배너 없이 시작한다(가짜 자리는 없다).
- 영상·추천상품(선택): 켠 경우에만 칩 영역과 제목 줄 사이에 보인다.
- `/shop`(전체 굿즈)의 맨 위 배너는 전시 노드가 아니라 홈 전시관리의 컬렉션 배너(굿즈샵 전체 슬롯, 최대 10장 슬라이드)다. 권장 크기는 NEW·BEST와 같은 **2544×680**이다. 어드민의 컬렉션 배너 안내 문구에 이전 치수(2880×1160·2360×520)가 남아 있으면 새 틀에서는 이 치수를 따른다.

구성을 켜지 않았거나 공개 상품이 없는 노드는 이름만 남는다. 칩 링크는 그 노드가 이동 가능할 때 그 노드로, 아니면 트리 순서상 첫 이동 가능한 하위로 가며, 자손에도 없으면 칩이 그려지지 않는다. 칩이 빠져 있으면 먼저 구성과 공개 상품을 확인한다.

## 4. 상품 분류·유형 연결 (상품 등록 카테고리를 같은 분류로 쓸 때)

상품 등록의 대표·추가 카테고리도 같은 분류로 쓰려면 `/admin/catalog/categories`에서 만든다.

1. **경로 붙여넣기**에 `>` 구분으로 한 줄씩 붙여 일괄 만든다(이름에 `/`는 쓸 수 있고 이름 하나는 120자 이내). 예:

   ```
   문구용품>다이어리 / 캘린더 / 플래너
   문구용품>스티커
   문구용품>노트 / 메모지
   문구용품>카드 / 봉투 / 포스터
   문구용품>필기류
   문구용품>데스크 용품
   인형 / 봉제
   아크릴
   피규어
   디지털
   홈데코
   소형가전
   기타
   ```

2. 각 분류(또는 상위)에 **상품 유형**을 연결한다([ADR-0037](../adr/0037-goods-type-from-category.md)). 권장: 문구용품 = 문구, 인형 / 봉제 = 인형, 아크릴 = 아크릴, 피규어 = 피규어, 디지털·홈데코·소형가전·기타 = 기타. 연결이 없으면 그 분류를 대표 카테고리로 쓰는 상품은 공개할 수 없다. 상품 유형은 표준 9종(피규어·인형·키링·아크릴·문구·쿠션·파우치·세트·기타) 안에서 고른다.
3. 전시 구성의 원천으로 상품 분류를 쓰는 노드는 이 분류가 있어야 한다. 수동 상품으로 구성하면 필요 없다.

## 5. 상품 옮기기와 KC 재검토

상품 수정 화면의 대표 카테고리를 바꾸거나, 카테고리 관리의 **굿즈 기본 카테고리 적용**으로 대표 분류를 바꾼다. 추가 카테고리는 유형과 무관해 공개 중에도 바뀐다.

- 초안 상품은 언제든 바뀐다. 유형이 바뀌면 KC 검토가 미검토로 돌아가므로 다시 검토한 뒤 공개한다.
- **공개 중 상품은 유형이 같은 카테고리로만** 그대로 저장된다. 유형이 바뀌는 이동(예: 키링 → 아크릴)은 저장 전에 화면이 막고 서버도 막는다(ADR-0037, KC 재검토 안전장치). 이때 카테고리 오류 바로 아래의 **초안으로 전환하고 카테고리 바꾸기** 버튼을 누르면 확인창 한 번으로 초안이 되고, 고른 카테고리 값은 그대로 남아 같은 화면에서 저장할 수 있다. 저장 뒤 KC를 다시 검토하고 공개한다.
- 유형을 지키려면 하위 분류를 둔다. 예: `아크릴>아크릴 키링`에 유형 '키링', `인형 / 봉제>인형 키링`에 '키링'을 연결하면 키링은 아크릴·인형 분류에 속해도 유형이 키링으로 남는다.
- 그룹상품 소유 상품은 그룹 공통 편집에서 바꾼다(상품 수정 화면에서는 잠긴다).

## 6. 반영 확인

전시 트리·구성·배너·아이콘 저장과 공개 스위치 전환은 공개 메뉴에 즉시 반영된다. 상품 공개·판매 제한 변경과 캠페인·피처드 IP 변경은 최대 300초(5분) 뒤에 반영될 수 있다. 확인 순서:

1. 고객 사이트 `/shop` — 칩 1줄(앞 4개)·2줄이 표의 순서이고 '전체' 칩이 선택돼 있다.
2. 문구용품 칩 — 하위 탭 '전체' + 6개, 배너, 정렬 셀렉트, 5열 그리드.
3. 하위 탭 하나(`?displayCategory=<id>`) — 선택 표시(`aria-current`)와 3단계 이름 줄('› 이름').
4. 모바일 375px — 칩·탭이 가로 스크롤, 2열 그리드. PC 메가메뉴·모바일 카테고리 시트의 전시 분류.
5. 상품 하나를 옮긴 뒤 해당 칩 목록에 나오는지(5분 안).

문제가 있으면: 칩 영역이 비어 있다 → 1번(공개 스위치)·공개 전시 존재 여부 / 칩 한 개만 없다 → 그 노드 구성이 꺼졌거나 공개 상품이 없다 / 상품이 안 나온다 → 상품·IP 공개 상태, 판매 제한(성인 상품은 카테고리 전시에서 성인 인증 회원에게만), 원천 분류 연결 / 하위 탭이 없다 → 2단계가 없거나 이동 가능한 하위가 없다.
