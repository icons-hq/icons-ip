# 반품배송비 차감 — 켜는 순서·확인·끄기

결정: [ADR-0031](../adr/0031-return-fee-deduction-partial-refund.md). 단순 변심 반품의 반품배송비(편도, 최초 무료배송이면 왕복)를
환불금에서 빼고 토스 부분 취소(무통장은 송금액)로 돌려준다. **스위치는 꺼진 채 배포됐다.** 꺼져 있으면 모든 화면·금액·원장·결제사
호출이 이전과 같다.

## 켜기 전 사람 게이트(다섯 개 모두)

| # | 게이트 | 누가 | 확인 방법 |
|---|---|---|---|
| 1 | 토스 상점 부분 취소 사용 | 결제 담당 | 결제 어드민(테스트·라이브)에서 ICONS 상점(MID `iconsi0xvd`·`iconsi8sr4`)의 부분 취소 사용 여부를 확인하고, 테스트 키로 부분 취소 1건을 실제로 성공시킨다(아래 '테스트 키 리허설') |
| 2 | 나이스페이 부분 취소 계약 | 결제 담당 | 계약 전에는 나이스페이 결제의 반품을 차감하지 않는다(자동). 계약 뒤 어댑터를 고치는 별도 작업이 필요하다 — 이 게이트는 켜기를 막지 않지만, 나이스페이 결제의 반품은 계약 전까지 전액 환불이라는 점을 CS에 공지한다 |
| 3 | 반품배송비 금액(운영값, 편도) | 운영 책임자 | 서원 착불 운임과 상품 상세의 '고객 귀책 반품비(편도)' 표기와 같은 금액이어야 한다(아래 대조 쿼리) |
| 4 | 배송·반품 정책 문서 개정 공지 | 운영 책임자 | 아래 '정책 문서 개정 초안'을 법률 문서에 반영하고 시행 7일 전에 공지한다. 이 런북은 공개 법률 문서를 고치지 않는다 |
| 5 | 서원 착불·불량 반품 운임 정산 계약 | 물류 담당 | 서원 회신 G2 "별도계약이 필요합니다". 단순 변심 착불은 ICONS가 차감해 받고, 불량은 물류에서 지급하는 구조를 계약으로 확정한다 |

## 금액 대조(켜기 직전, 읽기 전용)

상품 상세는 상품별로 '고객 귀책 반품비(편도)'와 '최초 무료배송 후 반품비(왕복)'를 보인다. 정책 금액과 다르게 표기된 공개 상품이
있으면 고지와 차감이 어긋나므로 먼저 맞추거나 비운다.

```sql
-- 정책 금액(편도)을 :one_way로 넣는다.
select id, name, claim_return_fee, claim_return_free_shipping_fee
from public.goods
where published_at is not null and archived_at is null
  and ((claim_return_fee is not null and claim_return_fee <> :one_way)
    or (claim_return_free_shipping_fee is not null and claim_return_free_shipping_fee <> :one_way * 2))
order by id;
```

## 켜기(후속 migration)

운영 DB 직접 수정이 아니라 새 migration으로 켠다(감사 기록 `system.return_fee_deduction.settings_changed`가 남는다).

```sql
update private.return_fee_deduction_settings
set enabled = true,
    one_way_amount = 3000,                       -- 게이트 3의 운영값
    evidence = '배송·반품 정책 개정 공지 2026-MM-DD, 서원 운임 계약 2026-MM-DD',
    enabled_at = now()
where singleton;
```

켜는 PR에서 함께 한다.

- 반품 접수 안내 연결: `components/orders/OrderClaimRequest.tsx`가 `ORDER_CLAIM_INTAKE_NOTICES.return` 대신
  `orderClaimIntakeNotice('return', policy)`를 쓰고, 정책은 `loadReturnFeeDeductionPolicy()`(공개 RPC
  `get_return_fee_deduction_policy`)로 읽는다. 상품 상세 '반품/교환 안내'(`components/shop/GoodAdditionalInfo.tsx`)의
  반품비 문구도 같은 정책을 가리키게 한 줄 잇는다.
- 운영 가이드(`lib/admin/guide/topics/claims.ts`)·주간 변경 기록에 아래 '켤 때 넣을 문장'을 넣는다.

## 켠 뒤 처리 흐름

- **카드(토스)**: 반품 상세 환불 단계에 '반품배송비 3,000원 차감, 환불 27,000원'이 보인다. [환불 접수]가 이 금액을 정하고(접수 뒤에는 바뀌지 않는다),
  [환불 완료 확정]이 토스 부분 취소 → 사후 조회 잔액 확인 → 주문 취소·재고 복원·카드팩 회수 → 환불 원장 27,000원을 끝낸다. 카드 부분 취소는
  카드사 처리에 영업일 3~4일이 걸린다(고객 알림에 적힌다).
- **결제사가 부분 취소를 받지 않는 결제**(가상계좌·`isPartialCancelable=false`·과세 제외 금액): 돈이 움직이기 전에 차감을 전액 환불로 돌리고
  전액 취소한다. 상세에 '차감 없음 · 결제사 부분 취소 불가로 전액 환불'이 남는다. 반품배송비가 필요하면 배송비 청구로 따로 받는다.
- **차감하지 않는 판정**(나이스페이·코페이·선물 주문·같은 요청에 배송비 청구가 있음·반품배송비 ≥ 결제액): 환불 단계에 이유와 배송비 청구 안내가 보인다.
- **무통장**: [계좌 송금 접수 기록]이 금액을 정하고, 송금 대기 목록·송금 엑셀·송금 완료 확인이 모두 '결제액 − 차감액'이다.
- **일괄 환불 확인창**: 행마다 '반품배송비 N원 차감'과 차감 뒤 합계가 보인다.
- **하자·오배송 반품·교환·취소**: 차감 칸이 없다.

## 이상 신호와 조치

| 코드·화면 | 뜻 | 조치 |
|---|---|---|
| `provider_balance_mismatch`(결제사 잔액이 예상과 다릅니다) | 토스 잔액이 차감 결정의 기대값과 다르다 — 상점관리자에서 따로 취소했거나 다른 취소가 끼어들었다 | 결제 어드민에서 취소 내역을 대조한다. 다시 눌러도 같다. 결제 담당에게 넘긴다 |
| `provider_cancellation_incomplete` | 취소 API는 200인데 사후 조회 잔액이 그대로 | 잠시 뒤 다시 확정한다. 같은 멱등키라 중복 취소되지 않는다 |
| `refund_deduction_evidence_required`(DB) | 부분 취소 확인 없이 확정하려 했다 | [환불 완료 확정]을 다시 누른다(결제사 조회가 이미 반영된 취소로 수렴한다) |
| 결제확인필요 뒤 전액 취소를 원함 | 차감을 정한 요청은 금액이 바뀌지 않는다 | 고객과 합의해 전액 환불이 필요하면 부분 취소 뒤 남은 반품배송비를 상점관리자에서 따로 취소하고 원장을 대조한다(개발 담당과 함께) |

## 끄기

```sql
update private.return_fee_deduction_settings set enabled = false where singleton;
```

새 판정은 바로 멈춘다. **이미 환불 접수로 정한 요청은 정한 금액 그대로 진행한다**(부분 취소가 이미 나갔을 수 있다). 그 요청을 전액으로 바꾸려면
위 표의 마지막 행처럼 사람이 결제사와 원장을 함께 맞춘다.

## 테스트 키 리허설(게이트 1)

테스트 키 환경에서 30,000원(배송비 3,000원 포함) 카드 주문 → 배송완료 → 단순 변심 반품 → 회수 확인 → 환불 접수 → 환불 완료 확정.
확인: 결제 어드민의 그 결제가 `PARTIAL_CANCELED`·잔액 3,000원, 취소 내역 27,000원 1건 / 클레임 상세 환불 기록 27,000원·반품배송비 3,000원 차감 /
구매자 주문 상세 '반품배송비 3,000원 차감, 환불 27,000원' / 같은 요청의 [환불 완료 확정]을 다시 눌러도 취소가 늘지 않는다.

## 켤 때 넣을 문장(가이드·주간 변경 기록)

- 가이드 클레임 처리: "단순 변심 반품은 반품배송비(편도 N원, 최초 무료배송 주문은 왕복)를 환불금에서 빼고 토스 부분 취소로 돌려줍니다. 금액은 [환불 접수]를 기록할 때 정해집니다. 결제사가 부분 취소를 받지 않는 결제와 나이스페이·코페이·선물 주문은 차감하지 않고 전액 환불하며, 반품배송비는 배송비 청구로 따로 받습니다."
- 주간 변경 기록: "단순 변심 반품의 반품배송비를 환불금에서 빼고 돌려줍니다(토스 부분 취소·무통장 송금액). 반품 상세 환불 단계와 일괄 환불 확인창에 차감액과 환불액이 보입니다."

## 정책 문서 개정 초안(게이트 4 — 사람이 법률 문서에 반영·공지)

> 단순 변심으로 인한 반품의 경우 반품 배송비(편도 N원, 최초 배송비가 무료였던 주문은 왕복 N×2원)는 구매자가 부담하며, 환불 금액에서 차감합니다.
> 상품의 하자·오배송 등 판매자 귀책 사유로 인한 반품은 차감하지 않습니다. 결제 수단이 부분 취소를 지원하지 않는 경우에는 결제 금액 전액을
> 환불하고 반품 배송비를 별도로 안내합니다. 카드 부분 취소는 카드사 처리에 영업일 기준 3~4일이 소요될 수 있습니다.
