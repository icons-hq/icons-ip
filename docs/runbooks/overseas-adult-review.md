# 해외 신분증 성인 인증 운영

해외 거주로 국내 휴대폰 본인확인이 어려운 회원은 마이페이지 → 성인 인증 → 해외 신분증으로 신청에서 거주국 발급 신분증 사본을 제출한다. [치지직 해외 거주자 안내](https://help.naver.com/service/30044/contents/22840)에 따라 증명사진을 가린 외국 발급 여권·운전면허증·거주허가증 등 유효한 문서를 심사한다. 고객이 입력한 영문 이름과 성별 표기는 사본과 함께 암호화해 한 번 확인한다. 가입 생년월일은 다시 입력하지 않는다. 가입을 완료하면 회원이 생년월일을 변경하거나 비울 수 없고, 정정은 개인정보처리방침의 문의 창구에서 처리한다. 파기 확인 뒤 승인된 계정은 1년간 모든 19금 상품을 이용한다. 다른 계정의 국내 본인확인 DI나 재발급 여권을 연결할 공통 값은 없고, 입력한 이름과 성별을 별도 프로필이나 결과 기록에 남기지 않는다. 새 국내 인증은 그 계정의 수동 증거를 회수한다.

## 접수를 열 때

1. 운영 책임자가 정식 오픈 전이고 실고객이 없음을 확인해 개인정보처리방침에 2026-11-26부터 해외 신분증 심사를 반영했다. 신청 화면과 사진 제출 전 별도 동의에 같은 범위를 안내한다.
2. 성인 상품 공개 설정이 켜져 있고 심사 가능한 관리자 계정이 있으면 접수가 열린다. 고객은 가린 사본과 본인확인정보를 한 화면에서 제출한다. 파일을 고르거나 페이지를 열기만 하면 신청 기록이 생기지 않는다. 상품을 추가하거나 수정할 때 별도로 지정할 작업은 없다.
3. 관리자는 고객관리 → 해외 성인 인증에서 심사한다. 기존 권한 체계에서는 관리자, 매니저 역할을 설정한 곳에서는 통합 매니저와 계정 주매니저가 처리한다. 본인 신청은 다른 관리자가 처리한다. 로그아웃하거나 권한을 잃으면 진행 중인 사진 열람과 결정도 종료된다.

## 접수와 파기

회원당 진행 중 한 건과 24시간당 세 번까지 허용한다. 제출 시점부터 24시간 뒤 만료된다. 영문 이름·생년월일·성별·발급 국가와 기관·유효기간을 남기고 증명사진·주소·문서번호·서명·바코드·여권 기계판독영역을 가린다. 고객은 미리보기에서 추가로 가릴 수 있다. 서버는 이미지를 검증·재인코딩하고 사본과 입력한 영문 이름·성별을 함께 암호화한다. 이미 발급된 미제출 신청은 새 동의로 제출할 때 이어 쓰며, 같은 제출을 재전송하면 새 신청을 생성하지 않는다.

심사자는 최대 5분 동안 한 번 열어 외국 발급·유효기간·가림 상태와 사본의 영문 이름·성별이 신청인 입력과 일치하는지 확인한다. 사본의 생년월일을 입력하면 DB가 가입 생년월일과 대조하고 한국 시간 연 나이 기준으로 판정한다. 가린 사본과 신청 정보의 일치를 확인하는 서류 심사이며, 발급 기관이 현재 신청자의 문서 소유권을 인증한 것은 아니다. 대조가 어렵거나 문서 도용이 의심되면 승인하지 않고 반려한다. 변경 전에 제출된 자료는 당시 동의한 확인 방법으로 마무리한다. 심사 창을 숨기거나 벗어나면 자료 열람이 종료된다.

결정·취소·만료 시 열람을 닫는다. AES-256-GCM 키는 요청별 난수 두 개로 파생한다. 하나는 private DB 행에, 다른 하나는 비공개 Storage 객체의 암호문에 있다. 결정 시 DB 조각을 없애고 Storage API로 객체를 삭제한다. DB가 객체 메타데이터의 부재를 확인한 뒤에만 승인한다. 버킷 이름은 `overseas-adult-evidence`다. 객체 버전 보관·별도 복제·백업을 켜면 파기 보장이 바뀌므로 이 버킷에는 적용하지 않는다. DB 백업만으로는 사진을 복호화할 수 없다.

매분 파기 작업이 기한 지난 신청·중단된 업로드·결정이 접수된 신청을 회수한다. 실패 건은 재시도하고 시스템 상태의 ‘해외 성인 인증 사진 파기’에 실패를 기록한다. 장애 중에는 사진을 재열람하거나 파기 완료를 수기로 표시하지 않는다. 복구 후 해당 작업의 성공, 객체 부재, 파기 확인 시각을 확인한다. 승인 기록은 1년, 나머지는 30일이며 탈퇴 시 신청자의 계정 연결을 제거한다. 고객·심사자의 사진과 생년월일 원문은 상담 메모나 장애 로그에 남기지 않는다.
