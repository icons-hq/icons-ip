# 해외 신분증 성인 인증 운영

해외 거주 회원은 마이페이지 → 성인 인증 → 해외 신분증으로 신청에서 본인의 해외 발급 신분증 사진 한 장을 제출한다. 신청서에 이름·생년월일·성별을 입력하거나 얼굴과 코드를 촬영하는 단계는 없다. 담당자가 사진의 발급 국가·기관·유효기간과 생년월일을 확인한다. 가입을 완료한 회원은 가입 생년월일을 직접 변경하거나 비울 수 없으며, 정정은 개인정보처리방침의 문의 창구에서 처리한다. 승인 및 파기 확인 뒤 해당 계정은 1년간 모든 19금 상품을 이용한다.

## 접수를 열 때

1. 운영 책임자가 정식 오픈 전이고 실고객이 없음을 확인해 개인정보처리방침에 2026-11-26부터 해외 신분증 심사를 반영했다. 신청 화면과 사진 제출 전 별도 동의에 같은 범위를 안내한다.
2. 성인 상품 공개 설정이 켜져 있고 심사 가능한 관리자 계정이 있으면 접수가 열린다. 고객은 사진을 선택하고 수집 안내를 확인한 뒤 동의하고 제출한다. 파일을 고르거나 페이지를 열기만 하면 신청 기록이 생기지 않는다. 상품을 추가하거나 수정할 때 별도로 지정할 작업은 없다.
3. 관리자는 고객관리 → 해외 성인 인증에서 심사한다. 기존 권한 체계에서는 관리자, 매니저 역할을 설정한 곳에서는 통합 매니저와 계정 주매니저가 처리한다. 본인 신청은 다른 관리자가 처리한다. 로그아웃하거나 권한을 잃으면 진행 중인 사진 열람과 결정도 종료된다.

## 접수와 파기

회원당 진행 중 한 건과 24시간당 세 번까지 허용한다. 사진에는 생년월일, 발급 정보와 표시된 유효기간이 보여야 한다. 한국 발급 문서·한국 주민등록번호가 보이는 자료는 받지 않는다. 해외 여권·운전면허·거주허가 문서번호가 보이는 사진은 해당 번호의 임시 처리에 별도 동의를 받는다. 번호가 없는 사진을 제출하는 선택지도 제공한다. 서버는 사진 형식·크기·해상도를 확인하고 메타데이터를 제거해 암호화한다. 제출 전에는 사진을 서버로 보내지 않는다. 미제출 상태의 기존 신청은 새 동의로 이어 쓰며 같은 제출의 재전송은 새 신청을 만들지 않는다.

심사자는 접수번호를 선택해 한 번, 최대 5분 열람한다. 유효한 외국 발급 문서인지 확인하고 사진에 적힌 생년월일을 입력하면 DB가 가입 정보와의 일치 및 한국 시간 연 나이 기준을 판정한다. 한국 주민등록번호나 제출 동의 범위를 벗어난 정보가 보이거나, 판독이 어렵거나 도용이 의심되면 즉시 반려해 열람을 끝내고 파기한다. 문서번호나 사진 속 개인정보를 복사하지 않는다. 이것은 제출 사진과 회원 기록의 대조이며 발급 기관이 신청자의 문서 소유를 별도로 인증하는 절차는 없다. 이전 방식으로 이미 제출한 자료만 해당 동의 판의 방법으로 심사한다.

결정·취소·만료 시 열람을 닫는다. AES-256-GCM 키는 요청별 난수 두 개로 파생한다. 하나는 private DB 행에, 다른 하나는 비공개 Storage 객체의 암호문에 있다. 결정 시 DB 조각을 없애고 Storage API로 객체를 삭제한다. DB가 객체 메타데이터의 부재를 확인한 뒤에만 승인한다. 버킷 이름은 `overseas-adult-evidence`다. 객체 버전 보관·별도 복제·백업을 켜면 파기 보장이 바뀌므로 이 버킷에는 적용하지 않는다. DB 백업만으로는 사진을 복호화할 수 없다.

매분 파기 작업이 기한 지난 신청·중단된 업로드·결정이 접수된 신청을 회수한다. 실패 건은 재시도하고 시스템 상태의 ‘해외 성인 인증 사진 파기’에 실패를 기록한다. 장애 중에는 사진을 재열람하거나 파기 완료를 수기로 표시하지 않는다. 복구 후 해당 작업의 성공, 객체 부재, 파기 확인 시각을 확인한다. 승인 기록은 1년, 나머지는 30일이며 탈퇴 시 신청자의 계정 연결을 제거한다. 고객·심사자의 사진과 생년월일 원문은 상담 메모나 장애 로그에 남기지 않는다.
