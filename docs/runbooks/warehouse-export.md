# 출고지시와 운송장 회신 (#429)

출고지 설정의 양식에 따라 `/admin/sales/dispatch`의 XLSX·CSV 출력이 달라진다. 일반 양식은 기존 12열에 옵션코드를 선택적으로 추가하고 헤더·순서를 조정한다. 김포 WMS와 서원 우체국은 제공된 양식의 열과 순서를 고정한다. 여러 출고지는 XLSX의 별도 시트로 내보내며 CSV는 출고지를 하나 선택해야 한다. 파일 생성이 실패하거나 배송 상태가 변경되면 출고지시 전달 시각을 기록하지 않는다.

## 제공 원본과 적용 범위

2026-09-08 사용자가 제공한 다음 두 원본을 읽기 전용으로 대조했다. 고객 행은 저장소와 테스트에 반입하지 않았다.

| 원본 | 헤더 범위 | SHA-256 |
|---|---|---|
| `260908_우체국 송장 입력 양식.xlsx`의 `송장양식` | A1:G1, 7열 | `f7442d08afadfd91f403093a7828b0cc3a14f03af384ae572e5c30dcf645b0fc` |
| `20260907_주문서확인처리_김포 물류 송장 출력 전용.xlsx`의 동명 시트 | A1:U1, 21열 | `f9c9e660ebcb82c47fd9e10415b172cf6c4196810cfaed69ad2279792c380a02` |

정확한 헤더 목록은 `lib/admin/warehouse-templates.ts`에 있다. 출력 파일은 원본의 고객 데이터·빈 추가 시트·서식을 복제하지 않는다. 식별자·전화번호·우편번호·운송장은 문자열을 유지하고, CSV의 수식 시작 문자는 보호한다.

## 값 매핑

- **김포 21열:** 상품·옵션명과 할인 전 단가는 주문 당시 스냅샷이다. `주문번호(쇼핑몰)`에는 ICONS 전체 주문 UUID를 유지한다. 수취인명 합성의 쇼핑몰명은 ICONS다. 상품 수량은 숫자로 쓰고, 배송비는 배송 건의 첫 상품 행에 한 번 표시한다. 신규 출고 파일의 운송장은 빈칸이다.
- **서원 7열:** 배송 건마다 한 행을 만든다. 전화번호·5자리 우편번호·전체 주소를 쓰고, 품목명에 각 상품/옵션과 해당 수량을 합친다. 이 양식에는 수취인명·주문번호·운송장 열이 없다.
- 김포의 사방넷 주문번호·옵션별칭·공급단가·EA(상품)·두 번째 연락처, 서원의 기타연락처·운임Type·수량은 현재 빈칸이다. 존재하지 않는 공급단가를 판매가로 대체하지 않는다. 서원의 수량이 상품 수량인지 박스 수량인지, 김포 EA와 공급단가의 의미는 확인 중이다.

**실제 창고 인수 확인은 남아 있다.** 빈칸 허용 여부, 단가의 할인 기준, 전화번호 칸, 배송비 행 배분, 서원 수량·수취인 전달과 회신 식별 절차를 물류 담당자와 확인해야 한다. 합성 주문의 파일 생성·재입력 성공만으로 창고 접수 성공이나 #429 전체 완료를 선언하지 않는다.

## 김포 회신 등록

1. 해당 출고지에 김포 WMS 21열 양식과 활성 기본 택배사를 설정한다.
2. 발주·발송 목록 위에서 그 출고지를 선택한다. 출고 파일의 `주문번호(쇼핑몰)` 값을 유지한 21열 XLSX 회신을 올린다. 기존 일반 3열 XLSX·CSV·붙여넣기도 계속 지원한다.
3. 21개 헤더를 정확히 인식한 파일에서 주문번호와 운송장을 읽는다. 고객명·주소·행 순서로 주문을 추정하지 않는다. 서버가 선택 출고지의 기본 택배사와 `(주문, 출고지)`에 속한 유일한 배송 건을 확인한다.
4. 같은 주문의 동일 운송장 상품 행은 한 건으로 센다. 서로 다른 운송장이 있거나 같은 주문의 다른 행이 잘못됐으면 그 주문의 모든 행을 고친 뒤 다시 올린다. 실패 보고서는 원본 줄 번호를 유지한다.
5. 성공한 배송 건은 배송 중으로 바뀌고 배송 메일이 대기열에 들어간다. 메일 대기열 경고가 있으면 발송 이력과 배송 상태를 확인한다. 재시도는 기존 멱등 발송·메일 규칙을 따른다.

파일은 256KB·1,000행 한도다. 숫자로 저장돼 자릿수가 유실될 수 있는 주문번호·운송장, 수식, 비활성 출고지·택배사, 다른 출고지나 미확인 주문을 거절한다. 서원 제공 파일에는 회신용 식별자가 없으므로 현재 일반 3열 회신을 사용한다. 실제 WMS가 발급한 운송장을 기준으로 대조하며, 연습 파일을 실제 창고나 택배사에 보내지 않는다.
