# 상품 KC 정보 검토

2026-09-10 · 영업 피드백 [#477](https://github.com/icons-hq/icons-ip/issues/477) · 2026-10-07 MD 피드백: 해당 없음 간소화 · 2026-11-12 KC 자가 신고·기타 인증([ADR-0036](../adr/0036-goods-kc-self-declaration.md))

KC 검토는 판매할 모델·옵션의 KC 대상 여부와 고객에게 게시할 KC 정보를 운영자가 확인해 기록하는 작업이다(자가 신고). 상품 유형이나 카테고리만 보고 적용 제도를 자동 판정하지 않는다. 검토 완료는 운영자가 실제 제품 표시와 입력이 일치함을 확인했다는 뜻이며, 인증 발급이나 시험·법적 적합성 판정을 대신하지 않는다. 공급처·제조업자·수입업자에게 받은 원본 자료의 위치(내부 검토 근거)는 남겨 두면 좋지만 선택이다.

## 신규 공개와 기존 공개의 경계

새 상품은 등록 화면에서 기본 정보·옵션과 KC 정보를 함께 입력해 한 번에 저장한다(2026-10-27 회의 R13·D6②, `admin_save_good_workspace`). 아직 저장 전인 새 옵션은 저장 때 옵션값 조합으로 KC 모델에 연결된다. KC를 비워 두면 기본 입력만 저장되고, 저장 뒤 KC 정보에서 검토한다. 새 공개와 비공개 후 재공개에는 완료된 KC 검토가 필요하다. 기존 7개 고시정보·대표 이미지·출고지 등 다른 공개 조건도 계속 적용한다.

순서는 기본 정보·유형·고시정보·옵션과 KC(**KC 인증 대상 여부**에서 대상 아님 확인 또는 대상 모델 입력)를 입력해 저장 → 화면 맨 위 판매 준비의 게시 상태에서 공개다. 등록 화면에서 KC를 검토 완료로 함께 저장하려면 확인 체크가 필요하며, 체크가 없으면 미검토로 저장한다. KC 저장이 실패하면 기본 입력도 저장되지 않고 입력은 화면에 남는다. 등록 화면은 공개를 함께 하지 않는다. KC 검토 뒤 상품명·IP·상품 유형·제조자·제조국·소재·크기나 옵션 구성을 바꿔 저장하면 검토가 미검토로 돌아가므로 다시 검토한다. 기본 상품을 저장할 때마다 KC 정보는 서버의 검토 상태를 다시 불러온다.

상품 편집의 **저장 후 공개**는 저장하지 않은 입력이 있고 공개 조건을 모두 채웠으며 이번 저장이 KC 검토를 되돌리지 않을 때만 저장 막대에 나오고(그 밖의 공개는 판매 준비의 **공개로 전환**), 한 transaction에서 저장한 뒤 마지막에 공개로 전환한다. KC 검토가 현재가 아니면 공개 전환이 `goods_kc_review_required`로 저장까지 되돌리므로, 관리 화면은 같은 입력을 공개 전환 없이 초안으로 다시 저장하고 공개만 보류한다. 저장 영역은 **초안 저장 완료 · 공개 보류**와 함께, 이번 저장이 완료된 검토를 무효화했으면 바뀐 상품 정보나 옵션을, 검토가 원래 없었으면 검토 완료를 안내한다. 초안 다시 저장도 실패하면 아무것도 저장되지 않았으므로 원래 KC 오류를 보인다. 이 DB 계약은 `supabase/tests/goods_kc_publish_draft_fallback.sql`이 고정한다.

도입 시점에 이미 공개된 상품의 게시상태는 변경하지 않는다. 자료가 없으면 관리 화면에 **기존 공개 · KC 미기록**으로 보이며, 가격·할당 재고 조정은 계속할 수 있다. 자료를 자동으로 채우거나 검토 완료로 표시하지 않는다. 상품을 비공개로 전환한 뒤에는 새 공개 조건을 따라야 한다.

상품명·IP·상품 유형·제조자·제조국·소재·크기 또는 옵션명·옵션 속성을 바꾸려면 먼저 비공개로 전환한다. 변경 후 검토는 미검토로 돌아간다. 옵션 가격·할당 재고·안전재고·예약판매 조건은 KC 모델 검토와 별개다. 옵션 사용 중지는 허용하며, 재사용은 마지막 완료 검토에 그 옵션이 포함되고 이름·속성이 그대로인 경우에만 공개 중에도 가능하다. 새 옵션을 자동으로 인증 범위에 포함시키지 않는다.

기본 seed와 별도 운영 연습 seed의 신규 상품도 실제 KC 근거가 없으므로 초안이다. 기존 seed 행의 게시상태는 각 seed의 기존 conflict 처리로 보존한다. 테스트의 합성 검토자료를 Preview·운영 상품에 승계하지 않는다.

## 상품 전체 KC 해당 없음

KC 정보는 맨 위 **KC 인증 대상 여부**(대상 아님 · 상품 전체 KC 해당 없음 / 대상 · 인증 종류와 번호 입력)를 먼저 고른다. 고르기 전에는 모델 입력칸을 열지 않는다. KC 대상이 아닌 상품은 상품정보제공고시 카드의 **KC 정보**에서 **대상 아님**을 고르면 **상품 전체 KC 해당 없음** 칸이 열리고, "이 상품은 KC 안전인증·안전확인·공급자적합성확인·안전기준준수 대상이 아님을 확인했습니다." 확인 체크가 켜진 채로 시작한다. 등록 화면은 그것으로 끝나고(고른 한 번), 저장하기를 누를 때 제출 시점의 사용 옵션 전체에 연결해 함께 저장한다. 확인 체크를 풀면 해당 없음 모델을 미검토로 저장한다. 이 칸에는 옵션 연결 칸이 없으므로, 확인 체크와 무관하게 해당 없음 모델 1개는 언제나 제출 시점의 사용 옵션 전체로 다시 연결된다(체크를 푼 뒤 옵션 구성을 바꿔도 저장된다). 저장된 상품은 이어서 **해당 없음으로 검토 완료**를 누르면, 해당 없음 모델 1개에 사용 중인 옵션이 모두 연결되어 검토 완료로 저장된다. 해당 없음 모델이 이미 하나 있으면(고시 프리셋 틀 포함) 그 모델의 제품군·고객 안내·선택 칸을 지키고 옵션만 다시 연결하며, 없으면 제품군 그 외·제도 해당 없음 모델을 새로 만든다. 이미 저장된 미검토 해당 없음 모델(고시 프리셋 틀 등)로 열린 화면은 대상 아님이 골라진 채 확인 체크는 꺼져 있어 운영자가 직접 체크한다. 고객 안내는 선택으로 펼쳐 입력한다. 검토 전에 해당 없음 모델 1개가 있으면 이 칸은 그 모델의 고객 안내와 같은 값이며, 어느 쪽에서 고쳐도 고친 안내가 저장된다.

- 입력이 있는 다른 KC 모델을 지울 때만 '입력한 KC 모델 N개(모델 1 · 모델명 …)를 지우고…'로 확인을 받는다. '대상'을 고르거나 모델 추가로 생긴 빈 모델(옵션 연결만 있는 모델)과 지켜지는 해당 없음 모델은 묻지 않는다. 이전에 저장한 검토 내용은 최근 검토 이력에 남는다.
- 공개 중·보관 상품에서는 비활성화된다. 기존과 같이 비공개 전환 또는 복원 후 검토한다.
- 사용 중인 옵션이 없으면 옵션을 저장한 뒤 진행한다.
- 검토자·시각·이력은 다른 검토 완료와 같이 남는다. 이 확인은 운영자가 KC 대상이 아님을 확인했다는 기록이며 법적 판정을 대신하지 않는다.
- 검토를 마치면 KC 정보 위쪽에 **상품 전체 KC 해당 없음으로 검토 완료 · 검토자 · 시각**과 연결된 옵션 수·고객 안내만 보인다. 확인 체크 칸은 다시 나오지 않고, 모델 상세와 내부 근거 칸은 **모델 상세 보기·고치기**에 접혀 있다. 고객 안내 수정이나 KC 대상 전환은 그 안에서 하며, 입력을 바꾸면 펼쳐진 채로 미저장 상태를 보여준다.

## 모델별 입력

KC 대상 상품은 **KC 인증 대상 여부**에서 **대상**을 고른다. 사용 중인 옵션을 모두 연결한 모델 1개가 열리고(연결은 고칠 수 있다), 필요하면 모델을 더 추가한다. 같은 옵션에 여러 제도가 적용되면 모델·제도 행을 나누어 기록할 수 있다. 모든 사용 중인 옵션을 한 개 이상의 검토 행에 명시적으로 연결한다. 사용 중지 옵션은 연결하지 않아도 검토가 유지되며, 다시 사용하려면 아래 재사용 규칙을 따른다. 마지막 모델을 빼면 대상 여부를 고르기 전으로 돌아간다.

| 입력 | 내용 |
|---|---|
| 제품군·적용 제도 | 실제 분류를 확인한 값을 선택한다. 미선택은 미검토로 저장할 수 있다. |
| 품목 분류·모델명 | 확인한 자료에서 식별되는 실제 분류와 모델을 입력한다. |
| 사업자 구분·사업자명 | 해당 제조업자 또는 수입업자를 입력한다. |
| 적용 옵션 | 이 모델과 자료에 실제로 해당하는 옵션만 선택한다. |
| 인증·신고번호 | 안전인증 또는 안전확인에 필요한 번호다. 공통 인증번호를 모든 상품에 입력하지 않는다. |
| 고객 안내 | 고객에게 공개할 내용만 입력한다. 해당 없음에서는 선택이다. |
| 적용 판단 사유·근거 참조 (선택) | 실제 분류 판단과 그 원본 문서를 찾을 수 있는 사내 보관번호 또는 접근 제한 문서 주소를 남길 수 있다. |
| 인증·신고문서·시험성적서·공급자 확인서 참조 (선택) | 선택한 제도에서 확인한 실제 자료의 보관참조를 남길 수 있다. 파일을 공개 이미지 버킷에 올려 대체하지 않는다. |

입력 가능한 조합은 전기용품·어린이제품의 안전인증/안전확인/공급자적합성확인, 생활용품의 위 세 제도와 안전기준준수, 모든 제품군의 해당 없음이다. 전기용품의 안전성검사 등 이 화면이 지원하지 않는 제도가 필요한 상품을 다른 제도나 해당 없음으로 대체해 완료하지 않는다.

시스템의 완료 조건은 다음과 같다(2026-11-12 자가 신고, ADR-0036). 이는 이 워크플로의 입력 확인 조건이며, 해당 상품에 필요한 모든 법적 요건을 열거한 것은 아니다. KC 대상 제도의 공통 입력은 고객 상세에 게시하는 제품군·제도·품목 분류·모델명·사업자 구분·사업자명과 적용 옵션이다. 안전인증·안전확인·공급자적합성확인 대상 제품을 인터넷으로 팔면 인증·신고번호, 제품명, 모델명(있는 경우), 제조업자명 또는 수입업자명을 게시해야 하므로(전기용품 및 생활용품 안전관리법 제9조④·제18조④·제25조④, 같은 법 시행규칙 제20조③·제37조③·제48조③) 이 칸은 낮추지 않는다. 내부 검토 근거(판단 사유·근거·문서 참조)는 모든 제도에서 선택이다.

| 제도 | 공통 입력 외 완료에 필요한 기록 |
|---|---|
| 안전인증 | 안전인증번호 |
| 안전확인 | 안전확인 신고번호 |
| 공급자적합성확인 | 없음. 공통 인증·신고번호는 입력하지 않는다. |
| 안전기준준수 | 없음. 인증·신고번호는 입력하지 않는다. |
| 해당 없음 | 공통 입력 대신 제품군·제도·적용 옵션만 필요하다. 품목·모델·사업자·판단 사유·근거 참조·고객 안내는 선택이며 인증·신고번호는 입력하지 않는다. |

자료가 아직 없으면 **미검토로 저장**한다. 모델별 입력은 게시 항목·번호·적용 옵션을 모두 확인하고 확인란("실제 제품의 KC 표시(인증 종류·인증·신고번호)와 모델·사업자·적용 옵션이 일치함을 확인했습니다.")을 선택해야 **KC 검토 완료**가 활성화된다. 번호가 없는 대상 모델은 '검토 완료 전 확인'에 이유가 보이고, 미검토로만 저장되어 공개가 막힌다(판매 준비의 KC 검토 필요). 담당자는 현재 로그인한 운영자, 시각은 서버 기록으로 남는다. 다른 사람이 상품·옵션·검토 내용을 바꿨다면 저장 충돌을 알려 다시 확인하도록 한다.

저장 실패 시 현재 입력은 유지된다. 내부 근거 참조는 브라우저 자동복구 저장소에 보관하지 않으므로 작업을 중단하기 전 미검토로 저장한다. 최근 검토 이력과 변경 전 근거는 보존된다.

## 공개·프리셋·복사

고객 상세와 고시 미리보기에는 제품군·제도·모델·대상 옵션·사업자·필요 번호·고객 안내만 표시한다. 해당 없음은 KC 안내 1행과 입력한 선택 항목·고객 안내만 보여준다. 모델이 하나뿐이면 "KC 인증 대상이 아닌 상품입니다."로 알리고 적용 옵션 목록을 생략한다. 다른 모델과 함께 고지되면 상품 전체가 아니라 "적용 옵션은 KC 인증 대상이 아닙니다."와 적용 옵션 목록을 보여준다. 사내 문서참조·판단 사유·검토 담당자·변경 이력은 고객 데이터와 분리한다. 검토가 끝나지 않은 새 내용은 공개 고시로 내보내지 않는다.

고시 프리셋은 7개 고시 필드를 모두 적용하며 선택적으로 KC **모델 틀**(제품군·제도·해당 없음 안내 문구)을 새 미검토 모델에 채운다. 번호·모델명·사업자·옵션·증빙·검토 완료는 복사하지 않는다. 상품 등록 화면에서도 KC 틀이 같은 화면의 KC 입력에 바로 미검토 모델로 채워지고(TKT-006), 상품과 함께 저장해도 남는다(확인 체크를 켜지 않으므로 미검토 초안, TKT-086 — `supabase/tests/goods_notice_kc_templates.sql`). KC 입력이 비었거나 상품 전체 해당 없음뿐이면 틀로 바꾸고(해당 없음 틀은 대상 아님이 골라지고 확인 체크는 꺼진 상태), 대상 모델이 있으면 뒤에 더한다. 저장된 상품은 KC 정보에 새 미검토 모델로 추가된다. 아직 반영되지 않은 틀이 남은 채 첫 저장이 끝나면 버리지 않고 저장된 상품의 KC 정보로 넘긴다. 다른 상품으로 이동하면 아직 적용하지 않은 틀은 버린다. KC 틀이 없는 프리셋을 선택하면 첫 저장이나 KC 저장 응답을 기다리던 미반영 틀을 취소한다. 이미 편집 중인 KC 모델은 지우지 않는다. 최근 저장값 복사는 고시 7칸만 복사하며 미반영 KC 틀도 유지한다. 상품 전체 복사도 새 상품의 KC 정보는 빈 미검토 상태로 시작한다.

메인 폼의 공개 화면 미리보기는 마지막 저장된 현재 검토의 `kc_disclosures`를 고객 상세와 같은 parser·표 컴포넌트로 표시한다(기타 인증은 KC 정보 안 미리보기에서 확인한다). 미검토는 공개 표가 비어 있으며, 미저장 상품·옵션 변경으로 검토가 무효화되는지는 저장 후 확인한다. KC 영역의 고객 고시 미리보기는 작성 중인 모델의 검토 준비를 돕는 별도 표시다.

## 기타 인증

KC 외 인증(예: 방송통신기자재 적합성평가)은 **KC 정보** 아래 **기타 인증**에 여러 건(최대 20건) 입력한다(SHEET-014, ADR-0036). 판매자가 신고하는 기록이라 공개 조건이 아니고 검토 단계가 없다.

| 입력 | 내용 |
|---|---|
| 인증 종류 | 필수. 자유 입력이며 자주 쓰는 종류(방송통신기자재 적합성평가·어린이보호포장·생활화학제품 안전기준확인)를 제안한다. |
| 인증기관 | 선택. |
| 인증번호 | 필수. 같은 인증 종류·인증번호는 한 번만 넣는다(대소문자 무시). |
| 고객 상세에 표시 | 새 항목은 켜진 채 시작한다. 켠 항목만 상품 상세의 제품 안전정보에 KC 고지 뒤 '기타 인증' 표로 보인다. |

- 등록 화면은 상품과 함께 저장한다(`admin_save_good_workspace`의 `otherCertifications` 섹션, 실패하면 아무것도 저장되지 않는다). 저장된 상품은 이 자리에서 **기타 인증 저장**으로 따로 저장한다(`admin_save_goods_other_certifications`). 다른 작업이 먼저 저장해 버전이 다르면 저장은 거절되고, 화면이 최신 저장값을 다시 읽어 요약을 보이며 버전만 새로 받는다(입력은 그대로). 이대로 다시 저장하면 최신 저장값을 덮어쓰고, 최신 저장값으로 바꾸려면 **저장된 기타 인증 다시 불러오기**를 누른다(저장하지 않은 입력이 있으면 지우기 전에 묻는다). 이 버튼은 불러온 뒤에도 늘 있다.
- 공개 중에도 고칠 수 있고 고객 화면에 바로 반영된다. 저장마다 감사 로그(`admin.good.other_certifications_saved`)에 전후 값을 남긴다. 보관 상품은 복원한 뒤 고친다.
- 고객 데이터는 `goods.other_certification_disclosures`(노출 항목의 종류·인증기관·인증번호)뿐이고, 원본(`private.goods_other_certifications`)과 노출 여부는 운영자만 본다. 트리거가 원본에서 다시 계산하므로 상품 복사·직접 갱신은 값을 넣지 못한다. 상품 복사는 기타 인증을 승계하지 않는다.
- 기타 인증은 KC 고지를 대신하지 않는다. KC 대상 제품은 KC 정보에서 따로 신고한다.

## 상품 엑셀

기존 **상품** 시트는 옵션 하나당 한 행을 유지한다. **KC 검토** 시트는 상품코드×KC행번호 하나당 한 행이며, 같은 모델의 여러 옵션코드는 셀 안에서 줄바꿈으로 나눈다. 상품코드·옵션코드는 텍스트로 보존한다.

- 그대로 내려받아 다시 올린 KC 행은 기존 검토를 보존한다. 검토 상태·버전은 읽기 전용이며, 엑셀에서 완료라고 써도 승인이 되지 않는다.
- KC 내용이나 근거를 수정하면 **상품** 시트의 게시상태를 **초안**으로 명시한 경우에만 저장한다. 수정 내용은 미검토로 들어가며, 실제 검토 완료는 상품의 KC 검토 화면에서 진행한다.
- KC 시트 또는 대상 상품의 KC 행이 없으면 기존 내용을 유지한다. 모두 비우려면 상품 시트의 **KC 초기화=예**를 명시한다.
- 새 상품·옵션의 자동 코드가 아직 없으면 먼저 초안으로 저장하고 다시 내려받아 KC 행을 연결한다. 명시한 코드가 있는 새 상품은 같은 저장 transaction에서 실제 옵션을 만든 뒤 연결하며 미검토로 저장한다.
- 잘못된 옵션코드나 동시 수정 충돌은 그 상품의 상품·옵션·KC 변경 전체를 되돌린다. 다른 상품 그룹의 기존 부분실패 처리와 원본 보존 흐름은 유지한다.

## 확인한 공식 구분

Safety Korea는 [어린이제품 안전인증](https://www.safetykorea.kr/policy/targetsSafetyCert3), [안전확인](https://www.safetykorea.kr/policy/targetsSafetyCheck3), [공급자적합성확인](https://www.safetykorea.kr/policy/targetsSafetySupply)을 나누고 모델별 검토·표시 절차를 설명한다. [전기용품 제도](https://www.safetykorea.kr/policy/targetsSafetyCert)와 [표시 안내](https://www.safetykorea.kr/policy/targetsSafetyProvider)는 안전인증·안전확인·공급자적합성확인 및 안전성검사를 구별하며, 공급자적합성확인에 일반 인증·신고번호를 요구하지 않는 구분을 명시한다. [생활용품 대상품목](https://www.safetykorea.kr/policy/targetsSafetyCert2)과 [공급자적합성확인](https://www.safetykorea.kr/policy/targetsSafetyQuality)도 별도 제도로 안내한다. 위 자료는 2026-09-10 제도 구분을 확인한 근거이며 개별 판매 모델의 적합성 증거가 아니다.
