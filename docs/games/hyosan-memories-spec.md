## 0. 한 줄 정의

방문자(=**절비**)가 폐허가 된 효산고에 잠입해, 각 장소에 남은 시즌1의 "**기억 에코**"를 8개 스테이지로 돌파하며 절비 능력을 되찾고, 옥상 모닥불의 남라에게 도달하는 **2D 탑뷰 핵앤슬래시 액션 RPG**.

> 장르 공식(사용자 확정 원문): 구조 = Enter the Gungeon · 적 물량 = Vampire Survivors/SAS Zombie Assault · 성장/엘리트/보스 = Diablo · 그래픽·배경 = 지우학 실사 드라마 감성.

## 2. 스토리·세계관

### 2.1 프레임 — 기억 에코

- 플레이어는 효산고 재학생 출신 **절비**다(캠페인 픽션 "방문자=절비"의 연속).
- 시즌1 종결 후 폐허가 된 효산고. 밤마다 옥상에 피어오르는 모닥불(12화 미러링)을 보고 격리 철조망을 넘어 잠입한다.
- 각 장소에 도달하면 그곳의 시즌1 사건이 **기억 에코**로 재생되고, 그 안에서 싸운다. **기억 속 자신은 아직 인간이었으므로 좀비가 적대한다** — "좀비는 절비를 공격하지 않는다"는 캐논과의 모순을 이 프레임이 해소한다.
- 스테이지를 클리어할수록(기억이 돌아올수록) 절비 능력이 깨어난다. **기억 회수 = 능력 해금** — 서사와 성장 시스템이 동일물이다.
- 최종 옥상만 현재 시점. 모닥불 앞의 남라와 재회한다. 캐논 훅: 12화에서 남라는 "나 같은 존재가 더 있어 그들에게 가야 한다"고 말했다 — **플레이어가 바로 그 절비 중 하나다.**

### 2.2 컷인 (정지 일러스트 3장)

| 시점 | 장면 |
|---|---|
| 오프닝 | 격리 철조망 밖, 밤. 옥상의 모닥불을 목격하고 잠입을 결심 |
| 스테이지 5→6 사이 | 음악실의 기억 — 남라가 귀남에게 물리는 순간(6화). 플레이어블이 아닌 기억 컷인 |
| 엔딩 | 모닥불의 남라. 기억 완성. "또 보자" — 시즌2 직결 훅(단, 시즌2 소재는 쓰지 않고 시즌1 엔딩 장면만 사용) |

## 3. 스테이지·보스 (8스테이지 확정)

| # | 스테이지 | 성격 | 보스 | 캐논 근거 (에피소드) |
|---|---|---|---|---|
| 1 | 과학실 | 튜토리얼, 발단의 기억 | 김현주(페이션트 제로) + 햄스터 연출 | 1화 — 요나스 바이러스, 감금 탈출 |
| 2 | 보건실→급식실 | 첫 대량 웨이브 | 보건교사 김경미 좀비 | 1화 — 첫 감염→점심시간 집단 확산(원테이크 신) |
| 3 | 2학년 5반 교실·복도 | 바리케이드전 | 체육교사 강진구("체육복 좀비") | 2화 — 교실 농성, 밈 좀비 |
| 4 | 방송실·계단 | 소방호스 하강 연출, 계단 전투 | **홍대원("라바콘 좀비")** — 계단 미끄럼 기믹 | 2화 — 오른발에 낀 라바콘 때문에 계단을 못 오름 |
| 5 | 도서관 | 책장 지형전 | **귀남 1차전 (인간)** | 5화 — 책장 위 결투, 왼눈 손상→절비 각성 |
| 6 | 교무실 | 스텔스 변주, 화재 확산 | 민은지(추적·방화) | 4·8화 — 영상 파괴, 교무실 방화 |
| 7 | 체육관 | 최대 규모 포위 웨이브 | 보스 없음(웨이브 러시) + **활 습득** | 10화 — 체육관 포위, 카트 바리케이드 탈출 |
| 8 | 옥상 계단·옥상 | 최종전 → 현재로 귀환 | **귀남 최종전 (절비)** | 8·9화 — 옥상 공방, 남라의 귀남 투척 |

- 귀남은 **2회**(5스테이지 인간 → 8스테이지 절비). 인간→절비의 변화가 최종전의 무게를 만든다.
- 고증 디테일: 홍대원의 발에 낀 것은 과자 꼬깔콘이 아니라 **라바콘(안전 고깔)**이다. 밈 통칭은 "꼬깔콘 좀비"지만 인게임 연출은 라바콘으로 고증한다.
- 컷 항목: 음악실(컷인으로 대체) · 화장실·양궁장·운동장·공사장(분량상 제외, 확장 후보로 보존).

### 3.1 원작 고증 재검증 항목 (구현 전 본편 확인)

리서치(위키·나무위키 교차)에서 상충이 남은 항목 — 구현 시 본편 재확인 후 확정한다.

- 한경수 변이 장소: 방송실 부속실 vs "교실" 표기 상충
- 홍대원 라바콘 장면의 화수: 1화 오프닝 vs 2화
- 민은지를 문 주체에 대한 나무위키 요약 오류 가능성

## 4. 게임플레이

### 4.1 플랫폼·조작

- **모바일 퍼스트 + 데스크톱** 동시 지원. 클릭 이동(디아블로식)은 배제 — 직접 조작.
- 모바일: 좌측 가상 조이스틱(이동) + 우측 버튼 3개(공격 / 스킬 / 대시). 공격은 이동 방향·최근접 적 자동 조준 보정.
- 데스크톱: WASD/화살표 이동 + J/K/L(공격/스킬/대시). 키 리맵은 v1 비대상.

### 4.2 전투 — 근접 주무기 + 후반 보조 활

- 기본 키트: 이동 · **근접 콤보**(3타) · **대시**(무적 프레임 짧게 — EtG 닷지롤의 근접 번역) · 해금 능력.
- **차지 강타**: 괴력 해금 후. 홀드→방출, 넉백·군중 제어.
- **활(보조 원거리)**: 스테이지 7 체육관에서 습득(하리의 양궁 캐논 회수). 탄약 제한형, 웨이브·보스전의 완급 담당.
- 무기 파밍·장비 드랍은 없다(성장 축은 기억 해금 단일).

### 4.3 성장 = 기억 회수 (능력 매핑, 확정)

| 클리어 | 회수하는 기억 | 해금 |
|---|---|---|
| S1 과학실 | 발단 — 요나스 바이러스 | **초감각**: 주변 적·숨김 아이템 감지 펄스 |
| S2 급식실 | 첫 확산 | **괴력**: 차지 강타·넉백 |
| S3 교실 | 바리케이드전 | **재생**: 전투 이탈 시 체력 회복 |
| S4 방송실 | 대피 방송 | **도약**: 돌진 회피 → 광역 착지 일격 |
| S5 도서관 | 귀남의 각성 | **갈망 해방**: 폭주 발동·제어 |
| S6 교무실 | 은지의 복수 | 능력 강화 선택 I |
| S7 체육관 | 마지막 탈출 | 능력 강화 선택 II + 활 |
| S8 옥상 | 전부 — 현재로 귀환 | 전 능력 총동원 → 엔딩 |

### 4.4 갈망 게이지 (절비 리스크 시스템)

- 게이지 1개. 처치할수록 차오른다.
- 가득 차면 **폭주**: 공격력·속도 상승 + **화면이 붉게 물들며 시야가 좀비의 것처럼 변한다**(포스트 프로세싱 — 시야 "축소"가 아니라 시각 변질. 사용자 확정 연출). 지속 후 탈진 페널티.
- S5 "갈망 해방" 해금 후에는 수동 발동·조기 해제가 가능해진다(리스크의 통제권 회수 = 절비로서의 성숙이라는 서사).
- v1은 단순하게: 게이지 1개, 폭주 1종.

### 4.5 엘리트 (Diablo 접사 시스템)

- 일반 좀비에 접사 1~2개가 붙어 엘리트가 된다. 이름표 + 강조 링 표기.
- v1 접사 4종: **질주하는**(이속↑) · **끈질긴**(체력↑·경직 저항) · **폭주하는**(공속↑, 처치 시 갈망 게이지 추가 상승) · **울부짖는**(주변 좀비 가속 버프).
- 경험치·레벨은 없다(성장 이중화 방지).

### 4.6 스테이지 내부 구조 (EtG 번역)

- **고정 핸드크래프트 방 배치** — 절차 생성 없음. 각 방이 고증 장면을 재현한다(기억 에코의 정체성).
- 방 진입 → 문 잠김 → 웨이브 클리어 → 개방의 EtG식 연쇄. 스테이지당 방 3~6개 + 보스방.
- 리플레이 가치는 엘리트 변형·클리어 타임·숨김 굿즈 탐색으로 확보(맵 자체는 불변).
- 스폰 연출로 물량감 증폭: 창문 난입, 문 붕괴, 환풍구. 시체는 잔류(성능 예산 내 페이드).

### 4.7 잡몹 로스터 (캐논 기반 — §10 기본값)

지우학 좀비는 "뛰는 좀비"가 정체성이다. 기본 개체부터 빠르고, 대신 유리몸.

| 타입 | 특성 | 캐논 근거 |
|---|---|---|
| 학생 좀비 | 기본 러너. 무리 지어 직진 | 전편 |
| 발작형 | 경련 후 급가속 돌진 | 제작진 "좀비마다 개별 특성" 인터뷰 |
| 벽찧기형 | 벽·문을 두드려 다른 좀비를 부름(방치 시 증원) | 동일 인터뷰 |
| 난입형 | 창문·문을 뚫고 등장(스폰 연출 전담) | 1~2화 교실·복도 |
| 교사 좀비 | 헤비 — 느리고 단단, 넉백 저항 | 강진구 계열 |

### 4.8 사망·저장·세션

- 사망 시 해당 스테이지 처음부터. 클리어한 스테이지는 서버에 저장되어 이어하기 가능.
- 첫 완주 목표 15~20분(스테이지당 2~3분). 클리어 후 스테이지 재플레이 자유(구매권 재부여는 없음 — 멱등).
- 난이도는 단일(스테이지 곡선으로만 상승).

## 5. 보상 — 구매권 (카드 0장)

> 정의·트레이드오프의 정본은 [ADR-0011](../adr/0011-goods-purchase-entitlement-game-reward.md). 용어는 `CONTEXT.md`.

### 5.1 확정 규칙

- 이 게임은 **카드를 발급하지 않는다**. 보상은 **구매권** — 특정 굿즈 SKU에 대한 **독점 구매 자격**(구매권 없으면 해당 SKU 구매 불가).
- 부여는 전부 **결정론**: ① 스테이지 클리어 = 그 스테이지에 지정된 굿즈 1종의 구매권 확정 부여, ② 맵 **고정 위치**의 숨김 아이템 습득 = 보너스 굿즈 구매권. 무작위 요소 없음(확률형 논점 원천 차단).
- 계정당 SKU별 1회 부여 · 구매권 1개당 구매 수량 1 · 캠페인 종료까지 유효 · **재고 예약 아님**(권한자 수가 재고를 초과할 수 있고 구매는 선착).
- 굿즈 슬롯: 8스테이지 × (지정 1 + 숨김 0~1) = 최대 16슬롯. 실제 SKU 배정은 운영 몫(스펙은 슬롯만 정의).

### 5.2 부여 이벤트 계약 (서버, 초안)

- 스테이지 클리어 확정 RPC(가칭 `complete_game_stage`): 입력 = 게임 슬러그·스테이지 번호·습득 아이템 슬롯 목록. 서버가 검증하는 것 — 인증·정지·스테이지 **순서**(N-1 클리어 없이 N 불가)·최소 플레이 시간(휴리스틱)·멱등.
- 멱등 키 스킴(기존 관례 계승): `game_stage:<game>:<user>:<stage>` · `game_item:<game>:<user>:<slot>`.
- 원장·RLS·상점 노출(구매 플로우에서 구매권 검사)의 **정본은 #303 그릴링과 통합**한다. 이 스펙이 확정하는 것은 "게임이 무엇을 언제 발급 요청하는가"까지다.
- **정직한 한계**: 실시간 액션은 (구 생존 게임의 결정론 Sim과 달리) 서버 재현 검증이 불가능하다. 클리어 신뢰는 순서 강제+시간 휴리스틱+이상 로깅+운영 회수 권한으로 다루며, 구매권이 재고 비예약·구매는 정상 결제라는 점이 악용 폭발 반경을 제한한다. 상세는 ADR-0011.

### 5.3 시스템 함의

- **카드 게이트(#309, 현재 OFF)와 게임 출시가 디커플링된다** — 이 게임은 카드 파이프(`play_game`→`grant_cards`)를 쓰지 않는다.
- 기존 goods variant mock("실제 경품이나 구매권이 생기지 않는다")과 무관한 **신규 실물 커머스 연결**이다. legacy 래플(추첨 부여)과도 다르다 — 부여에 무작위가 없다.

## 6. 아트 디렉션

- **전면 실사 드라마 감성** — 인게임뿐 아니라 **게임 외곽 UI(타이틀·메뉴·기억 카드·결과 화면)까지 전부**. 캠페인 디자인 정본 v0.2 "아날로그 재난 서식"은 이 게임 표면에 **적용하지 않는다**(사용자 확정 — 캠페인 결정 ④의 게임 예외. #295 스킨 공존 그릴링이 이 예외를 전제로 진행할 것).
- 뷰: 2D Orthogonal Top-down + **3/4뷰 캐릭터 스프라이트** + 입체감 있는 벽·가구(페인팅으로 볼륨 표현) + 고해상도 2D 배경.
- 조명: 하이브리드 — Phaser Light2D 포인트 라이트 **씬당 ≤4**(화재·달빛 창·비상등) + 베이크드 음영 + 블롭 섀도. 전 광원 실시간은 모바일 성능상 배제(확정).
- 수위: **무혈 기본**(타격 플래시·먼지/재 소멸). 어두움은 팔레트·사운드로. 원작은 청불이지만 캠페인 페이지는 전연령 공개 브라우징이다.
- **시즌1 화면 충실도 우선**(사용자 제공 Netflix 계약 전제): 정식 캐릭터는 박지후(온조)·윤찬영(청산)·조이현(남라)·로몬(수혁) 등 시즌1 출연 배우의 얼굴, 헤어, 체형, 의상 연속성을 공식 스틸에 맞춘다. 오리지널 플레이어·엑스트라는 특정 정식 배역으로 오인시키지 않되 같은 캐스팅 질감과 효산고 의상을 정확히 따른다.
- 자산 스펙은 정식 배역(`identity.mode: canonical`)과 오리지널/엑스트라를 명시적으로 구분한다. 정식 배역은 평균 QA와 공식 소스 충실도 외에 배우 `characterIdentity` 최저점을 독립 게이트로 통과해야 한다.
- **세트 재해석 금지**: 급식실·교실·복도 등은 장르풍의 일반 학교로 대체하지 않고 시즌1 세트의 구조·색·재질·가구·소도구를 정본으로 삼는다. 탑다운 투영과 게임 가독성 확보에 필요한 최소 변환만 허용한다. 세부 정본과 출처는 [시즌1 비주얼 레퍼런스](./hyosan-memories-visual-reference.md)를 따른다.
- 음성·배우 보이스 클론·드라마 OST는 현재 시각 에셋 허용 범위에 자동 포함된 것으로 보지 않으며 별도 권리 확인 전 사용하지 않는다.
- 캐릭터 커스텀은 v1 비대상(교복 절비 단일 외형).

### 6.1 G2 급식실 프로덕션 에셋 계약 (#342)

G1 그레이박스의 진실원은 1280×720 논리 월드와 `Phaser.Scale.FIT` 카메라다. 전투실 경계는 `(72, 72)`–`(1208, 648)`, 유효 크기는 1136×576이며 바닥·가구 배치는 64px 논리 그리드에 맞춘다. G2는 이 카메라에서 읽히는 아래 생산 규격을 확정한다.

| 자산 | 셀 | 배치 | 프레임 의미 |
|---|---:|---:|---|
| 플레이어 이동 | 128×128 | 6열×4행, 24프레임 | 남·서·북·동 행마다 6프레임 걷기 |
| 플레이어 3타 콤보 | 128×128 | 6열×4행, 24프레임 | 방향마다 준비→1타→전환→2타→강타 준비→3타 |
| 학생 좀비 달리기 | 128×128 | 6열×4행, 24프레임 | 남·서·북·동 행마다 6프레임 달리기 |
| 학생 좀비 공격 | 128×128 | 4열×4행, 16프레임 | 방향마다 웅크림→팔 뻗기→최대 도달→회수 |
| 김경미 보스 이동 | 192×192 | 6열×4행, 24프레임 | 남·서·북·동 행마다 경련 뒤 급가속 6프레임 |
| 김경미 보스 공격 | 192×192 | 6열×4행, 24프레임 | 방향마다 준비→돌진→팔 뻗기→최대 도달→비틀림→회수 |
| 급식실 모듈 세트 | 1024×1024 | 단일 투명 PNG | 64px 바닥·벽·배식구·문·테이블·의자·소도구 모듈 |
| 급식실 조립 검수본 | 1280×720 | 단일 불투명 PNG | G1 카메라·동선과 시즌1 세트 충실도 검수 |

- 모든 다중 프레임 시트는 row-major이며 방향 행은 **남·서·북·동** 순서다. 이름표·교표와 얼굴 비대칭이 뒤집히므로 동·서는 별도 authored frame이고 미러링하지 않는다.
- 정규화는 각 셀을 독립 검출하되 전체 시트에서 가장 큰 visible bbox를 기준으로 공통 scale을 사용하고, 각 셀의 발을 `bottom-center` anchor에 맞춘다. 빈 셀·잘린 셀·과도한 가장자리 접촉은 실패한다.
- atlas key는 `<asset_id>_00`부터 row-major로 증가한다. padding 4px, extrusion 1px, 최대 변 4096px이며 상한 전 결정적으로 다음 행으로 줄바꿈한다. 단일 프레임은 기존 자산 id와 M0 byte 계약을 보존한다.
- G2는 에셋·atlas·manifest·승인 기록까지만 소유한다. 정확한 스펙·PNG·atlas SHA-256에 대한 사용자 승인 전에는 G3(#343) Phaser 통합을 시작하지 않는다.

## 7. 에셋 파이프라인 (확정)

사용자 확정 다이어그램을 그대로 구현한다. 코드 위치: **`scripts/asset-pipeline/`** (레포 커밋).

```
asset-spec.yaml → CODEX PLANNER(현재 작업 세션) → imagegen 스킬 직접 호출(후보 생성)
  → TECHNICAL QA (alpha/size/trim/frame/bbox/edges — sharp, 결정론)
  → CANDIDATE VISION QA(현재 작업 세션 직접 검토·후보 SHA 결속)
  → score 부족 시 imagegen edit/regenerate (최대 N=3, 실패 시 BEST 후보 결정)
  → Normalize/Trim → OUTPUT VISION QA(현재 작업 세션 직접 검토·최종 PNG SHA 결속)
  → Sprite Atlas → Asset Manifest
  → Phaser Game → Playwright 실행 → 인게임 Screenshot → CODEX VISION QA → 현재 작업 세션 직접 수정 → DONE
```

- **생성 노드 = 현재 Codex 앱 작업에서 이미지를 만들 때 쓰는 기본 내장 `imagegen` 스킬을 직접 호출**한다. 별도 CLI·API·하위 Codex 호출을 사용하지 않는다. 비전 QA도 같은 작업 세션이 이미지를 직접 검토한다. `imagegen` 결과는 기본 생성 위치에서 격리된 run 입력 디렉터리로 복사한 뒤, 스크립트가 기술 QA·정규화·atlas·manifest를 담당한다.
- 기획 프롬프트 작성, 공식 레퍼런스 첨부, 점수 미달 후보의 edit/regenerate, 인게임 시각 수정도 모두 같은 Codex 앱 작업 세션이 직접 수행한다. 각 시도 결과와 비전 판정 JSON을 run 입력으로 남기고 최대 3회 안에서 반복한다. CLI/API fallback, 이미지 생성 스크립트, 중첩 Codex 호출로 자동 전환하지 않는다.
- 저장소 스크립트의 역할은 모델 호출이 아닌 sharp 기반 기술 QA·normalize/trim·atlas·manifest로 한정한다.
- 현재 앱 ImageGen이 투명 요청에도 RGB 체크무늬를 구워 반환하면, 같은 Codex 앱 작업의 내장 `imagegen` 편집으로 전경은 유지하고 배경만 단색 마젠타 크로마로 바꾼다. 코드가 밝은 체크무늬를 추정 제거하지 않는다. 시도 메타데이터에 명시된 `magenta-matte-to-alpha`는 가장자리 크로마 비율을 검증하고 연결된 마젠타만 alpha 0으로 바꾸며, 흰 셔츠 같은 비마젠타 전경과 내부색을 보존하는 결정론적 패키징이다. 새 시각 요소를 생성하지 않는다.
- 각 ImageGen 원본, 기술 변환 후 후보, normalize/trim된 최종 PNG는 `candidateSha256`·`visionQa.reviewedSha256`·`outputVisionQa.reviewedSha256`으로 각각 결속한다. 후보와 최종 출력은 동일한 6개 품질 차원과 3개 하드 가드를 누락·추가 없이 판정하며, 정규화 뒤 품질 저하도 fail closed한다.
- 같은 output을 쓰는 실행은 소유 token·host·PID·OS 프로세스 시작 identity를 기록한 lock으로 직렬화한다. 같은 host에서 종료됐거나 PID가 재사용됐음이 OS identity로 확인된 output lock만 배타적 recovery marker 아래 자동 복구한다. Recovery marker 자체, 살아 있는 소유자·다른 host·malformed/구형 lock은 강제 만료시키지 않는다. 정상 실행은 30초 heartbeat로 소유권 상실을 감지한다. 소유 token 변경·heartbeat 실패는 진행 작업을 중단하고 drain하며, 모든 shared publish 전후 token fencing 및 in-flight heartbeat 종료를 강제한다. Atlas는 고유 run 디렉터리에서 먼저 완성한다. 각 실행은 direct-session 파싱보다 먼저 기존 승인 가능 manifest를 무효화하고 모든 산출물을 기록한 뒤 manifest를 마지막에 게시한다. direct-input 루트·session·작업·출력 경로는 실제 경로까지 확인하고, 저장소 루트 자체도 출력으로 허용하지 않는다. 배타적 run 디렉터리와 원자적 leaf 쓰기로 심볼릭 링크를 통한 저장소 밖 읽기·쓰기를 거부한다. 스펙과 direct-session은 UTF-8 원본 바이트를 한 번 읽어 fatal decode하며, 스펙은 그 동일 바이트로 실행과 manifest SHA를 만든다. 검증된 스펙과 plan·generation·technical QA·candidate/output QA를 deep-freeze하고 runner 호출 전 SHA를 primitive snapshot으로 결속한다. Direct-session 후보는 direct-input 기준 안전한 상대 POSIX 경로만 허용한다. 권리 범위·중복 없는 등록된 Netflix 공식 ID–URL 레퍼런스·자산별 reference 결속을 필수화해 manifest에 보존하고, `sprite`·`boss`·`cutin`은 `characterIdentity`를 비적용 처리할 수 없다. `minSourceFidelity`는 0.85 아래로 낮출 수 없으며, manifest는 atlas 이미지와 frame-data JSON을 각각 SHA-256에 결속한다.
- 기술 QA·정규화·아틀라스 = sharp 기반 스크립트(이미 레포 의존성). 인게임 검증 = playwright-core + **prod 빌드**(이 레포 dev 서버는 Playwright 하이드레이션 불가 — 알려진 함정).
- `asset-spec.yaml`은 `scripts/asset-pipeline/asset-spec.yaml` 단일 정본. 스키마 초안:

```yaml
meta:
  styleRef: "지우학 시즌1 배우·의상·효산고 세트에 충실한 페인티드 2D"
  fidelityTargets: [season-1-production-design, canonical-actor-likeness, uniform-costume-continuity]
  forbidden: [gore, webtoon-elements, wrong-season-elements]
pipeline:
  approvalBlocks: [G3]
  atlas: { name: hyosan-memories-g2-sprites, padding: 4, extrusion: 1, maxSize: 4096 }
assets:
  - id: player_halfbie_walk
    kind: sprite        # sprite | tileset | background | boss | cutin | ui
    identity: { mode: original } # canonical이면 character·performer와 qa.minCharacterIdentity 필수
    view: topdown-3q    # 3/4뷰
    size: 128x128
    frames: 24
    frameLayout: { columns: 6, rows: 4, order: row-major, anchor: bottom-center, trim: shared-scale }
    promptBrief: "교복 절비, 남·서·북·동 3/4뷰 걷기 사이클"
    qa: { minScore: 0.8, minSourceFidelity: 0.85 }
```

- **리스크(정직 고지)**: "실사 감성 고해상 + 공식 배우/세트 동일성 + 탑뷰"는 이미지 생성 최난도 조합이다. 평균 QA와 별도로 공식 소스 충실도 0.85를 요구하고, 정식 배역은 배우 동일성 최저점도 별도로 요구한다. M0 시안 게이트가 방향 리스크를 앞에서 흡수한다.

## 8. 기술

- **렌더러: Phaser** (사용자 확정. 신규 의존성 — 기존 마블 룰렛의 커스텀 canvas 패턴은 쓰지 않는다).
- 통합: `/games/[gameId]` 풀블리드 라우트(셸 제외 가드 기존 관례) + 클라이언트 전용 dynamic import. `PopupGameHost` 계약은 카드 결과 재생 전제라 **구매권 이벤트용 확장이 필요**하다(구현 티켓에서).
- 서버: `games.type`이 `'marble_roulette'` 단일값 CHECK — 신규 유형 추가 시 마이그레이션·어드민 콘솔·카탈로그 로더 최소 4개소 동시 확장 필요(#306 감사와 일치). 구매권 파이프는 신규(§5.2).
- 성능 예산(확정): 동시 좀비 **모바일 40 / 데스크톱 80** · 스테이지 총 처치 150~300 · 60fps 목표(모바일 30 허용).
- 선행 조건: 이 워크트리는 `node_modules` 미설치(빌드·타입체크 전 `npm install` 필요, postinstall이 box2d WASM 복사) · Next.js 16 API는 코드 작성 전 `node_modules/next/dist/docs/` 확인(레포 규율) · Phaser 버전은 구현 착수 시 최신 문서(context7)로 확정.
