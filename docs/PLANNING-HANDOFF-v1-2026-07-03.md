> **BM 정합 확인**: 본 레포 ADR-0003(무료 리워드 피벗)은 icons ADR-0015로 **대표 판정·수용 완료** — 충돌 없음. 이후 BM급(가격·수익구조·정체성) 결정은 icons에서 선행하고, 본 레포는 구현 ADR만 만든다.

## 2. 확정 IA (ADR-0014) — 구현 요구 3건

현행 4탭(홈/굿즈샵/뽑기/커뮤니티)+GNB 6은 **공식 인정** — 변경 없음. 요구:

1. **상단 아이콘 장바구니→알림함** ([#68](https://github.com/sangwopark19/icons-ip/issues/68)) — 알림함 착지 화면(FO-NT-01: 유형별 1탭 끄기 포함)과 **한 묶음**으로 구현(아이콘만 바꾸면 고아 링크).
2. **`/shop/[slug]` 상품 상세 라우트** (L2 권고) — "이 굿즈의 인증 N건" 소셜커머스 역링크의 착지. 현행 목록 내 담기 구조로는 BR-1 세 번째 Signal이 성립하지 않음.
3. **마이 영역 단일 `/my`** — 프로토타입의 `/console`·`/mypage` 이원 구조는 승계하지 말 것. 잔액(무상)·주문·설정 포함.

## 3. 핵심 로직 불변식 (플로우차트 v1.1 — Failure 표가 QA 예외 케이스)

**공통 3원칙**: ① 돈·재화 단계는 원자적(부분 성공 금지) ② 실패 사유는 사용자 언어로 표면화(generic 금지 — 2026-06-11 가입 장애 교훈) ③ 과거 이력 불변.

- **주문(Flow 1, 전문 유효)**: `create_order` 원자적(주문+재고 차감+금액 스냅샷) · 재고 race → 주문 미생성·결제 취소·장바구니 보존 · **특전 카드 발급 실패해도 주문 유효**(재시도 큐+수동 발급, 롤백 금지) · 실PG는 웹훅 검증 후에만 확정(ADR-0010 게이트).
- **무상 보상(구 Flow 2·3 승계)**: 보상·추첨 결과는 서버 단일 결정 · 공시(안내)와 실제 로직 단일 소스 정신 유지 · 지급 실패 시 보상 트랜잭션(참여 기록만 남고 보상 없음 = 금지) · 래플은 async 마감 + commit-reveal(본 레포 04-dev-spec 원본).

## 7. 정합 노트 — PRD 개정 제안 (icons-ip 판단 사항)

1. **비전 문구**: 현행 PRD §1 "슈퍼앱 … 커머스를 척추로"는 icons ADR-0011(정체성 = **온라인 팝업 + IP 커뮤니티**, 커머스·게이미피케이션은 그 위) 표현과 결이 다름 — 구현 우선순위에는 영향 없으나, 대외 문구 통일을 위해 개정 권장.
2. PRD §1.2 목표의 "유료 가챠" 항목은 ADR-0003 배너로 이미 처리됨 — 본 인계서 §3 무상 보상 불변식으로 대체.
