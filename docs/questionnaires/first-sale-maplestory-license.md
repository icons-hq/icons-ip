# 메이플스토리 라이선스 세부 확인서

**목적:** 넥슨 메이플스토리 상품화 라이선스의 실행 조건(품목·감수·표기·채널·정산)을 확정해 첫 실판매 상품 등록과 판매 개시를 마감합니다.

> **상태: 2026-08-26 작성 · 미회신.** [#315](https://github.com/icons-hq/icons-ip/issues/315)의 완료 근거가 된다. 계약 **완료** 사실은 2026-08-26 제품 소유자가 확인했다 — 이 확인서는 계약 존재가 아니라 실행 세부를 묻는다.

**보내는 사람:** ICONS 개발·운영팀
**답변 담당:** 라이선스 계약 담당자
**답변 사용처:** 상품 등록([#316](https://github.com/icons-hq/icons-ip/issues/316))의 표기 문구·이미지 사용 범위, 판매 개시 판단, 정산 리포트 준비에 반영합니다.

## 배경

첫 실판매 대상이 메이플스토리 공식 라이선스 굿즈로 확정됐습니다([#319](https://github.com/icons-hq/icons-ip/issues/319)). 판매는 iconsip.com 자사몰에서 Korpay 카드 결제로 진행합니다. 계약서 원문·계약 금액·개인 연락처는 이 문서나 GitHub 이슈에 적지 않습니다.
