# ICONS 온라인 팝업 — 시장·전략 리서치 보고서

> 작성일 2026-06-30 · 대상 서비스 [iconsip.com](https://iconsip.com) · 문서 1/4 (보고서·PRD·로드맵·개발기획서)
> **상태: 제품 범위에서 제거된 historical research snapshot.** 2026-08-12 #115·#66 후보를 active roadmap에서 제거했다. 실제 pilot이 생기면 이 문서를 현행 요구사항으로 재사용하지 않고 작은 RFC로 다시 검증한다. 현행 결정과 구현은 [ADR-0003](../adr/0003-free-reward-pivot.md)·[ADR-0004](../adr/0004-draw-ticket-card-packs.md)·[ARCHITECTURE](../ARCHITECTURE.md)를 따른다. 아래의 면제·비해당 단정은 superseded됐으며 법률 자문이나 면제 증명이 아니다.
> 본 보고서의 법률·PG 판단은 **방향 제시**이며, 최종 확정은 대한민국 변호사·각 PG 심사담당·게임물관리위원회 확인이 필요하다(§10·§11).

## 0. 한눈에 보는 결론 (Executive Summary)

1. **카드 자체 가격·충전금·현금화를 없애는 설계는 법률·PG 위험을 낮추지만 자동 면제를 만들지는 않는다.** 굿즈 주문과 무작위 카드팩이 연결되면 간접 유상으로 판단될 여지가 있고, 게임물·확률형 아이템 표시·사행성 적용 여부는 공개 전 법률·관계 기관 확인이 필요하다.
2. **작성 당시 기존 ICONS는 "유료 충전금 가챠"를 채택한 상태였다.** 이후 ADR-0003과 migration `20260707100001_p2_gacha_decommission.sql`로 유료 지갑·뽑기 테이블과 RPC를 제거해 이 제품 충돌은 해소했다.
3. **PG 심사**: 카드 자체 결제와 충전금을 제거하면 심사 범위는 단순해지지만 입점 가능성이나 위험 등급을 보장하지 않는다. 실제 BM·상품·표시 문구를 각 PG에 사전 제출해 서면 또는 추적 가능한 결과를 받는다.
4. **시장은 충분히 크고 모바일 중심이다**(2024 온라인쇼핑 242조, 모바일 75%). 팝업스토어·IP 굿즈·블라인드박스가 동시에 성장 중이고, 벤치마크는 "회원 기반 + 수집 루프"가 리텐션의 핵심임을 수치로 입증한다(팝마트 회원 매출 92.7%, 재구매율 49.4%).
5. **차별화 포인트는 "팝업이 끝나도 남는 것"이다.** 더현대·래플·블라인드박스가 공통적으로 가진 휘발성·박탈감·리셀 거품을, 우리는 **종료 후에도 잔존하는 커뮤니티·카드·바인더·아카이브**와 **무료·비양도 리워드**로 정면 차별화한다.

## 1. 사업 맥락과 ICONS 기존 자산과의 관계 ★

### 1.1 우리가 만들려는 것
라이선스 IP(카카오프렌즈·네이버웹툰 등) 실물 굿즈를 **직접 제조·판매**하는 B2C 온라인 팝업. IP가 **2주 단위로 교체**되며(A IP 2주 → B IP 2주), 게임화 요소(카드·미션·포인트·등급·한정판)를 얹는다. 디지털 수집카드는 **실물 구매 후 제공되는 무료 리워드**로만 지급하고, 유료 가챠·포인트 충전은 배제한다.

### 1.2 검토 당시 ICONS와의 결정적 긴장
2026-06-30 작성 당시 ICONS는 슈퍼앱의 핵심 인게이지먼트 루프로 **유료 디지털 가챠**를 설계했다. 다음 표는 피벗 전 비교이며 현행 상태가 아니다.

| 구분 | 기존 ICONS (PRD/ARCH/ADR 0001) | 이번 온라인 팝업 브리프 |
|---|---|---|
| 카드 획득 | **충전금(유료)** → RNG 가챠 → 천장 | 실물 구매 후 **무료 리워드** |
| 지갑 | 토스 충전, 선불 잔액(`wallets`/`wallet_ledger`) | **충전금 없음** |
| 규제 수용 | 확률 공시·게임물 등급분류·전자금융 환불을 **요구사항으로 수용** | 규제 표면 축소를 목표로 하되 적용 여부는 미확정 |
| 스키마 | `card_pools`·`pool_odds`·`pulls` 등 가챠 스키마 적용됨(P2) | 무료 발급 기반 |

검토 당시 `supabase/migrations`에는 가챠 스키마(P2)가 존재했다. 현행은 migration `20260707100001_p2_gacha_decommission.sql`이 유료 지갑·뽑기 객체를 물리 제거했고, 재사용 가능한 카드풀·확률 원장·바인더만 남겼다.

### 1.3 권고 — 3가지 선택지 (의사결정 필요)
- **(A) 무료 리워드로 피벗 (권장).** 온라인 팝업을 ICONS의 새 척추로 삼고, 유료 가챠(ADR 0001)를 보류/철회한다. 법적·PG 리스크가 가장 낮고 본 브리프 의도에 부합. ADR 0001을 supersede하는 새 ADR 기록 필요.
- **(B) 도메인 분리.** 유료 가챠는 별도 법인·별도 도메인·별도 PG 계약으로 격리하고, 온라인 팝업(무료)만 iconsip.com에서 운영. 운영·회계·정산이 복잡해지고 회원/데이터가 쪼개진다.
- **(C) 공존(비권장).** 한 사이트에 유료 가챠 + 무료 리워드. 무료 모델의 규제·PG 이점이 사라지고, "유료 확률형으로 오해"라는 본 브리프의 최대 우려(§13)가 현실화된다.

> 본 보고서 이하의 모든 설계는 **(A) 무료 리워드 피벗**을 기본 전제로 한다. 최종 결정은 사업·법무 판단 사항이다.

## 3. 벤치마크 분석

8개 서비스를 수익구조·UX·결제·랜덤리워드·커뮤니티·적용/안티패턴으로 해부했다(상세 별첨 데이터). 핵심만 요약한다.

| 서비스 | 한 줄 정체성 | 우리가 ★훔칠 것 | 우리가 ✗피할 것 |
|---|---|---|---|
| **픽앤팝** | 모바일 실물 가챠, 50% 포인트환급 | 보관→묶음배송(객단가↑), 교환방 | 50%환급-재뽑기 = 유료가챠+충전금 |
| **콜리** | 덕질 SNS+커머스 | 컬렉션 전시→좋아요→랭킹 소셜루프 | 데이터·제작 B2B로 정체성 분산 |
| **무신사 래플** | 한정판 공정배분 | **응모 무과금→당첨자만 정가결제** | 봇 우회·리셀·박탈감 마케팅 |
| **KREAM** | 한정판 거래소+드로우 | 매일 드로우 리텐션, 정품검수 신뢰 | C2C 중개 마진함정(수수료=매출 55%) |
| **위버스샵** | 팬덤 OS(커뮤+커머스+구독) | **팬덤 OS 통합·종료후 잔존**, 디지털+실물 번들 | 무료팔로우→유료멤버십 의무화 |
| **라인프렌즈/카카오** | 자체 IP 굿즈+라이선싱 | 파생캐릭터·콜라보로 IP 변주 | B2B 라이선싱 아웃바운드 |
| **더현대 팝업** | 오프라인 팝업 성지 | **이틀1회 교체→체류·N차방문** | 종료와 함께 휘발 |
| **팝마트** | 블라인드박스 글로벌 | **회원 매출 92.7%·재구매 49.4%**, 무과금 레어도등급 | 유료 블라인드박스, 라부부 리셀 거품 |

### 핵심 시사점 Top 5
1. **회원 기반 + 수집 루프 = 리텐션 핵심** (팝마트가 수치로 증명). 우리 "회원 + 무료 카드 + 바인더 잔존"은 산업적으로 옳은 방향이다.
2. **"갈 때마다 새로움"이 체류·재방문을 만든다** (더현대 이틀1회 교체). 2주 IP 교체를 캘린더화하고 "지나면 못 본다"는 한정성을 전면화하라.
3. **희소 상품은 "응모 무과금 → 당첨자만 정가 결제"로 사행성 없이 배분**하라 (무신사·KREAM). 유료 가챠 배제 원칙과 충돌하지 않는다.
4. **커뮤니티↔컬렉션↔마이페이지를 하나의 OS로 통합하고 종료 후 잔존**시켜라 (Weverse). 단 무료 팔로우는 끝까지 무료로.
5. **무과금 레어도 등급 + 파생 변주**로 수집 사다리와 콘텐츠 보충을 동시에(팝마트 시크릿/히든, 라인프렌즈 minini).

### 안티패턴 Top 3
1. **유료 랜덤 + 충전금 재투입 루프**(픽앤팝 50%환급, 팝마트 블라인드박스) — 우리가 명시 배제한 모델.
2. **인위적 품귀 → 리셀 거품 → 붕괴**(라부부 리셀 2,000%↑ 후 80% 폭락). 무료·비양도 리워드로 리셀 동기를 원천 차단.
3. **무료 약속의 유료 전환**(Weverse 멤버십 의무화·플랫폼 30~60% 수취). 신뢰 파괴.

## 4. 포지셔닝 — "끝나도 남는 팝업"

벤치마크가 공유하는 약점은 **휘발성**이다. 오프라인 팝업은 끝나면 사라지고, 래플은 탈락자에게 박탈감을, 블라인드박스는 리셀 거품을 남긴다. 우리의 차별화 명제:

> **"팝업은 2주마다 바뀌지만, 당신의 카드·바인더·기록·커뮤니티는 영원히 남는다."**

- 입장 경험(3D/스토리형 랜딩·티저·카운트다운)은 오프라인 팝업의 "경험"을 온라인으로 옮긴다.
- 구매 → 무료 카드 리워드 → 바인더 적재 → 전시·랭킹 → 다음 IP 팝업으로 이어지는 **수집·소셜 루프**가 재방문 엔진이다.
- 종료된 IP는 **아카이브**로 회수되어 FOMO(지금 사야 함)와 잔존(기록은 남음)을 동시에 만든다.

## 5. 법률 리스크 (요약 — 상세 근거는 본문 출처)

> 전제: **무료 리워드 + 실물 결제** 설계. 최종 판단은 변호사·게임위 확인 필요.

### 5.1 디지털 카드 — 위험 축소 설계, 면제 미확정 ★
- [게임산업진흥에 관한 법률 제2조제11호](https://www.law.go.kr/LSW/lsInfoP.do?lsId=010196)는 직접적·간접적으로 유상 구매하는 게임아이템과 유상·무상 아이템의 결합을 정의에 포함한다. 굿즈 주문과 무작위 카드팩의 연결이 간접 유상에 해당하는지, 서비스가 게임물인지, 확률 표시의무가 적용되는지는 문언만으로 면제를 단정하지 않는다.
- 카드 자체 가격·충전금·현금화·C2C를 두지 않고 굿즈 가격을 카드 유무와 무관하게 고정하는 것은 위험을 낮추는 제품 사실이다. 이것만으로 형법상 사행성 불성립이나 다른 규제 면제를 확정하지 않는다.
- 카드 단독 유료판매, 충전금·포인트 구매, 추가 대금, 현금화·거래소는 위험을 크게 높이므로 금지한다. 주문 연동 자체도 법률 검토 대상에서 제외하지 않는다.
- 공개 전 대한민국 변호사·게임물관리위원회와 적용 법률·분류·표시 방법을 확인한다. 확인 전에는 주문 연동 무작위 카드팩과 참여형 게임 보상을 공개하지 않고, 표시 또는 소비자 고지가 필요하면 `pool_odds`를 진실원으로 카드풀·발급 조건과 함께 노출한다.

### 5.2 동일가치 실물 랜덤상품 — 균등가치가 핵심
- 복표·사행성의 핵심 요건은 "**일부 당첨이익 / 나머지 손실**"(대법원 2003도5433). **모든 구성품 가치를 동일하게** 맞추면 손실자가 없어 사행성 요건이 깨진다.
- 실질 리스크는 사행성보다 **전자상거래법 제13조 구성품 정보 미제공 + 표시광고법 미끼 광고**다(공정위 포켓몬코리아 과태료 100만원, 우주마켓 등 3사 1,900만원·영업정지 선례).
- 안전설계 4원칙: ①가치 동일성 입증 ②미끼·고가당첨 금지 ③전 구성품·확률 사전 표시 ④7일 청약철회 보장(개봉=철회 가능).

### 5.3 일반 커머스 법률
- **전자상거래법**: 2주 다품목 반복판매 → 통신판매업 신고 **필수**. 사업자정보·신고번호 상시 표시. 실물 굿즈는 **7일 청약철회 기본 보장**("한정판=환불불가" 일률 고지는 위법 소지). 디지털 카드는 "제공 개시 후 철회 제한" 가능하나 **제17조 6항의 명확한 표시·조치를 갖춰야만 유효**. 환급 3영업일(지연 시 연 15%).
- **표시광고법 ★2주 팝업 최대 리스크**: '한정/마감임박'을 내세우고 마감 후 동일 조건으로 재판매하면 거짓·과장(에듀윌 등 **과징금 3.1억** 선례). '품절임박/단 N개'는 실재고와 연동·로깅해야 한다. 타이머·옵션 UI는 전자상거래법 다크패턴 규제(2025.2.14)도 함께 통과해야 한다.
- **경품류 고시**: 2016년 폐지 → 무료 증정(소비자경품) **가액 한도 규제 없음**(우리에게 유리). 단 공정거래법상 부당 고객유인은 잔존.
- **개인정보**: 마케팅 동의는 분리 옵트인으로 받고 야간 광고성 발송은 별도 요건을 확인한다. 이 보고서의 제안은 2026-08-12 현행 PRD에서 만 14세 이상 전용·법정대리인 동의 예외 없음·자가신고와 분리된 `verified_14_plus`·신규 거절 후 durable 파기로 내부 결정됐다. 다만 구현·provider 계약·법정 문서 시행 전에는 실제 서비스가 자동 연령 gate를 제공한다고 표시하지 않는다.
- **미성년자**: 만 14세 이상 미성년의 결제 취소권과 법정대리인 동의 필요 여부는 가입 가능 연령과 다른 문제다. 민법 제5조를 포함한 적용 요건을 변호사와 확인하고 예방·증빙·결제 한도·취소 경로를 설계한다.
- **해외판매 ★최대 리스크 = IP 라이선스 territory 위반**: 카카오/네이버웹툰 IP는 한국 한정일 가능성이 높고, 무단 해외 직배송은 **계약 해지·라이선스 박탈**로 이어질 수 있다(관세보다 큰 위협). 미국 de minimis $800 면세 폐지(2025.8.29), EU 14일 무조건 철회권. **초기엔 국내 한정, 해외는 라이선서 서면 동의 후.**

## 6. PG·결제 리스크 및 전략

- **표준 입점 가능**: 실물 굿즈만 결제 + 무료 리워드 → 결제금액 = 상품금액 일치 → 카드사·PG 최선호 저위험 유형. 토스페이먼츠·KG이니시스·NHN KCP·나이스페이먼츠·스마트로 모두 일반 통신판매로 입점 가능, 네이버페이·카카오페이도 가능.
- **고위험 키워드 회피**: 충전·유료가챠·유료랜덤팩은 거의 모든 PG에서 제한(카카오페이는 "랜덤박스" 명시 제한업종, PortOne은 High-Risk 분류).
- **BM 설명서**: "라이선스 IP 실물 굿즈 판매, 카드 자체 가격·추가 대금·충전·현금전환 없음"이라는 기술 사실과 주문 연동 조건을 숨기지 않고 적는다. 유료 가챠·충전 상품으로 오인시키는 표현은 제거하되, 법령·법무 검토상 확률 표시가 필요하면 `pool_odds`를 발급 조건과 함께 공개한다. 심사원은 비로그인 공개 탐색을 확인하고, 구매·결제는 ICONS의 로그인 gate를 유지한 승인된 심사용 계정으로 검증한다.
- **선결 요건**: 통신판매업 신고(네이버페이는 선행 필수), 에스크로(현금성 거래), 보증보험(나이스 필수).
- **동일가치 랜덤은 단계 분리**: 1차 입점은 순수 실물만. 랜덤 세트는 정산 안정화 후 신규계약팀 사전 컨펌받아 "균등가치 블라인드 기획세트"로 추가.

## 8. 수익모델

- **본류: 상품 마진** (직접 판매자). 충전·구독·중개 수수료가 아니다.
- **객단가 상향 장치**(무과금): 묶음배송 무료 임계치(픽앤팝식), 한정판·세트 구성, 시즌 컬렉션.
- **재방문·LTV 엔진**: 무료 카드 수집 → 바인더 도감 진행률 → 전시·랭킹 → 미션·등급 → 다음 IP 팝업. (팝마트 재구매율 49.4%가 수집 루프의 위력을 입증)
- **"왜 들어오고 왜 다시 오는가"**(소비자 관점):
  - 들어오는 이유: 좋아하는 IP의 한정 굿즈 + "지금만" 한정성 + 입장 경험.
  - 다시 오는 이유: 모으던 카드/바인더/도감, 미션·등급 진척, 커뮤니티 소통, 2주마다 바뀌는 새 IP.
- **확장성**: 오프라인 대비 회당 고정비가 낮아 IP 회차를 빠르게 돌릴수록 한계비용이 체감한다. B2B 마켓플레이스·데이터 판매·제작대행(콜리형)은 **범위 밖**으로 둔다(정체성 분산 방지).

## 10. ICONS 적용 방향 (종합 권고)

1. **유료 가챠 처리 결정**: 이 권고는 이후 [ADR-0003](../adr/0003-free-reward-pivot.md)과 #65로 채택·구현됐다. 유료 지갑·뽑기 객체는 제거됐지만 법률·PG·브랜드 위험이 자동 해소된다고 단정하지 않는다.
2. **기존 자산 최대 재사용**: 인증·온보딩·커뮤니티(신고/차단/모더레이션)·검색·admin·카탈로그·토스 웹훅 골격과 `pool_odds`를 재사용한다. 현재 주문 확정은 조건에 맞는 카드팩만 발급하고, 카드는 사용자 개봉 `open_draw_ticket` 또는 참여형 게임 `play_game`에서 결정된다.
3. **MVP는 "실물 커머스 + 무료 카드 + 회원 + 1개 팝업"** 으로 좁힌다(§PRD). 대기열·AR·3D·동일가치 랜덤은 후속.
4. **제품 사실을 코드로 강제한다**: 카드 자체 결제 RPC 없음, 상품가 = 카드팩 유무와 무관하게 고정, 주문→카드팩→개봉 원장, 청약철회·동의 로그. 이것은 법적 면제 보장이 아니므로 별도 분류·표시·약관 gate를 둔다.
5. **드롭/한정은 래플(응모 무과금)** 우선 — 선착순 동시성·사행성·봇 리스크를 동시에 낮춘다.
6. **"끝나도 남는 것"을 제품의 중심축**으로: 종료 IP 아카이브, 카드/바인더 잔존, 커뮤니티 상시화.

## 11. 출처와 면책

- **검증 강도**: 통계청 온라인쇼핑 수치는 3표 적대적 검증 통과. 법률은 법령 원문·공정위/문체부 보도자료·로펌 해설 등 1차 출처 다수 교차확인. PG·벤치마크·시장 일부는 공식·언론·2차 출처 혼재로 "출처 있음(추가 검증 권장)" 수준.
- **주요 1차 출처**: 통계청 온라인쇼핑동향(kostat.go.kr) · 게임산업법 제2·33조 및 문체부 해설서(korea.kr) · 공정위 제재 보도(korea.kr, 포켓몬·우주마켓·에듀윌) · 대법원 2003도5433 · 전자상거래법(law.go.kr) · 개인정보보호법/정보통신망법(casenote) · TossPayments/Cloudflare/Supabase 공식 문서.
- **면책**: 본 문서는 공개 자료 기반 리서치 종합이며 **법률 자문이 아니다.** 확률형/사행성/랜덤/미성년/해외/territory/PG 입점은 시행 시점에 변호사·게임물관리위원회·각 PG 심사담당의 개별 확인이 필요하다. 수치·법령은 개정으로 변동될 수 있다.
