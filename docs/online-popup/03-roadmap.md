## 0. 지금 당장 해야 할 액션 (이번 주) ★

개발보다 먼저 풀어야 할 **의사결정·검증** 항목이다. 순서가 중요하다.

1. ✅ **[결정됨 2026-07-03, 구현 완료 2026-07-07] 유료 가챠 폐기 → 무료 리워드로 피벗** ([ADR-0003](../adr/0003-free-reward-pivot.md), 0001 supersede). #65와 migration `20260707100001_p2_gacha_decommission.sql`이 충전금·유료 뽑기 객체를 제거했다.
2. **[법무] IP 라이선스 계약 territory·채널·디지털 포함 여부 확인.** 카카오프렌즈·네이버웹툰 등 계약서의 (a)판매 지역(국내/해외) (b)온라인 채널 허용 (c)디지털 수집카드가 라이선스 범위인지 (d)2차 활용/굿즈 종류. → **해외 판매·디지털 카드의 가능 여부가 여기서 갈린다.**
3. **[법무] BM 1페이지 요약서 작성 → 변호사 자문.** "실물만 유료결제, 카드는 무상 리워드, 충전/유료가챠/카드거래소 없음"을 명문화하고 §5 체크리스트로 검토.
4. **[사업] 사업자등록·통신판매업 신고 착수**(미완 시). PG·네이버페이 입점의 선결 요건.
5. **[PG] 결제사 신규계약팀 사전 컨택**(토스/KG이니시스 등)에 BM 요약 공유 → 카드 자체 가격·추가 대금·충전금은 없지만 굿즈 주문과 무작위 보상이 연결된다는 전체 BM을 사전 확인한다. 유료 가챠·충전 상품으로 오인시키는 문구는 제거하되 필요한 확률 고지는 숨기지 않는다.
6. **[제품] MVP 1개 팝업의 IP·굿즈 SKU·카드풀 확정.** 첫 팝업을 무엇으로 열지.

## 1. Post-launch #115 타임라인 로드맵 (2주 / 1개월 / 3개월 / 6개월)

> 기준일 2026-08-11. 아래 일정은 이미 구현된 ICONS 기반을 다시 만드는 계획이 아니라 #115의 팝업 운영 계층을 추가하는 post-launch 후보 일정이다.

### 현행 기반 (착수 전 완료)
- 이메일/PW·Google/Apple/Kakao 인증, 공개 카탈로그·검색·커뮤니티, staff/admin 운영 경로가 구현돼 있다.
- 굿즈 장바구니→재고 선점→토스 승인·웹훅 확정→주문·청약철회/환불과 관리자 재고·주문 운영 경로가 구현돼 있다.
- 유료 가챠·충전금은 제거됐고, `reward_policies`·`draw_tickets`·`card_grants`, 주문 확정→카드팩 발급→`open_draw_ticket` 개봉→카드 발급, 바인더와 카드 보상형 참여형 게임이 구현돼 있다.

### 착수 후 ~2주: 팝업 기반 + 컴플라이언스 확정
- 법무·PG 선검토 착수(§0). 통신판매업 신고.
- 첫 팝업의 IP·굿즈 SKU·카드풀·운영 기간을 확정한다.
- 기존 카탈로그·결제·카드 리워드 경로를 재사용하고 `popups`·미션·운영 회차처럼 #115에만 필요한 새 도메인과 migration을 설계한다.

### 착수 후 ~1개월: 팝업 MVP 구축
- 기존 공개 카탈로그·굿즈 결제·카드팩 경로에 단일 팝업 랜딩(2D·카운트다운)과 아카이브 전환을 연결한다.
- 기존 admin에 팝업 기간·노출·연결 상품·운영 상태를 관리하는 최소 콘솔과 기본 통계를 추가한다.
- 청약철회·마케팅 분리 동의 UI를 팝업 흐름에서 재검증한다. #188 연령 gate의 내부 결정은 현행 PRD에 있으나 이 historical popup roadmap의 AC가 아니며, 구현·provider·법정 문서 시행 gate를 별도로 통과해야 한다.
- prod 빌드 기준 행동 QA(이 repo `next dev` 하이드레이션 이슈 회피).

### ~3개월: MVP 출시 + V1 착수
- **MVP 소프트 론칭**(1개 IP 팝업, 한정 SKU). 결제·재고·발급·환불 실거래 검증.
- 운영 루프 가동: 2주 교체·아카이브, 미션·등급·룰렛/도장깨기, 카드 자랑·랭킹.
- **래플(응모 무과금→당첨 결제)** 도입(한정 드롭). Turnstile + Rate Limiting + 봇/중복 방지.
- 브랜드 리포트 v1(팝업별 매출·전환·연령·채널).

### ~6개월: V1 안정화 + V2 검토
- 2~3개 IP 회차 운영 데이터 축적, KPI 기반 개선(전환·재방문·수집률).
- 기존 소셜 로그인은 재사용하고 production controlled smoke를 닫는다. 알림신청·사전예약과 커뮤니티를 고도화한다.
- **V2 검토**: 동일가치 실물 랜덤("균등가치 기획세트") 법률·PG 단계 분리 진입, 대기열(트래픽 시), 3D/AR, 카드 교환.
- **#66 V2 검토**: Expo WebView는 refresh token·범용 Supabase session 주입을 금지한다. native 인증 subject/session과 정확한 capability·resource에 묶인 single-use bridge token을 first-party BFF가 소비하는 방식을 기본으로 하고, 짧은 access JWT 직접 주입은 별도 보안 승인 예외로만 둔다.

## 3. 법/PG 선검토 항목 (체크리스트) ★

> 모두 **변호사·게임물관리위원회·PG 심사담당 확인 필요**. 보고서 §5·§6 근거.

### 법률
- [x] 유료 가챠 폐기 결정·구현 완료([ADR-0003](../adr/0003-free-reward-pivot.md), #65). ADR-0001은 superseded 상태다.
- [ ] **게임물관리위원회·변호사 사전 확인** — 서비스의 게임물 해당성, 주문 연동 보상의 간접 유상성, 확률 표시의무와 필요한 공개 방법을 확인한다. 확인 전 주문 연동 무작위 카드팩·참여형 게임 보상은 공개하지 않는다.
- [ ] 변호사 의견서: 카드 자체 가격·추가 대금·충전금·현금화가 없고 **상품가가 카드 무관 고정**이라는 사실을 제시하되, 이를 자동 면제 근거로 단정하지 않는다.
- [ ] IP 라이선스 territory·채널·디지털 범위 확인(해외·디지털 카드 가부).
- [ ] 전자상거래법: 통신판매업 신고, 사업자/신고번호 표시, **실물 7일 청약철회 보장**, 디지털 카드 청약철회 제한 표시·조치(제17조 6항).
- [ ] 표시광고법: '한정/마감임박' 반복판매 차단·근거 보존, '품절임박'=실재고 연동.
- [ ] 개인정보: 마케팅 **분리 옵트인**과 **야간(21시~) 푸시 별도 동의**를 검증한다. #188의 만 14세 이상·법정대리인 동의 예외 없음·`verified_14_plus`·신규 거절 계정 durable 파기는 현행 정본의 내부 결정이지만 이 historical roadmap의 구현 AC가 아니다.
- [ ] 미성년자: #188 후보 승인 시 만 14세 이상 미성년의 결제 취소권·법정대리인 동의 필요 여부·결제 한도·고지·로그를 가입 gate와 분리해 법무 확인한다.
- [ ] (V2) 동일가치 실물 랜덤: 균등가치 입증·구성/확률 표시·미끼 금지.

### PG
- [ ] BM 설명서: "실물 굿즈 판매, 결제금액=정가, 카드=무상 부수 콘텐츠(판매·충전·현금화 불가)".
- [ ] 사이트 전면·약관에서 유료 가챠·충전 상품으로 오인시키는 문구를 제거한다. 법령·법무 검토상 확률 표시가 필요하면 `pool_odds`의 현재 값을 발급 조건과 함께 노출한다.
- [ ] 통신판매업 신고번호·사업자정보 하단 노출, 굿즈 3개 이상, 비로그인 공개 탐색→구매 시 로그인 gate→결제 흐름 점검.
- [ ] 에스크로(현금성 거래)·보증보험 준비.
- [ ] 1차 입점=순수 실물만. 동일가치 랜덤은 정산 안정화 후 신규계약팀 사전 컨펌·단계 분리.

## 4. MVP 출시 전략

- **좁게 출시**: 1개 IP 팝업 · 한정 SKU · 무료 카드 1풀 · 회원 기반. 대기열·AR·동일가치 랜덤은 뺀다.
- **소프트 론칭**: 소규모 팬 대상으로 결제·재고·발급·환불 실거래를 먼저 검증(돈·재고 무결성 최우선).
- **한정성으로 첫 트래픽**: 카운트다운·티저·인플루언서 시딩으로 오픈 모멘텀. 단 표시광고법 준수(실재고·실마감).
- **데이터 계측 처음부터**: 퍼널(방문→가입→구매), 수집률, 공유율 이벤트를 MVP에 내장(브랜드 리포트·개선의 토대).

| 네이버 검색 | 인텐트 흡수 | IP·굿즈 키워드 SEO, 네이버페이 연동 |
| 팬 커뮤니티 | 진성 유입 | IP별 커뮤니티 시딩, 공식 라이선스 신뢰 메시지 |

## 6. 운영 전략

- **2주 캘린더 운영**: IP 회차를 사전 캘린더화(예고→티저→오픈→중반→마감→아카이브). 더현대식 "갈 때마다 새로움".
- **잔존 엔진**: 종료 IP는 아카이브로, 카드·바인더·커뮤니티는 상시. 다음 회차로 자연 연결.
- **CS·배송·환불**: 청약철회 3영업일 환급, 미성년 취소 워크플로, 반품·재배송 정책 명문화.
- **콘텐츠 보충**: 같은 IP를 파생·콜라보·등급 변주로 늘려 회차 콘텐츠 공급(라인프렌즈·팝마트식).
- **커뮤니티 모더레이션**: 신고·차단·숨김(기존 ICONS 자산), 운영 정책 문서화.
