# 지우학 온라인 팝업 시연 모듈

`icons-hq/icons`의 `/sample/aouad`를 ICONS IP에서 검토할 수 있도록 가져온 독립 화면입니다. 원본 커밋은 `7989794969bd74cf53a0fdefb595cfcfff8717b9`이며, 복사 경로와 원본 SHA-256은 `provenance.json`에 기록합니다. 이후의 로컬 개선은 이 원본 입력 기록을 변경하지 않습니다.

## 구성

- `source/components/aouad/`: 오프닝, 15개 허브 장면, 10개 상세 존, 굿즈 상세, 학생증 및 시연 게임.
- `source/components/popup/`: 이동 안내도와 공통 HUD.
- `source/lib/`: 브라우저 시연 상태를 위한 게임 엔진, 소리, URL 및 스크롤 처리.
- `private/ip-popups/aouad/`: 원본 이미지·영상·오디오와 검수한 신규 컨셉 굿즈 이미지. 원본 206개의 복사 이력은 `provenance.json`에 남습니다.
- `HyosanGameDialog.client.tsx`·`hyosan/`: 효산의 기억 3D 게임 진입, 고정 원본·패키지 manifest와 재빌드용 소스 보관본.
- `private/ip-popups/aouad-hyosan/`: 선택한 게임의 정적 시연 패키지. 팝업 미디어와 분리된 Route Handler가 제공합니다.

기본 export는 `source/components/aouad/AouadSample.jsx`입니다. 무대의 높이는 `100dvh`이며 자체 CSS Module 토큰을 씁니다. Next.js 클라이언트 경계에서 동적으로 불러오고, 전역 셸과의 경계는 호스트 라우트가 소유합니다. Phaser는 게임 진입 시 동적으로 불러오며 원본의 `phaser4` 별칭을 저장소의 `phaser` 4.2.1 의존성으로 연결했습니다.

## 효산의 기억 통합

체험존은 급식실 → 방송실 → 도서관 → 효산의 기억 순서입니다. 마지막 장면 `?s=hyosan`에서 **효산의 기억 시작하기**를 누르면 최신 활 전투·강화·학교 탐험 게임을 같은 페이지의 전체 화면으로 엽니다. 게임 엔진과 3D 모델은 이때 처음 요청하고, 복귀하면 팝업 장면·학생증·시연 상태를 유지합니다. 기존 급식실·방송실·도서관 체험도 그대로 이용할 수 있습니다.

원본은 `88b9937a118120f60ef5166b66e5c370fc292b3a`의 독립 Vite 시연판입니다. 게임 로직과 원본 모델을 바꾸지 않고, 검산한 HTML·JS의 URL 8곳을 `/ip-popups/aouad/hyosan/`으로 재배치했습니다. 모델 원본 15개와 각 전송용 압축 파일의 SHA-256을 검증합니다. 기존 `/games/hyosan-memories`나 개발용 에셋 경로의 권한을 여는 방식은 사용하지 않습니다.

Vercel CDN은 전송 압축을 다시 적용할 수 있습니다. 배포 뒤에는 응답의 실제 압축 방식·크기·해시를 기록하고, 압축을 해제한 파일을 패키지 원본 SHA-256과 비교합니다. 사전 압축 파일 크기는 최종 CDN 전송량과 구분합니다.

진행·활 강화·난이도는 이 브라우저에 저장합니다. 같은 origin의 게임은 기존 Web Lock으로 저장을 보호하며, 다른 탭에서 이미 열려 있으면 안내 후 재시도합니다. 팝업으로 돌아가면 게임 문서를 해제해 잠금도 반환합니다. 팝업 시연 초기화와 게임 안의 새 탐험은 각각의 저장 범위를 사용하며, 서버 계정 진행·카드·구매권·실제 리워드는 만들지 않습니다.

키보드로는 게임 메뉴의 첫 버튼에서 `Shift+Tab`, 마지막 버튼에서 `Tab`을 눌러 상단 복귀 버튼으로 이동하고 `Enter`로 닫을 수 있습니다. 일반 `Escape`는 게임 일시정지를 유지하며, 닫으면 원래 시작 버튼에 포커스를 돌려줍니다.

`hyosan/upstream-source.tar.gz`와 검산된 원본 미디어로 다른 작업 폴더 없이 원본 빌드를 재현할 수 있습니다. 실행·검증·교체 절차는 [운영 가이드](../../../docs/runbooks/aouad-executive-demo.md#효산의-기억-게임-통합--2026-09-10)를 따릅니다. 이번 연결은 선택된 게임의 시연 통합이며 기존 최종 미술·실기기 성능 승인 상태를 변경하지 않습니다.

## 시연과 운영의 경계

원본은 비밀번호로 보호된 기획 시연판입니다. 굿즈·가격·재고·기간·구매권·주문·당첨·배송·현장 예약·커뮤니티 글은 시연 데이터이며 브라우저 상태로 작동합니다. 이식만으로 실제 결제, 재고, 권리 발급, 배송 신청, 예약 및 외부 게시가 활성화되는 것은 아닙니다. 실거래를 연결하려면 서버 권한·멱등 처리·운영 정책과 해당 도메인의 별도 검증이 필요합니다.

원본 `40_dev/adr/ADR-0024-official-footage-in-aouad-sample.md`는 PM 제공 공식 타이틀 영상 1건의 시연 사용 확인을 기록합니다. 같은 ADR은 나머지 웹 수집 스틸의 권리 미확보 상태와 대외 제출 시 최종 자산·문안 감수 경계를 유지합니다. `provenance.json`은 파일 출처 기록이며 별도 자산 사용 허가를 의미하지 않습니다.

위 내용은 원본 ADR 작성 당시의 기록입니다. 2026-09-10 PM은 현재 시연에 포함된 스틸의 Netflix 검토용 공유에 대해 사용을 승인했습니다. 이번 공개 전환은 그 검토용 시연 범위에 따라 페이지와 현재 에셋을 로그인 없이 엽니다. PM의 시연 사용 승인은 상업 판매나 이후 추가되는 자료의 사용 범위로 확대하지 않습니다.

## 이식 검증

복사 시 원본 엔트리의 재귀 import 경로 36개를 추출해 빠진 상대 의존성이 없음을 확인했습니다. 원본 에셋은 원본 SHA-256과 일치하도록 복사했습니다. 이후 수정 검증은 호스트 라우트의 브라우저 QA, 관련 테스트, lint 및 build 결과로 기록합니다.

## 로컬 품질 개선

- 임시 도형 합성·사진과 맞지 않는 제품·인물 표기를 내장 ImageGen으로 만든 컨셉 굿즈 이미지 **23개**로 교체했습니다. 일반 굿즈 9종은 `generated-asset-manifest.json`, 소형 경품 14종은 `generated-box-asset-manifest.json`에 원본 PNG·최종 WebP의 SHA-256과 검수 결과를 기록합니다. 무크롭 WebP quality 90으로 패키징했고 최종 23종은 총 4,735,676 bytes입니다. 2026-09-09 최종 23종의 변환 전·후 직접 이미지 검수와 원본·최종 SHA 46개 검증을 통과했습니다. 로컬 HTTP 응답 23종도 최종 SHA와 일치합니다. 결과는 제작된 실물의 촬영본이 아닌 프레젠테이션용 디자인 시안입니다.
- 굿즈 상세의 원작 설명은 사진에 실제로 보이는 내용과 디자인 모티프를 설명하도록 정리했습니다. 표시된 `1인 1개` 제한은 숫자 `per: 1`로도 기록해 시연 장바구니와 같은 값을 사용합니다.
- 히어로 영상과 이미지 순환은 화면 노출, 브라우저 탭 상태, 모션 축소 설정을 따릅니다. 화면을 떠날 때는 진행 중인 재생 요청까지 정리하며, 영상 로딩 실패에는 포스터를 보여줍니다. 관련 수명주기는 `hero-playback.test.ts`로 검증합니다.
- `presentation-state.js`는 저장된 값을 현재 화면이 쓰는 필드로 다시 구성합니다. 손상된 JSON, 잘못된 당첨·주문 값, 범위를 벗어난 예약은 화면에 직접 전달하지 않습니다. 브라우저 저장소가 차단되거나 가득 차도 그 세션의 변경은 메모리에 유지됩니다.
- `presentation-commerce.js`는 선택한 옵션을 장바구니 행에 보존하고 같은 굿즈의 모든 옵션 수량에 공통 한도를 적용합니다. 옵션을 고르지 않은 의류와 알 수 없는 굿즈는 추가하지 않습니다. 굿즈 상세의 주 행동은 상시 판매·구매권·사전예약·선착순·래플을 구분하는 순수 상태 데이터로 제공합니다. 실제 거래 API를 호출하지 않습니다.

## 접근과 검증

정본 경로는 `/ip/aouad`입니다. 2026-09-10 현재 `AOUAD_POPUP_PUBLIC=true`인 공개 모드라서 로그인 없이 `/ip`의 프레젠테이션 카드와 직접 경로를 사용할 수 있습니다. `AOUAD_POPUP_PUBLIC=false`로 되돌리면 staff/admin 전용 카드·경로가 됩니다. 서버 공개·회수 스위치, 로컬 QA, 배포 후 확인 순서는 [시연 운영 가이드](../../../docs/runbooks/aouad-executive-demo.md)를 따릅니다. 공개 카탈로그에 가짜 IP나 굿즈 행을 추가하지 않습니다.

에셋 229개는 `public` 밖에 보관하고 `/ip-popups/aouad/[...asset]`의 Node Route Handler가 화면과 동일한 공개·회수 스위치를 매 요청 확인합니다. 현재 공개 모드에서는 인증 없이 통과하지만, `asset-index.json`에 기록된 파일만 허용하고 GET·HEAD·영상 Range 응답은 모두 private/no-store입니다. 비활성화·잘못된 경로·경로 탈출·symlink는 닫힌 상태로 유지합니다. 인증이 필요한 비공개 모드의 이미지는 Next 이미지 최적화 프록시를 거치지 않습니다. Vercel 출력 추적은 이 에셋 라우트에만 비공개 파일을 포함합니다. 저장 위치 변경 전후 229개 SHA가 일치하며, `provenance.json`은 원본 입력 경로 기록이므로 보존합니다.

2026-09-09 현재 전체 저장소 테스트 4,889개, TypeScript 검사와 production build가 통과했습니다. 이 모듈의 lint는 오류·경고 0개이며 전체 저장소에는 기존 downloader 경고 1개가 남습니다. 브라우저에서는 첫 방문 학생증 발급·허브 진입, 37개 굿즈 상세, 메인 14개 장면, 장바구니 옵션·주문, 커뮤니티 작성, 현장 예약을 확인했습니다. 급식실·방송실·도서관은 실제 플레이 완료·대화상자 중 정지·재도전 제한을, 네 뽑기 방식은 개봉·결과·복귀·중단 취소·잔여 수량을 확인했습니다.

사진 업로드는 브라우저의 이미지 디코더로 비율을 유지한 최대 240px JPEG를 만들고, 실패 안내와 Object URL 해제를 처리합니다. 실제 파일 선택 후 240×180 이미지가 학생증에 반영되고 새로고침에도 복원되는 것을 확인했습니다. 허브는 가까운 장면부터 내용을 마운트하고 진열 이미지는 화면·가로 레일 안에 들어올 때 불러옵니다. 이미 방문한 장면은 상태를 유지합니다. 기본 표지의 초기 이미지 요청은 표지·학생증 사진 2개였으며, 모바일 14개 장면 직접 진입과 진열장 가로 이동을 재검증했습니다.

## 모바일 표시와 회귀 검증

모바일 안내 시트나 학교 안내도가 게임을 가리는 동안에는 급식실·방송실·도서관이 일시정지합니다. 메뉴를 닫거나 화면을 옮기면 기존 게임 상태로 복귀하며, 학생증 모달도 같은 일시정지 경로를 사용합니다.

방송실의 게임 세계는 좁고 짧은 화면에서도 HUD 위의 가용 높이에 전체가 들어오도록 같은 비율로 축소됩니다. 표시 크기만 맞추며 게임 좌표·물리·내려다보는 거리는 유지합니다.

모바일 오프라인 포스터는 배경 이미지의 로딩 여부와 무관하게 그리드 폭과 3:2 비율을 유지합니다. 설명은 터치 한 번으로 열리고 머리 영역 안에 배치되며, 학생증 패널의 닫기는 탭 스크롤과 분리합니다. 주문 행은 이미지·이름/옵션·금액을 두 열로 배치하고, 화면 아래 여백은 펼친 HUD의 실제 높이를 반영합니다. 긴 첫 방문 대화는 위쪽이 잘리지 않게 스크롤되며 굿즈 상세 행동은 본문 폭 안에 남습니다.

`npm run test:aouad-mobile-browser`는 실행 중인 앱을 Chromium·WebKit의 320·375·390·440px에서 확인합니다. 출력은 임시 디렉터리에 저장하고, 실제 서버 거래를 만들지 않습니다. 실행 환경·명령과 검증 기록은 [시연 운영 가이드](../../../docs/runbooks/aouad-executive-demo.md#모바일-브라우저-검증--2026-09-10)를 따릅니다.

## 거래 시연의 상태

래플·사전예약·선착순의 허브·상세·HUD는 `presentationDealSummary`로 같은 로컬 영수증(`dealRecords`)을 읽습니다. 래플은 무료 1회, 사전예약은 SKU·옵션·수량 기록만 생성하며 누적 구매를 바꾸지 않습니다. 선착순은 매대 한도·잔여 수량·시연 주문·누적 구매를 함께 갱신합니다. 카운트다운은 최초 시작에 저장한 `clockStartedAt`을 사용하므로 화면 이동·새로고침에도 이어지고, 시연 초기화 때 기록과 함께 현재 시각으로 재설정됩니다. 실제 거래 API는 호출하지 않습니다.

뽑기는 세션 실행 성공 직후, 결과 연출을 기다리기 전에 `presentation-draws.js`가 정확한 SKU와 고유 실행 ID를 저장합니다. `drawRecords`는 네 회차의 총 320칸과 실제 KST 날짜별 회차당 10회 한도를 보존하며, 보관함 표시 한도 200개와 분리합니다. 재진입·새로고침·같은 브라우저의 다른 탭에서도 이미 연 칸을 복원합니다. 자정에는 일일 횟수만 초기화하며 전체 시연 초기화가 새 판을 만듭니다. 결과 콜백과 배송 신청을 반복해도 같은 결과·주문을 중복 생성하지 않습니다. 누적 구매 혜택은 구성안으로 표시하고, 현재 구현에서 폐기된 10분 선오픈 혜택은 노출하지 않습니다.
