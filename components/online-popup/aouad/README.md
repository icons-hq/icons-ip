# 지우학 온라인 팝업 시연 모듈

`icons-hq/icons`의 `/sample/aouad`를 ICONS IP에서 검토할 수 있도록 가져온 독립 화면입니다. 원본 커밋은 `7989794969bd74cf53a0fdefb595cfcfff8717b9`이며, 복사 경로와 원본 SHA-256은 `provenance.json`에 기록합니다. 이후의 로컬 개선은 이 원본 입력 기록을 변경하지 않습니다.

## 구성

- `source/components/aouad/`: 오프닝, 14개 허브 장면, 10개 상세 존, 굿즈 상세, 학생증 및 시연 게임.
- `source/components/popup/`: 이동 안내도와 공통 HUD.
- `source/lib/`: 브라우저 시연 상태를 위한 게임 엔진, 소리, URL 및 스크롤 처리.
- `public/ip-popups/aouad/`: 원본 이미지·영상·오디오와 검수한 신규 컨셉 굿즈 이미지. 원본 206개의 복사 이력은 `provenance.json`에 남습니다.

기본 export는 `source/components/aouad/AouadSample.jsx`입니다. 무대의 높이는 `100dvh`이며 자체 CSS Module 토큰을 씁니다. Next.js 클라이언트 경계에서 동적으로 불러오고, 전역 셸과의 경계는 호스트 라우트가 소유합니다. Phaser는 게임 진입 시 동적으로 불러오며 원본의 `phaser4` 별칭을 저장소의 `phaser` 4.2.1 의존성으로 연결했습니다.

## 시연과 운영의 경계

원본은 비밀번호로 보호된 기획 시연판입니다. 굿즈·가격·재고·기간·구매권·주문·당첨·배송·현장 예약·커뮤니티 글은 시연 데이터이며 브라우저 상태로 작동합니다. 이식만으로 실제 결제, 재고, 권리 발급, 배송 신청, 예약 및 외부 게시가 활성화되는 것은 아닙니다. 실거래를 연결하려면 서버 권한·멱등 처리·운영 정책과 해당 도메인의 별도 검증이 필요합니다.

원본 `40_dev/adr/ADR-0024-official-footage-in-aouad-sample.md`는 PM 제공 공식 타이틀 영상 1건의 시연 사용 확인을 기록합니다. 같은 ADR은 나머지 웹 수집 스틸의 권리 미확보 상태와 대외 제출 시 최종 자산·문안 감수 경계를 유지합니다. `provenance.json`은 파일 출처 기록이며 별도 자산 사용 허가를 의미하지 않습니다.

## 이식 검증

복사 시 원본 엔트리의 재귀 import 경로 36개를 추출해 빠진 상대 의존성이 없음을 확인했습니다. 원본 에셋은 원본 SHA-256과 일치하도록 복사했습니다. 이후 수정 검증은 호스트 라우트의 브라우저 QA, 관련 테스트, lint 및 build 결과로 기록합니다.

## 로컬 품질 개선

- 임시 도형 합성·사진과 맞지 않는 제품·인물 표기를 내장 ImageGen으로 만든 컨셉 굿즈 이미지 **23개**로 교체했습니다. 일반 굿즈 9종은 `generated-asset-manifest.json`, 소형 경품 14종은 `generated-box-asset-manifest.json`에 원본 PNG·최종 WebP의 SHA-256과 검수 결과를 기록합니다. 무크롭 WebP quality 90으로 패키징했고 최종 23종은 총 4,735,676 bytes입니다. 2026-09-09 최종 23종의 변환 전·후 직접 이미지 검수와 원본·최종 SHA 46개 검증을 통과했습니다. 로컬 HTTP 응답 23종도 최종 SHA와 일치합니다. 결과는 제작된 실물의 촬영본이 아닌 프레젠테이션용 디자인 시안입니다.
- 굿즈 상세의 원작 설명은 사진에 실제로 보이는 내용과 디자인 모티프를 설명하도록 정리했습니다. 표시된 `1인 1개` 제한은 숫자 `per: 1`로도 기록해 시연 장바구니와 같은 값을 사용합니다.
- 히어로 영상과 이미지 순환은 화면 노출, 브라우저 탭 상태, 모션 축소 설정을 따릅니다. 화면을 떠날 때는 진행 중인 재생 요청까지 정리하며, 영상 로딩 실패에는 포스터를 보여줍니다. 관련 수명주기는 `hero-playback.test.ts`로 검증합니다.
- `presentation-state.js`는 저장된 값을 현재 화면이 쓰는 필드로 다시 구성합니다. 손상된 JSON, 잘못된 당첨·주문 값, 범위를 벗어난 예약은 화면에 직접 전달하지 않습니다. 브라우저 저장소가 차단되거나 가득 차도 그 세션의 변경은 메모리에 유지됩니다.
- `presentation-commerce.js`는 선택한 옵션을 장바구니 행에 보존하고 같은 굿즈의 모든 옵션 수량에 공통 한도를 적용합니다. 옵션을 고르지 않은 의류와 알 수 없는 굿즈는 추가하지 않습니다. 굿즈 상세의 주 행동은 상시 판매·구매권·사전예약·선착순·래플을 구분하는 순수 상태 데이터로 제공합니다. 실제 거래 API를 호출하지 않습니다.

## 접근과 검증

정본 경로는 `/ip/aouad`입니다. 기본은 staff/admin 전용이며 `/ip`의 프레젠테이션 카드가 같은 권한의 사용자에게만 보입니다. 서버 권한, 공개·회수 스위치, 로컬 QA, 배포 후 확인 순서는 [시연 운영 가이드](../../../docs/runbooks/aouad-executive-demo.md)를 따릅니다. 공개 카탈로그에 가짜 IP나 굿즈 행을 추가하지 않습니다.

2026-09-09 현재 호스트 경로·접근 제어·HUD·브라우저 상태·영상 수명주기·게임·시연 커머스를 포함한 집중 테스트 21파일 208개, TypeScript 검사와 production build가 통과했습니다. 이 모듈의 lint는 오류·경고 0개이며 전체 저장소에는 기존 downloader 경고 1개가 남습니다. 브라우저에서는 첫 방문 학생증 발급·허브 진입, 37개 굿즈 상세, 메인 14개 장면, 장바구니 옵션·주문, 커뮤니티 작성, 현장 예약을 확인했습니다. 급식실·방송실·도서관은 실제 플레이 완료·대화상자 중 정지·재도전 제한을, 네 뽑기 방식은 개봉·결과·복귀·중단 취소·잔여 수량을 확인했습니다.

## 거래 시연의 상태

래플·사전예약·선착순의 허브·상세·HUD는 `presentationDealSummary`로 같은 로컬 영수증(`dealRecords`)을 읽습니다. 래플은 무료 1회, 사전예약은 SKU·옵션·수량 기록만 생성하며 누적 구매를 바꾸지 않습니다. 선착순은 매대 한도·잔여 수량·시연 주문·누적 구매를 함께 갱신합니다. 카운트다운은 최초 시작에 저장한 `clockStartedAt`을 사용하므로 화면 이동·새로고침에도 이어지고, 시연 초기화 때 기록과 함께 현재 시각으로 재설정됩니다. 실제 거래 API는 호출하지 않습니다.
